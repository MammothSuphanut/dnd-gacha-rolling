# Mystic Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Mystic subclass (Order) ทั้งหมดในโปรเจกต์ — official ล้วน (Unearthed Arcana: The Mystic Class) **ทั้ง 6 สายเป็น 2014-only** — class นี้เป็น UA playtest ที่ไม่เคยถูกจัดพิมพ์อย่างเป็นทางการทั้งใน 2014 core books หรือ 2024 XPHB เลย รวมทุกสายตามกติกา 2014-only
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, `class-mystic.json`
**หมายเหตุความเชื่อมั่น**: เป็น Unearthed Arcana (playtest) ไม่ใช่เนื้อหาจบสมบูรณ์แบบ official ปกติ — กลไก Psionic Discipline/Psi Point อาจไม่ได้ผ่านการปรับสมดุลรอบสุดท้ายเท่า class ที่พิมพ์จริง ควรคุย DM ก่อนใช้เสมอ
**กลไกคลาสหลัก**: เลือก Order ตั้งแต่ lv1 (คล้าย Warlock patron) — แต่ละ Order ได้ **Bonus Disciplines** เฉพาะทางเพิ่ม 2 อัน

## A Tier — พลิกเกมได้ชัดเจน

### Order of the Immortal 🔵🕰️ — Tanky psion
- **จุดเด่น**: Immortal Durability เพิ่ม HP max ต่อเลเวล + AC formula ไม่ใส่เกราะ (10+Dex+Con) เป็น mystic ที่อึดที่สุดในบรรดา 6 order โดยไม่ต้องพึ่งเกราะเลย
- **จุดด้อย**: Bonus Disciplines เฉพาะทาง Immortal เน้นเสริมร่างกาย อาจแคบกว่า order ที่เน้น utility/control
- **วิธีเล่น**: เล่นแนวหน้าแบบไม่ใส่เกราะ ใช้ HP/AC ที่สูงกว่า order อื่นยืนรับดาเมจแทนปาร์ตี้ได้

### Order of the Soul Knife 🔵🕰️ — Free psychic weapon
- **จุดเด่น**: Soul Knife สร้างอาวุธพลังจิตฟรี (1d8 finesse psychic) ไม่ต้องพึ่งอาวุธจริง + parry ให้ AC เสริมได้ ผสมทั้งดาเมจและป้องกันในตัวเดียว
- **จุดด้อย**: ดาเมจอาวุธพื้นฐาน (1d8) ไม่สูงมาก ต้องพึ่ง discipline เสริมดาเมจเพิ่มถึงจะแข่งกับมาร์เชียลแท้ได้
- **วิธีเล่น**: สร้าง Soul Knife แทนพกอาวุธจริง ตีประชิดควบคู่กับ parry เสริม AC เมื่อไม่ได้โจมตี

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Order of the Avatar 🔵🕰️ — Emotion control/support
- **จุดเด่น**: proficiency เกราะกลาง/โล่เสริมความอึด; Bonus Discipline สาย emotion ให้ control/support ทีมได้ดี
- **จุดด้อย**: ธีม emotion-based control อาจไม่ reliable เท่า control ตรงๆ (ขึ้นกับ discipline ที่เลือก)
- **วิธีเล่น**: ใช้ discipline สาย emotion เสริมทีม/กดดันศัตรู ควบคู่กับเกราะกลางที่ทำให้ยืนแนวหน้าได้บ้าง

### Order of the Awakened 🔵🕰️ — Mind/investigation utility
- **จุดเด่น**: skill proficiency หลากหลาย + Bonus Discipline สายอ่านใจ/สืบสวน เหมาะบทบาทนักสืบ/skill-monkey
- **จุดด้อย**: เอียงไปทาง utility/investigation มากกว่า combat power โดยตรง
- **วิธีเล่น**: ใช้ discipline อ่านใจ/สืบสวนเสริมบทบาทนักสืบ ควบคู่กับ skill proficiency ที่หลากหลาย

### Order of the Nomad 🔵🕰️ — Flexible proficiency utility
- **จุดเด่น**: Breadth of Knowledge ให้เปลี่ยน proficiency ได้ทุก long rest ยืดหยุ่นสูงมาก ปรับตัวตามภารกิจได้ตลอด
- **จุดด้อย**: ไม่มีดาเมจ/แทงค์เสริมโดยตรง เอียงไปทาง utility ล้วน
- **วิธีเล่น**: ปรับ proficiency ให้ตรงกับภารกิจ/สถานการณ์ที่คาดว่าจะเจอในแต่ละวัน

### Order of the Wu Jen 🔵🕰️ — Elemental control
- **จุดเด่น**: skill proficiency สาย nature/arcana + Bonus Discipline สายควบคุมธาตุ เหมาะบทบาท caster-lite ที่เน้นควบคุมสภาพแวดล้อม
- **จุดด้อย**: ธีม elemental control เอียงไปทาง utility/exploration มากกว่าดาเมจตรง
- **วิธีเล่น**: ใช้ discipline ควบคุมธาตุแก้ปัญหาสิ่งแวดล้อม/สำรวจ ควบคู่กับบทบาท caster-lite ของ mystic
