# Vagabond Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Vagabond subclass ทั้งหมดในโปรเจกต์ — Valda's Spire ล้วน **ทุกสายเป็น 2024 เท่านั้น** (class นี้ไม่มีเวอร์ชัน 2014 เลย ไม่มี orphan ให้พิจารณา)
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, `Mage Hand Press; Valda's Spire of Secrets - 2024.json`
**หมายเหตุสำคัญ**: Vagabond **แชร์ subclass pool กับ Captain/Gunslinger** 17 จาก 18 สาย (Dragon Banner, Eagle Banner, Jolly Roger, Siegeball Jersey, Daggermark, Feylost, Houndmaster, Knight Errant, Pugilist, Rōnin, Troubadour, Yellow Sign, Plague Doctor, Gourmand, Brigand, Adrenaline Junkie, Tower Banner) — เป็น subclass เดียวกันในข้อมูลต้นฉบับ ใช้เทียร์เดียวกับที่วิเคราะห์ไว้ใน [captain-subclass-tier-list-2024.md](captain-subclass-tier-list-2024.md) เพื่อไม่ให้งานซ้ำซ้อน มีเพียง **Mage Brand** ที่เป็นของ Vagabond เองแท้ๆ

- 🟢 Valda's Spire — 🔗 แชร์กับ Captain/Gunslinger (ดูรายละเอียดเต็มที่ไฟล์ Captain)

## A Tier — พลิกเกมได้ชัดเจน

### Dragon Banner 🟢🔗 — *ดูรายละเอียดเต็มใน Captain (A tier)*
- **สรุป**: Rampage (ตีต่อฟรีหลังฆ่า/crit) + Critical Focus — execute/nova damage แรงที่สุดในกลุ่มแบนเนอร์

### Tower Banner 🟢🔗 — *ดูรายละเอียดเต็มใน Captain (A tier)*
- **สรุป**: Iron Wall (temp AC/damage reduction) + Siege Defense — defensive tank support ระดับบนสุดของกลุ่ม

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Mage Brand 🟢 — Magic detection utility
- **จุดเด่น**: Arcane Synesthesia ระบุตัวตนคนที่ร่ายคาถาใน 24 ชม.ล่าสุดได้ทันที + ตรวจจับ magic item ผ่านการสัมผัส เป็น utility สืบสวน/anti-caster ที่ไม่มี subclass อื่นในกลุ่มนี้มี; Spellbranding เสริมพลังผ่านการสักลายเวทมนตร์
- **จุดด้อย**: ประโยชน์หลักเอียงไปทาง utility/investigation มากกว่าดาเมจ/แทงค์ตรงๆ
- **วิธีเล่น**: ใช้ Arcane Synesthesia สืบหาคนที่เพิ่งร่ายคาถา/ของวิเศษที่ซ่อนอยู่ ก่อนใช้ Spellbranding เสริมพลังตามสถานการณ์

## สรุปเร็วตามบทบาท

| บทบาท | สายที่เด่นสุด |
|---|---|
| Execute/nova damage | Dragon Banner |
| แทงค์/ป้องกันทีม | Tower Banner |
| Magic detection/investigation | Mage Brand |
| แชร์กับ Captain/Gunslinger (ดูไฟล์ Captain) | Eagle Banner, Jolly Roger, Siegeball Jersey, Daggermark, Feylost, Houndmaster, Knight Errant, Pugilist, Rōnin, Troubadour, Yellow Sign, Plague Doctor, Gourmand, Brigand, Adrenaline Junkie |

**จุดสังเกต**: Vagabond เป็น class ที่สาม (ต่อจาก Captain, Gunslinger) ที่ใช้ระบบ "mercenary company" subclass pool ร่วมกัน — มีแค่ Mage Brand ที่เป็นเอกลักษณ์เฉพาะตัว ถ้าต้องเลือกระหว่าง 3 class นี้ ควรดูที่กลไกหลักของ base class (Vagabond vs Captain vs Gunslinger) มากกว่าที่จะดูจาก subclass เพราะผลลัพธ์ subclass ส่วนใหญ่เหมือนกันหมด
