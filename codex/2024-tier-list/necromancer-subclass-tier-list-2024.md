# Necromancer Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Necromancer subclass ทั้งหมดในโปรเจกต์ — Valda's Spire ล้วน ยึด 2024 เป็นหลัก ทุกสายจาก 2014 (14 สาย) มีเวอร์ชัน 2024 ครบ ไม่มี orphan
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, `Mage Hand Press; Valda's Spire of Secrets - 2024.json`
**กลไกคลาสหลัก**: **Charnel Touch** (ทรัพยากร/attack หลัก) + **Thralls** (ritual สร้าง undead minion) — หลาย subclass มีฟีเจอร์ที่ trigger เมื่อทำดาเมจจาก Charnel Touch ถึงเกณฑ์ (5+)

---

- 🟢 Valda's Spire

## A Tier — พลิกเกมได้ชัดเจน

### Necrodancer 🟢 — Stun-lite control
- **จุดเด่น**: Charnel Groove บังคับเป้าที่โดนดาเมจ 5+ ให้ "เต้น" เสียการกระทำทั้งหมดในเทิร์นถัดไปโดยไม่ต้อง save เป็น control ระดับ stun ที่ไม่มี save ต้าน
- **จุดด้อย**: ต้องทำดาเมจถึงเกณฑ์ 5+ ก่อนถึงจะ trigger ได้ ศัตรู HP สูง/ต้าน necrotic อาจไม่ถึงเกณฑ์
- **วิธีเล่น**: ยิง Charnel Touch ใส่เป้าสำคัญให้ถึงดาเมจ 5+ ก่อนเพื่อล็อกไม่ให้ขยับทั้งเทิร์นถัดไป

### Overlord 🟢 — Army-buffing aura
- **จุดเด่น**: Charnel Aura สร้างโซนเสริมพลังรัศมี 30ft ให้ทั้งตัวเองและกองทัพ thrall เป็น subclass ที่เหมาะกับ build "necromancer จอมทัพ" ที่สุด
- **จุดด้อย**: ต้องเสีย Charnel Touch points 5+ เปิดใช้ แข่งทรัพยากรกับ Charnel Touch attack ปกติ
- **วิธีเล่น**: เรียก thrall เยอะๆ ก่อนไฟต์ใหญ่ แล้วเปิด Charnel Aura เสริมพลังให้กองทัพทั้งหมดพร้อมกัน

### Pale Master 🟢 — Necromancy damage scaling
- **จุดเด่น**: Charnel Empower แปลง Charnel Touch points เป็นดาเมจเสริมให้คาถา necromancy โดยตรง สเกลตามเลเวล+Int mod เป็นดาเมจนัดเดียวที่แรงมาก
- **จุดด้อย**: ต้องมี Charnel Touch points สะสมพอถึงจะเสริมดาเมจได้เต็มที่ แข่งทรัพยากรกับฟีเจอร์อื่น
- **วิธีเล่น**: สะสม Charnel Touch points แล้วปล่อยพร้อมคาถา necromancy หลักเป็นดาเมจนัดใหญ่ตอนจังหวะสำคัญ

### Plague Lord 🟢 — Anti-resistance debuff
- **จุดเด่น**: Necrotoxin ทะลุ resistance/immunity ต่อ poison ได้ (ปกติ poison โดน resist/immune บ่อยมาก); Vile Congregation ลด d20 test ของศัตรูใกล้ตัวต่อเนื่อง
- **จุดด้อย**: ประโยชน์เต็มที่ต้องเน้นธีม poison ซึ่งปกติเป็นดาเมจที่อ่อนที่สุดในเกม แต่ subclass นี้แก้จุดอ่อนนั้นได้ตรงจุด
- **วิธีเล่น**: ใช้คาถา/ฟีเจอร์ poison เป็นดาเมจหลักโดยไม่ต้องกลัว resistance ควบคู่กับ Vile Congregation ลด check ของศัตรูรอบตัว

### Reaper 🟢 — Damage-triggered stealth
- **จุดเด่น**: Charnel Veil ให้ล่องหนฟรีทุกครั้งที่ทำดาเมจ 5+ จาก Charnel Touch เป็น survivability/repositioning ที่ยอดเยี่ยม
- **จุดด้อย**: ต้องทำดาเมจถึงเกณฑ์ก่อนถึงจะล่องหนได้ ถ้าดาเมจไม่ถึงจะไม่มีตัวป้องกันสำรอง
- **วิธีเล่น**: ยิง Charnel Touch ให้ถึงเกณฑ์ดาเมจแล้วล่องหนหนีทันที เป็น hit-and-vanish ที่ปลอดภัยมาก

### Toymaker 🟢 — Multi-companion summon
- **จุดเด่น**: Charnel Puppet สร้าง Slaymate ได้ **2 ตัวต่อทุก 5 points** ที่เสีย — สเกลจำนวน companion ตามทรัพยากรที่ลงทุน มากกว่า subclass companion ทั่วไปที่ได้แค่ 1 ตัว
- **จุดด้อย**: ต้องเสีย Charnel Touch points เยอะเพื่อได้ companion จำนวนมาก แข่งทรัพยากรหนักกับฟีเจอร์อื่น
- **วิธีเล่น**: ทุ่ม Charnel Touch points สร้าง Slaymate หลายตัวก่อนบอสไฟต์ใหญ่ ใช้จำนวนเป็นตัวถล่มด้วย action economy

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Death Knight 🟢 — Necrotic sustain
- **จุดเด่น**: Charnel Resilience ให้ temp HP เท่าดาเมจ necrotic ที่ทำได้ เป็น sustain ที่ผูกกับดาเมจโดยตรง; Combat Research เสริมการต่อสู้
- **จุดด้อย**: temp HP ขึ้นกับปริมาณดาเมจที่ทำได้ ถ้าโจมตีอ่อนก็ได้ temp HP น้อยตาม
- **วิธีเล่น**: ตี Charnel Touch ต่อเนื่องเพื่อเก็บ temp HP สะสม เล่นแนวหน้าแบบก้าวร้าวได้มากกว่า necromancer ทั่วไป

### Blood Ascendant 🟢 — Lifesteal on kill
- **จุดเด่น**: Charnel Drain ฟื้น HP เมื่อฆ่าเป้าด้วย Charnel Touch เป็น sustain ที่ดีในไฟต์กลุ่มเยอะ
- **จุดด้อย**: ต้องปิดจ๊อบเป้าด้วย Charnel Touch โดยตรงถึงจะได้ฮีล ไม่ได้ผลกับดาเมจจากคาถาอื่น
- **วิธีเล่น**: ไล่ปิดจ๊อบเป้า HP ต่ำด้วย Charnel Touch ต่อเนื่องเพื่อฟื้น HP ตัวเองระหว่างไฟต์กลุ่ม

### Crone 🟢 — Curse debuff
- **จุดเด่น**: Charnel Curse ใส่เดอบัฟต่อเนื่องเมื่อทำดาเมจถึงเกณฑ์ ลดความสามารถศัตรูระยะยาว
- **จุดด้อย**: ต้อง save พลาดก่อนถึงจะติดเคิร์ส ไม่ auto เหมือนบาง subclass อื่น
- **วิธีเล่น**: ใช้ Charnel Curse ใส่เป้าที่จะสู้ยาวๆ (บอส) เพื่อลดความสามารถระยะยาวตลอดไฟต์

### Black Rider 🟢 — Mounted tank
- **จุดเด่น**: Corpse Cavalry เสริมการต่อสู้บนหลังม้าโครงกระดูก; Charnel Shield ลดดาเมจที่รับผ่าน reaction
- **จุดด้อย**: ประโยชน์เต็มที่ต้องมีพื้นที่ให้ม้าวิ่ง/ต่อสู้ ดันเจี้ยนแคบใช้ยาก
- **วิธีเล่น**: ขี่ม้าโครงกระดูกบุกประชิด ใช้ Charnel Shield ซับดาเมจสำคัญที่โดนตอบโต้กลับมา

### Dead Mist Acolyte 🟢 — Self-healing sustain
- **จุดเด่น**: Mistborne Regeneration แปลง Charnel Touch points เป็นฮีลตัวเองได้ เพิ่ม survivability ให้ necromancer ที่ปกติเปราะบาง
- **จุดด้อย**: ต้องเสีย Charnel Touch points 5+ แลกฮีล แข่งทรัพยากรกับฟีเจอร์อื่นเหมือนสายอื่นในกลุ่มนี้
- **วิธีเล่น**: แลก Charnel Touch points เป็นฮีลตอน HP ต่ำแทนที่จะพึ่งฮีลเลอร์ทีมอย่างเดียว

### Corpse Florist 🟢 — Enhanced thralls
- **จุดเด่น**: Garden of the Grave ปลูกดอกไม้ศพลง thrall เสริมความสามารถให้กองทัพ undead มีเอฟเฟกต์เพิ่ม
- **จุดด้อย**: ต้องมี thrall อยู่แล้วถึงจะได้ประโยชน์ ตัวเดียวไม่ได้ผลเทียบเท่า necromancer ที่เน้น solo caster
- **วิธีเล่น**: เรียก thrall แล้วปลูกดอกไม้ศพเสริมความสามารถก่อนไฟต์ใหญ่ เหมาะ build ที่เน้นกองทัพ undead

### Reanimator 🟢 — Custom-enchanted thralls
- **จุดเด่น**: Spell-Stitching ฝังเอฟเฟกต์เวทมนตร์ลง thrall ได้ ปรับแต่งกองทัพให้มีความสามารถพิเศษเฉพาะทาง
- **จุดด้อย**: ต้องเสียเวลา 1 ชม.+ ฝัง Spell-Stitch ล่วงหน้า ใช้กะทันหันกลางไฟต์ไม่ได้
- **วิธีเล่น**: เตรียม thrall ที่ฝัง Spell-Stitch ไว้ล่วงหน้าก่อนภารกิจสำคัญ ปรับแต่งความสามารถให้ตรงกับสถานการณ์ที่คาดว่าจะเจอ

## C Tier — utility เฉพาะทาง/combat impact ต่ำ

### Pharaoh 🟢 — Minor spellcasting focus utility
- **จุดเด่น**: ใช้ Holy Symbol เป็น spellcasting focus ได้ (ปกติ necromancer อาจต้องใช้ของเฉพาะทาง) เสริมความยืดหยุ่นด้านอุปกรณ์เล็กน้อย
- **จุดด้อย**: ฟีเจอร์ signature ที่เปิดเผยในข้อมูล local เอียงไปทาง utility เล็กๆ ไม่มี power spike ชัดเจนเทียบสายอื่นในกลุ่มนี้
- **วิธีเล่น**: เลือกสายนี้ถ้าต้องการ flavor ธีมฟาโรห์/กษัตริย์โบราณ มากกว่าพลังทางกลไกที่โดดเด่น

## สรุปเร็วตามบทบาท

| บทบาท | สายที่เด่นสุด |
|---|---|
| Control (stun-lite) | Necrodancer |
| ทัพ undead | Overlord, Corpse Florist, Reanimator |
| ดาเมจนัดใหญ่ | Pale Master |
| ทะลุ resistance | Plague Lord |
| Stealth/survivability | Reaper |
| Multi-companion | Toymaker |
| Sustain/ฮีลตัวเอง | Blood Ascendant, Dead Mist Acolyte, Death Knight |
| Debuff ระยะยาว | Crone |
| Mounted tank | Black Rider |
| Flavor/utility เบา | Pharaoh |

**จุดสังเกต**: Necromancer เป็น class ที่หลาย subclass ใช้ pattern "ทำดาเมจถึงเกณฑ์ 5+ แล้ว trigger เอฟเฟกต์พิเศษ" (Necrodancer, Crone, Reaper) ร่วมกัน — ถ้า build เน้นดาเมจสูงต่อครั้งจะได้ประโยชน์จาก subclass กลุ่มนี้มากกว่า build ที่กระจายดาเมจเป็นก้อนเล็กหลายครั้ง
