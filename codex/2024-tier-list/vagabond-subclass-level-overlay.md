# Vagabond — Subclass Level Overlay (ชั้น 2)

**อ้างอิง**: [vagabond-level-baseline.md](vagabond-level-baseline.md) (Class Baseline, ชั้น 1) + [vagabond-subclass-scorecard-2024.md](vagabond-subclass-scorecard-2024.md) (แหล่งข้อมูล feature-text หลัก)
**ขอบเขต**: 18 subclass — gate lv3/6/10/14 (ตรงกับ "(Vagabond Subclass/Subclass feature — ยกเว้น)" ในตาราง Chassis ของ baseline) — 7 ตัวเป็น 🔀 Cross-Compatible กับ Captain
**รูปแบบ**: delta-only แบบย่อ (>10 subclass) — list เฉพาะเลเวล/axis ที่เกรดต่างจาก baseline; ไม่ระบุ = เท่า baseline
**หมายเหตุสำคัญ**: baseline ตั้งอยู่บนสมมติฐาน "เลือก maneuver แบบ generalist" (Stunning Blow/Riposte/Dig Deep) ทำให้ Damage/Control/Survivability/AE/Versatility ของ baseline **สูงอยู่แล้ว** — ช่องว่างสำหรับ subclass ส่วนใหญ่จึงกระจุกอยู่ที่ **Support (D floor)** และ **Utility (D floor)** เป็นหลัก ต่างจากคลาสอื่นที่มักมีช่องว่างกระจายทั่วทุกแกน

**Baseline โดยสรุป**: Damage B(1-4)→A(5-17)→**S(18-20)** · Control D(1-2)→**A(3-20)** · Support **D(1-20) flat** · Survivability B(1)→**S(2-20)** · Action Economy C(1-2)→**B(3-20)** · Utility **D(1-20) flat** · Versatility B(1)→**A(2-20)**

## Adrenaline Junkie

*(0 delta ทุกแกน — Damage/AE ตรง baseline เป๊ะ, ที่เหลือ "ใกล้เคียง/เท่า baseline" ตามที่ old scorecard ระบุไว้เอง)*

## Brigand

*(0 delta ทุกแกน — Take Hostage/Underhanded Blow ไม่ยืนยันว่าเกิน Tier4-CC ที่ baseline สมมติฐานไว้แล้วจาก Stunning Blow)*

## Daggermark 🔀

- **Support**: D(1-5)→**C(6-20)** — Flanking Strike (lv6, ally คนถัดไปที่ตี target เดียวกันได้ Advantage — floor escape แคบแต่จริง)
- **Action Economy**: C(1-2)→B(3-9)→**A(10-20)** — Effortless Dodge (lv10, bonus action Disengage/Dodge ผ่าน battle die) + Quick Hide (Hide เป็น bonus action)
- **Utility**: D(1-2)→**B(3-20)** — Sleight of Hand+Stealth prof+Charismatic Initiative+Quick Hide (toolkit โจรครบชุด)

## Dragon Banner 🔀

- **Damage**: [A(5-13) เท่า baseline]→**S(14-20)** — Critical Focus(crit-range ขยาย)+Rampage(ตี+ขยับฟรีทุกครั้งที่ kill/crit)+Coup de Grâce(lv14) = "damage-nova engine ที่ snowball ได้แรงมาก"
- **Action Economy**: C(1-2)→**A(3-20)** — Rampage ให้ตี+ขยับฟรีไม่จำกัดจำนวนครั้งทุกครั้งที่ kill/crit = พลิก Extra-Action modifier ใหม่ตั้งแต่ subclass gate แรก

## Eagle Banner 🔀

- **Support**: D(1-2)→**C(3-20)** — Counter-Shot (reaction ปกป้อง ally จาก ranged attack — floor escape แคบแต่จริง)

## Feylost 🔀

- **Support**: D(1-2)→**C(3-20)** — Fey Mood "Forlorn" (redirect attack จาก ally มาที่ตัวเอง — 1-ใน-8 mood สุ่ม แต่เป็นจริงเมื่อเกิด)
- **Control**: [A(3-13) เท่า baseline]→**S(14-20)** — Frenzied Strike (บังคับเป้าโจมตีสุ่มรวมพวกเดียวกันเอง) กลายเป็น reliable หลัง Mercurial(lv14, เลือก mood เองได้แทนสุ่ม)

## Gourmand 🔀

- **Support**: D(1-5)→**S(6-20)** — Monster Meal (temp HP+บัฟติดตัวสูงสุด 3 ประเภทซ้อนกันให้พรรคพวก) = "magnitude สูงที่สุดใน class นี้" — delta สูงสุดในไฟล์นี้ (+9)
- **Action Economy**: C(1-2)→B(3-9)→**A(10-20)** — Quick Snack (lv10, ตัดการเสีย Action เต็มของ Breather ออกไปเลย = "ประหยัด action ที่ทรงพลังมาก")

## Houndmaster 🔀

- **Damage**: B(1-2)→**A(3-4)** [rest เท่า baseline] — Faithful Hound (นักสู้เพิ่มที่โจมตีเองได้ทุกเทิร์นผ่าน Sick 'Em! ตั้งแต่ lv3) ดึง A-onset เร็วกว่า baseline's lv5
- **Action Economy**: C(1-2)→**A(3-20)** — สั่งหมาโจมตีด้วย bonus action ทุกเทิร์น = companion-command pattern (old scorecard เองอ้างอิง Beast Master ของ Ranger ตรงๆ) พลิก Extra-Action+Resource-Conversion พร้อมกัน
- **Utility**: D(1-5)→**B(6-20)** — Hound's Instincts (lv6, Blindsight 30ft+ตรวจจับปลอมตัว/สิง/แปลงร่าง)

## Jolly Roger 🔀

- **Support**: D(1-9)→B(10-13)→**A(14-20)** — Dirty Tactics's Flank option(lv10, ally ได้ Advantage) ซ้อนกับ All Hands on Deck(lv14, bonus action แจก Advantage ให้ ally หลายคน)

## Knight Errant 🔀

- **Support**: D(1-5)→**B(6-20)** — Inspiring Battlecry(lv6, Heroic Inspiration ตัวเอง+ally ตอน Bloodied)+Redirection(lv10, reaction รับ attack แทน ally+resistance)
- **Utility**: D(1-2)→**B(3-20)** — Chivalrous Oath (เลือก skill prof 2 จาก 4)

## Mage Brand

- **Utility**: D(1-2)→**A(3-20)** — Spellbrand Spellcasting เปิดทาง Sorcerer utility spell(Detect Magic/Alarm/Comprehend Languages)+Arcane Synesthesia = **Primary(Magnitude) ปลดล็อกจริง**
- **Versatility**: [A(2) เท่า baseline]→**S(3-20)** — **"archetype เดียวของ Vagabond ที่มี full spellcasting hybrid บน chassis นักสู้"** — Imprinted Spellscar(lv14, ขโมย/imprint คาถา) เสริมต่อ = พลิก Primary tier เอง ไม่ใช่แค่ modifier flip (pattern เดียวกับ Divine Soul/Wu Jen)

## Plague Doctor 🔀

- **Support**: D(1-2)→**A(3-20)** — Remedy (bonus action ฮีล ally 2×battle-die+Con mod+แก้ 1 condition) = "ฮีลที่ reliable ที่สุดใน class" ตั้งแต่ subclass gate แรก
- **Utility**: D(1-2)→**B(3-20)** — Physician (Medicine expertise+Diagnosis ตรวจ Poisoned/Bloodied/contagion)

## Pugilist 🔀

*(0 delta ทุกแกน — Damage/Control/AE ตรง baseline เป๊ะ, Survivability's S ก็แค่ reinforce ceiling เดิม)*

## Rōnin 🔀

- **Action Economy**: [B(3-13) เท่า baseline]→**A(14-20)** — Swordmaster ให้ตีซ้ำฟรีไม่เสีย action ทุกครั้งที่พลาด

## Tower Banner 🔀

## ข้อค้นพบสำคัญ

1. **⚠️ ช่องว่างของคลาสนี้กระจุกอยู่ที่ Support/Utility (D floor) เกือบทั้งหมด ต่างจากคลาสอื่นที่กระจายทั่วทุกแกน** — เพราะ baseline สมมติฐาน "เลือก maneuver แบบ generalist" ทำให้ Damage/Control/Survivability/AE/Versatility สูงอยู่แล้วตั้งแต่ layer 1 (Damage เริ่ม A ที่ lv5, Control A ที่ lv3, Survivability S ที่ lv2, AE B ที่ lv3, Versatility A ที่ lv2) — 12/18 subclass ขยับ Support ได้ (67%), 8/18 ขยับ Utility ได้ (44%) แต่มีแค่ 3/18 ที่ขยับ Damage และ 2/18 ที่ขยับ Control
2. **Gourmand's Monster Meal เป็น Support delta สูงสุดในไฟล์นี้ (+9, D→S)** — บัฟติดตัวสูงสุด 3 ประเภทซ้อนกันให้พรรคพวกทั้งทีม magnitude สูงสุดในคลาสตามที่ old scorecard ระบุไว้เอง
3. **Yellow Sign's Frenzied Strike (reliable) vs Feylost's Frenzied Strike (random-until-lv14) เป็น subclass คู่ที่ใช้กลไก Control เดียวกันแต่ได้เกรดต่างช่วงเวลากัน** — Yellow Sign ได้ S ตั้งแต่ lv6 (ผ่าน Pallid Aura เสริม) ส่วน Feylost ต้องรอถึง lv14 (Mercurial ทำให้เลือก mood เองได้) — ตัวอย่างชัดเจนของ "reliability ของ trigger เดียวกัน กำหนดจังหวะที่ delta เริ่มมีผล"
4. **Mage Brand เป็น subclass เดียวในคลาสนี้ที่ทะลุ floor-lock ได้ 2 axis พร้อมกัน (Utility+Versatility)** ผ่าน full Sorcerer spellcasting ทับ chassis นักสู้เดิม — pattern เดียวกับ Wu Jen(Mystic)/Occultist(Monster Hunter)/Divine Soul(Sorcerer)/Scholar(Tactician) — ยืนยันว่า pattern นี้เกิดขึ้นได้กับ homebrew ทุกคลาส ไม่จำกัดแค่คลาส official
5. **Companion-command pattern (Houndmaster) ยืนยันตัวเองผ่าน cross-reference ตรงๆ กับ Ranger's Beast Master ใน old scorecard** — เป็นครั้งแรกที่ old scorecard เขียนอ้างอิงคลาสอื่นข้ามไฟล์แบบชัดเจน ("เทียบเคียง precedent ของ Beast Master ที่ Ranger") ยืนยันว่า pattern การให้เครดิต Action Economy ผ่านคำสั่ง companion ด้วย bonus action มีความสม่ำเสมอสูงมากทั้งระบบ
6. **Rōnin's Killing Stroke ยังคงเป็น pattern "reaction-ตีก่อนแทนที่จะยกเลิก" ที่แยกจาก cancel-the-hit** — คนละกลไกกับ Rōnin's ตัวเองใน Gunslinger (ที่มี Killing Stroke แบบ cancel-the-hit จริง) ยืนยันว่าชื่อฟีเจอร์ซ้ำกันข้ามคลาสไม่ได้แปลว่ากลไกเหมือนกันเสมอไป — ต้องอ่าน text จริงทุกครั้ง
