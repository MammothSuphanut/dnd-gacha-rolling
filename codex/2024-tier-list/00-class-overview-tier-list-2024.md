# Class Overview Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: เทียบ **ทุก class** ในสารบัญ [class-subclass-index.md](../General/class-subclass-index.md) แบบ class-ต่อ-class (ไม่นับ 3 sidekick class เพราะไม่มีโครงสร้าง subclass/power scaling แบบ PC class) รวม 28 class เดิม + **Aura Knight** (homebrew ใหม่ของโปรเจกต์นี้) = 29 class
**แหล่งข้อมูล**: [class-subclass-index.md](../General/class-subclass-index.md), tier list รายคลาสทั้งหมดใน [2024-tier-list/](.) (โดยเฉพาะบรรทัด "กลไกคลาสหลัก"/"จุดสังเกต" ของแต่ละไฟล์), ความรู้ทั่วไปเรื่อง 5e 2024 สำหรับ 13 class official
**หมายเหตุสำคัญ**: นี่คือการประเมิน **ระดับ chassis ของทั้ง class** (ไม่ใช่ subclass) — ไม่ได้จำลอง DPR ทุกเลเวลแบบละเอียดเหมือนไฟล์ subclass ต่อคลาส เป็นการสังเคราะห์จากกลไกหลัก + จุดแข็ง/จุดอ่อนของ subclass pool แต่ละคลาสที่มีอยู่แล้วในโปรเจกต์ ถือเป็นไกด์คร่าวๆ ไม่ใช่ผลจำลองทางคณิตศาสตร์ที่แม่นเป๊ะ — ใช้ประกอบการตัดสินใจ ไม่ใช่กฎตายตัว

D&D 2024 ตั้งใจออกแบบให้ **chassis พื้นฐานของทุก class ค่อนข้างสมดุลกัน** (ต่างจาก 2014 ที่ Fighter/Wizard ห่างชั้นกันชัดเจน) — จุดอ่อน/จุดแข็งเด่นชัดส่วนใหญ่จึงอยู่ที่ **ระดับ subclass** มากกว่าตัว class เอง เพราะแบบนี้ลิสต์นี้เลย**ไม่มี C/D tier** — ไม่มี class ไหนอ่อนจนต้องเตือนเป็นพิเศษในระดับ chassis

## S Tier — Ceiling สูงสุด ยืดหยุ่นรอบด้านที่สุด

### Wizard 🔵 — Arcane generalist
- **จุดเด่น**: Spell list กว้างที่สุดในเกม + Ritual Casting + Spellbook เปลี่ยนคาถาประจำวันได้อิสระ ปรับตัวได้ทุกสถานการณ์ไม่มีจุดอ่อน
- **จุดด้อย**: HP ต่ำสุดในกลุ่ม caster ต้องพึ่ง positioning/party support เพื่อเอาตัวรอด

### Cleric 🔵 — Divine generalist/support
- **จุดเด่น**: Heal+damage+utility ครบในตัวเดียว, เลือก Domain ปรับ role ได้กว้างสุดในกลุ่ม caster ทั้งหมด
- **จุดด้อย**: ต้องเลือก Domain ให้ตรงกับแคมเปญ ไม่งั้นเสีย niche บางด้านไปทั้งเกม

### Druid 🔵 — Shapeshifter/full caster hybrid
- **จุดเด่น**: Wild Shape ให้ tank/scout/utility เพิ่มแยกอิสระจาก spell slot เท่ากับได้ "สอง class ในตัวเดียว"
- **จุดด้อย**: ต้องบริหาร 2 ระบบ (caster + shape) พร้อมกัน ซับซ้อนกว่า caster เพียวตัวอื่น

## A Tier — แรง/มั่นคงสูง ไม่มีจุดอ่อนเด่นชัด

### Bard 🔵 — Support/utility all-rounder
- **จุดเด่น**: Magical Secrets + Jack of All Trades ครอบคลุมทุก pillar (combat/exploration/social) — ไม่มีสายไหนเป็น dead weight ([bard-subclass-tier-list-2024.md](bard-subclass-tier-list-2024.md))
- **จุดด้อย**: damage เดี่ยวไม่โดดเด่นเท่า blaster caster โดยตรง

### Sorcerer 🔵 — Nova blaster
- **จุดเด่น**: Metamagic ปรับ spell ได้ยืดหยุ่นสุด (Twin/Quicken/Heighten) ดันดาเมจ/ควบคุมเกินสเปกปกติของ level slot
- **จุดด้อย**: Spell list แคบกว่า Wizard, ต้องบริหาร Sorcery Points ให้ดีถึงจะได้ของ

### Paladin 🔵 — Smite tank/striker hybrid
- **จุดเด่น**: Divine Smite burst + half-caster utility + tank chassis ครบเครื่อง ทุก Oath official จัดว่าสมดุลกันดีมาก ([paladin-subclass-tier-list-2024.md](paladin-subclass-tier-list-2024.md))
- **จุดด้อย**: ต้องเข้าประชิดก่อนถึงจะปล่อยพลังหลักได้เต็มที่

### Warlock 🔵 — Short-rest nova caster
- **จุดเด่น**: Eldritch Blast+Invocation ให้ damage/utility คงที่ทุกเทิร์นแม้ slot น้อย, Pact Boon เปลี่ยน playstyle ได้ทั้งหมด
- **จุดด้อย**: Slot น้อยมาก พึ่ง short rest บ่อย ถ้าแคมเปญไม่ค่อยมี short rest จะอึดอัด

### Necromancer 🔴 — Minion/sustained damage caster
- **จุดเด่น**: Charnel Touch เป็นทั้ง attack และทรัพยากรกลาง + Thralls เพิ่มกำลังพลถาวร, trigger-on-damage ดันดาเมจสะสมได้สูง
- **จุดด้อย**: ต้องบริหาร minion หลายตัวพร้อมกัน เพิ่มภาระ bookkeeping ต่อเทิร์นเยอะ

### Witch 🟢 — Familiar-bond full caster
- **จุดเด่น**: full caster + Hex เฉพาะทางต่อ craft ให้เลือกธีมเวทมนตร์ได้อิสระมาก ครอบคลุม role หลากหลาย
- **จุดด้อย**: พลังส่วนใหญ่ผูกกับ Familiar ถ้าโดนฆ่ากลางไฟต์เสียเปรียบทันที

### Channeler 🟢 — Gish full caster (subclass ตั้งแต่ lv1)
- **จุดเด่น**: เลือก Portal Key ตั้งแต่เลเวล 1 กำหนดทั้งสไตล์ต่อสู้+ธีมคาถาพร้อมกัน ได้ identity ชัดเร็วกว่า full caster ทั่วไปที่ต้องรอเลเวล 2-3
- **จุดด้อย**: เลือกผิดตั้งแต่ lv1 แก้ยาก ไม่มี retrain ง่ายๆ แบบ subclass ที่เลือกทีหลัง

### Mystic 🟣 (UA — ยังไม่ผ่าน balance รอบสุดท้าย) — Psionic point-based caster
- **จุดเด่น**: Psi Point เดียวขับเคลื่อน Discipline หลากหลาย ยืดหยุ่นสูงมาก ปรับ role ได้ทุกไฟต์
- **จุดด้อย**: เป็น playtest material ความสมดุลไม่นิ่งเท่า class ที่พิมพ์จริง ควรคุย DM ก่อนใช้เสมอ

### Dancer 🟢 — Companion/control hybrid
- **จุดเด่น**: Dance Style เปิด companion/control ที่ทรงพลัง เป็น pattern ที่อยู่ tier บนสุดซ้ำหลาย class ในโปรเจกต์ ([dancer-subclass-tier-list-2024.md](dancer-subclass-tier-list-2024.md))
- **จุดด้อย**: ต้องคง Dance (สเตตแบบ rage) ไว้ตลอดถึงจะได้ประโยชน์เต็มที่ หลุดสเตตแล้วอ่อนลงทันที

### Aura Knight 🟡 (Homebrew ใหม่ของโปรเจกต์นี้) — Alignment-locked Aura striker/tank
- **จุดเด่น**: Aura Technique ให้ output คุมได้แม่นยำ (จ่าย Aura เท่าไหร่ได้ผลเท่านั้น ไม่มีองค์ประกอบสุ่ม, ไม่มีระบบ rank/อัพเกรดให้ยุ่งยากอีกแล้ว) + Domain (lv17) เป็น capstone-tier control ที่แรงจริง + Clarity Aura ให้ utility นอกคอมแบต (guarantee skill check) โดยแลกกับ Aura ก้อนเดียวกับที่ใช้ต่อสู้ + Aura Surge (lv1, ใช้ได้ 1 ครั้ง/short rest แล้วเพิ่มเป็น 4 ครั้ง/short rest ตาม Aura Upgrade I-III) เติม Aura เพิ่มเท่า WIS mod ทุกครั้งที่ใช้ BA แปลง slot ผูก WIS ให้มีค่าจริงและปิด gap "งบ Aura ทั้งวันบางไป" ได้ต่อเนื่องกว่าระบบเดิมที่ผูกกับ initiative
- **จุดด้อย**: ไม่มี Extra Attack เลยตลอด class และยังไม่มี spellcasting จริงแม้แต่น้อย — utility ที่มีจำกัดแค่ skill check ไม่ครอบคลุมกว้างเท่า utility spell ของ Paladin/Ranger, alignment lock (Lawful only) เป็นความเสี่ยงเชิงปฏิบัติที่ class อื่นไม่มี (พังทั้ง kit ถ้า alignment เปลี่ยนจริง) ([Aura-Knight.md](../../homebrew-subclass/Aura-Knight/Aura-Knight.md))

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Fighter 🔵 — DPR consistency king
- **จุดเด่น**: Extra Attack เร็วสุด + ASI เยอะสุด + Action Surge ให้ DPR เดี่ยวสูงสุดในกลุ่ม martial แบบไม่ต้องพึ่ง resource
- **จุดด้อย**: แทบไม่มี utility นอกคอมแบต ต้องพึ่ง subclass เติมเต็มเกือบทั้งหมด

### Ranger 🔵 — Hybrid skirmisher (buffed 2024)
- **จุดเด่น**: 2024 ปรับสมดุลใหม่ ได้ spell/utility ใช้งานจริง ไม่ใช่แค่ "Fighter ที่มีเวทมนตร์แถม" เหมือน 2014
- **จุดด้อย**: ยังไม่ถึงระดับ full caster ด้าน utility เทียบ Druid/Cleric

### Barbarian 🔵 — Tank/damage frontline
- **จุดเด่น**: Rage ให้ resistance+damage คงที่ทุกไฟต์ ไม่ต้องบริหาร resource ซับซ้อน
- **จุดด้อย**: ปลายเกมตันกว่า caster ชัดเจน, บาง homebrew subclass (เช่น Rage Mage) แรงเกิน baseline ([barbarian-subclass-tier-list-2024.md](barbarian-subclass-tier-list-2024.md))

### Rogue 🔵 — Skill/utility specialist
- **จุดเด่น**: Expertise+skill utility ดีที่สุดในเกม, Cunning Action ให้ mobility/stealth สูง
- **จุดด้อย**: Sneak Attack ดาเมจต่อเทิร์นต่ำสุดในกลุ่ม martial ถ้าไม่มี advantage/ally ช่วย

### Monk 🔵 — Mobile martial artist (buffed 2024)
- **จุดเด่น**: 2024 ปรับ unarmed die/Ki ให้ใช้ง่ายขึ้นเยอะ, mobility สูงสุดในกลุ่ม martial
- **จุดด้อย**: ยัง MAD (DEX+WIS+CON) และดาเมจต่อฮิตต่ำกว่า weapon-based martial

### Artificer 🔵 — Utility/gadget half-caster
- **จุดเด่น**: Infusion ให้ magic item แบบไม่ต้องหาของจริง, Tool Expertise ครอบคลุม utility check แทบทุกด้าน
- **จุดด้อย**: Damage/combat impact ตามหลัง half-caster อื่น (Paladin/Ranger) ชัดเจน

### Captain 🟢 — Maneuver/companion leader
- **จุดเด่น**: Battle Dice+Maneuver แบบ Battle Master + Cohort companion เสริมกำลังพลได้จริง
- **จุดด้อย**: ต้องบริหาร Battle Dice ให้ดี ใช้ผิดจังหวะจะหมดเร็ว

### Gunslinger 🟢 — Ranged maneuver martial
- **จุดเด่น**: Risk Die เสี่ยงแลกแรง ให้ ceiling สูงกว่า martial ปกติถ้าเล่นเป็น
- **จุดด้อย**: ต้องพึ่งระยะยิง ถ้าโดนบังคับเข้าประชิดเสียเปรียบทันที

### Vagabond 🟢 — Skirmisher (แชร์ pool กับ Captain/Gunslinger)
- **จุดเด่น**: แชร์ subclass คุณภาพเดียวกับ Captain/Gunslinger 17/18 สาย มีแค่ Mage Brand ที่เป็นของตัวเองแท้ๆ
- **จุดด้อย**: identity เฉพาะตัวของ class เองค่อนข้างบาง เพราะพลังหลักมาจาก subclass ที่แชร์กับ class อื่น

### Craftsman 🟢 — Crafting support/utility
- **จุดเด่น**: Masterwork weapon/armor ให้ item power-up ถาวรที่ class อื่นไม่มี เสริม party ได้ทั้งตัวเองและคนอื่น
- **จุดด้อย**: ต้องมีเวลา/materials คราฟต์นอกไฟต์ ถ้าแคมเปญเร่งรีบจะเสียประโยชน์

### Warden 🟢 — Tank/control specialist
- **จุดเด่น**: Guardian Tactics (Block/Challenge/Grasp) ล็อกเป้าหมายและปกป้องทีมได้ตรงจุดสุดในกลุ่ม tank
- **จุดด้อย**: บทบาทเดี่ยวชัดมาก (tank-control) ยืดหยุ่นน้อยกว่า class อื่นถ้าปาร์ตี้ไม่ต้องการ tank

### Investigator 🟢 — Detective/ritual caster hybrid
- **จุดเด่น**: Trinkets+Grimoire ให้ utility นอกคอมแบตกว้างมาก เหมาะแคมเปญสายสืบสวน
- **จุดด้อย**: ประโยชน์เอียงไปทาง exploration/social มากกว่า combat ตรงๆ

### Monster Hunter 🔴 — Specialist hunter
- **จุดเด่น**: ทุก Guild ออกแบบตรงธีม "ล่ามอนสเตอร์" ชัดเจน ไม่มีสายไหนหลุด theme หรืออ่อนชัด ([monster-hunter-subclass-tier-list-2024.md](monster-hunter-subclass-tier-list-2024.md))
- **จุดด้อย**: เป็น class เล็ก (subclass น้อยสุดอันดับ 2) และ niche เฉพาะภารกิจล่ามอนสเตอร์

### Alchemist 🟢 — Bomb/support blaster
- **จุดเด่น**: Bomb+Reagents+Formula ปรับ damage type/เอฟเฟกต์ได้ยืดหยุ่นเหมือน caster ทั้งที่เป็น martial-adjacent
- **จุดด้อย**: Reagents เป็นทรัพยากรจำกัด ใช้ผิดจังหวะจะหมดเร็วเหมือน caster ที่ slot หมด

### Martyr 🟢 — Self-sacrifice support/tank
- **จุดเด่น**: ใช้ radiant damage ใส่ตัวเองแทน rest เป็นทรัพยากรรีเซ็ตเร็วกว่า class อื่นทั้งหมด ไม่ต้องรอ short/long rest
- **จุดด้อย**: ทุกฟีเจอร์แลกด้วย HP ตัวเอง เล่นผิดจังหวะเสี่ยงตายเองได้ง่ายกว่า class อื่น

### Warmage 🟢 — Generalist cantrip caster
- **จุดเด่น**: full caster ที่เน้น cantrip แข็งแรง ไม่ต้องพึ่ง slot ก็ sustain damage ได้ตลอดวัน, 2 house (Kings/Knights) ผลักเป็น gish เต็มตัวได้
- **จุดด้อย**: House ส่วนใหญ่ "เสริมพลังทั่วไป" ไม่มีกิมมิกเด่นเทียบ full caster อื่นในลิสต์นี้ ([warmage-subclass-tier-list-2024.md](warmage-subclass-tier-list-2024.md))

## สรุปตำแหน่งเทียบ Aura Knight

Aura Knight อยู่ **A tier** — ยืนยันอีกครั้งหลังปรับใหญ่ทั้ง class ในรอบนี้ (ตัดระบบ rank/อัพเกรดทิ้งทั้งหมดให้ technique มีค่าคงที่ตัวเดียว, ปรับ proficiency ให้ผูกกับ Path จริงจัง — Retribution ได้ Twin Blade Stance dual-wield, Guardian ได้ heavy armor+shield, เพิ่ม Aura Surge lv1 แก้ปัญหางบ Aura ทั้งวัน):
- **Combat consistency**: ไม่ต้องรอชาร์จหลายเทิร์นอีกต่อไปตั้งแต่ต้นไฟต์ (Aura Upgrade) และตอนนี้ไม่ขาดแคลนตลอดทั้งวันด้วย (Aura Surge ให้ Aura เพิ่มเท่า WIS mod ทุกครั้งที่ใช้ BA แปลง slot ใช้ได้ 1→4 ครั้ง/short rest ตาม Aura Upgrade I-III — งบรวมวันมาตรฐาน สมมติ 2 short rest/วันกับ WIS mod ทั่วไป เพิ่มจาก ~47→71 ที่ lv11 และ ~89→129 ที่ lv20, ดูรายละเอียดสมมติฐานที่ [Aura-Knight.md](../../homebrew-subclass/Aura-Knight/Aura-Knight.md))
- **Multi-pillar utility**: มี utility นอกคอมแบตจริง (การันตี skill check ได้ผ่าน Clarity Aura) แม้ไม่ใช่ spellcasting — จับคู่ใกล้เคียง **Paladin** มากขึ้น (combat burst + utility ที่ต้องแลกด้วย resource เดียวกัน ไม่ใช่ของแถมฟรี)
- **Nova ceiling ที่ตรวจสอบแล้ว**: technique สายดาเมจ (Light Sword, Sun Slash) ไม่มี cap และ "เก็บ Aura หลายเทิร์นแล้วเทลงตาเดียว" ทำได้จริงเพราะแปลง Aura ใช้แค่ Bonus Action — แต่คำนวณแล้วดาเมจรวมทั้งไฟต์เท่าเดิมไม่ว่าจะกระจายจ่ายหรือเก็บมาเทตาเดียว (อัตราแลกเปลี่ยนเชิงเส้น 1:1 คงที่) แค่เปลี่ยนจังหวะเท่านั้น ไม่ใช่การปั๊มดาเมจเกินงบ — ความเสี่ยงพลาดการโจมตีครั้งเดียวก็ถ่วงดุลการ nova ไว้ในตัวอยู่แล้ว ไม่ต้องเติม cap เทียม

ยังไม่ใช่ S เพราะ utility ที่มีแคบกว่า full caster จริง (จำกัดแค่ skill check ไม่ครอบคลุม exploration/social แบบ spell เช่น Teleport/Scrying) และมี alignment lock เป็นความเสี่ยงเชิงปฏิบัติที่ full caster ไม่ต้องแบก — ตำแหน่ง A เทียบเท่า Paladin/Warlock ถือว่าเหมาะสมกับ trade-off ที่ยังคงไว้
