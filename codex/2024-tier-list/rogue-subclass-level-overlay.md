# Rogue — Subclass Level Overlay (ชั้น 2)

**อ้างอิง**: [rogue-level-baseline.md](rogue-level-baseline.md) (Class Baseline, ชั้น 1) + [rogue-subclass-scorecard-2024.md](rogue-subclass-scorecard-2024.md) (แหล่งข้อมูล feature-text หลัก)
**ขอบเขต**: 19 Roguish Archetype — gate lv3/9/13/17 (ตรงกับ "(Rogue Subclass/Subclass feature — ยกเว้น)" ในตาราง Chassis ของ baseline)
**รูปแบบ**: delta-only แบบย่อ (>10 subclass) — list เฉพาะเลเวล/axis ที่เกรดต่างจาก baseline; ไม่ระบุ = เท่า baseline
**หมายเหตุสำคัญ**: baseline's **Utility=D-flat** (floor-lock เพราะไม่มีสเปลล์ แม้ Anchor จะเรียก Rogue เป็น "Utility specialist ตัวจริง") **พังทลายในไฟล์นี้อย่างกว้างขวาง — 13/19 subclass ขยับ Utility ได้** ตั้งแต่ full-spellcasting (Arcane Trickster/Sanguine Thief) ไปจนถึง toolkit ที่ไม่มีสเปลล์เลยแต่แน่นพอ (Thief's magic-item-kit, Shadow Master's stealth-kit) — ยืนยัน pattern เดียวกับ Fighter's "Utility floor 18/21 porous": floor-lock ล็อกแค่ chassis เปล่า ไม่ใช่ทุก subclass

**Baseline โดยสรุป**: Damage B(1-6)→A(7-16)→S(17-20) · Control D(1-4)→C(5-13)→B(14-20) · Support **D(1-20) flat** · Survivability C(1-6)→A(7-20) · Action Economy D(1-4)→B(5-20) · Utility **D(1-20) flat** ⚠️ · Versatility C(1-4)→A(5-20)

## Arachnoid Stalker (ValdaPlayerPack)

- **Damage**: B(1-2)→**A(3-16)** [S(17-20) เท่า baseline] — Venomous Strike (SA die ทั้งหมด d6→d8 poison ตั้งแต่ lv3, ดัน Magnitude เพิ่มตรงๆ)
- **Control**: D(1-2)→B(3-13)→**A(14-20)** — Webbing (cast Web ฟรี, lv3, hard-CC เร็วกว่า baseline 2 เลเวล) ซ้อนกับ Paralytic Venom(lv17, Cunning Strike option, Paralyzed จริง)
- **Utility**: D(1-2)→**A(3-20)** — Webbing(หลายประโยชน์)+Wall Crawling(lv9, climb+ซ่อนเพดาน+spider climb) = toolkit ครบเครื่องที่สุดในกลุ่ม

## Arcane Trickster (XPHB)

- **Control**: D(1-2)→C(3-8)→B(9-16)→**A(17-20)** — เข้าถึงสาย Wizard illusion/enchantment เต็มรูปแบบ+Magical Ambush(lv9)+Spell Thief(lv17)
- **Utility**: D(1-2)→C(3-8)→B(9-16)→**A(17-20)** — **Spellcasting เต็มรูปแบบ (Magnitude ปลดล็อกจริง)** = floor-lock พังตรงๆ

## Assassin (XPHB)

- **Damage**: B(1-2)→**A(3-6)** [rest เท่า baseline] — Assassinate (Advantage+extra dmg ทุกเป้าที่ยังไม่เทิร์นในรอบแรก) = "nova รอบแรกที่แรงที่สุดในกลุ่ม Rogue"

## ข้อค้นพบสำคัญ

1. **⚠️ Utility floor-lock ของ baseline พังทลายกว้างที่สุดเท่าที่เคยเจอในระบบนี้ — 13/19 subclass ขยับได้ (68%)** ตั้งแต่ full-spellcasting (Arcane Trickster/Sanguine Thief, escalation curve D→C→B→A เต็มรูปแบบ) ไปจนถึง non-spell toolkit ที่แน่นพอ (Arachnoid Stalker/Inquisitive/Shadow Master/Thief ได้ A แม้ไม่มีสเปลล์เลย) — ยืนยัน pattern เดียวกับ Fighter's "Utility floor 18/21 porous": floor-lock เป็นเรื่องของ chassis เปล่าเท่านั้น ไม่ใช่ทุก subclass ในคลาสที่มี Utility=D-flat
2. **"ปลด Conditionality requirement ของ Sneak Attack (ไม่ต้องพึ่ง Advantage)" เป็น pattern ที่เกิดซ้ำ 5 ครั้งและทุกครั้งดัน Damage B→A เร็วขึ้นเป็น lv3** (Assassin's Assassinate, Highway Rider's Ride Them Down, Inquisitive's Insightful Fighting, Scion's Bloodthirst-adjacent, Shadow Master's Release Shadow, Soulknife's Psychic Blades) — ยืนยันว่า baseline's เอง flag ไว้ตรงๆ ว่า Conditionality คือ modifier ที่ต่ำกว่า peer ตลอด และเป็นจุดแรกที่ subclass ส่วนใหญ่เลือกอุดก่อน
3. **Sanguine Thief's Bloody Exit เป็น "cancel-the-hit" ตัวที่ 3 ในระบบนี้** (ต่อจาก Gunslinger's Rōnin/Ranger's Nomad) — reaction ที่ทำให้การโจมตีพลาดอัตโนมัติ ดัน Survivability ข้าม ceiling A ที่มั่นคงของ baseline ไปถึง S
4. **Thief's Reflexes (lv17, สองเทิร์นเต็มในรอบแรก) เป็นกลไก Action Economy ที่แรงที่สุดในไฟล์นี้** — ดัน Thief ข้าม baseline's B-ceiling ไปถึง S ตัวเดียวในกลุ่มที่ได้ S ผ่าน "extra full turn" ไม่ใช่แค่ extra action/bonus-action-reinforcement
5. **Sanguine Thief/Soulknife ทั้งคู่มี "pool เดียวป้อนหลาย axis พร้อมกัน" แต่ถูกจำกัดที่ A ไม่ใช่ S สำหรับ Versatility** (ตาม precedent จาก Necromancer's Necrodancer และ Ranger's Hollow Warden/Winter Walker) — ยืนยันว่า cross-axis-density-single-mechanism cap อยู่ที่ A เสมอ เว้นแต่จะเป็น full-dual-magic-system แบบ Mystic's Wu Jen ที่ยังเป็นเคสเดียวที่ได้ S
6. **6/19 subclass ไม่ได้ delta ใดๆ เลยในบาง axis สำคัญเพราะ old scorecard ระบุ "เท่า/ใกล้เคียง baseline" ตรงๆ** (Grifter 0-delta ทุกแกน, Damage ของ Enforcer/Phantom/Scout/Scion/Swashbuckler/Titan Slayer/Thief ตรง baseline พอดี) — ยืนยันว่าการอ่าน old scorecard ตรงๆ (ไม่ใช่แค่ดู delta number) เป็นเครื่องมือคัดกรองที่แม่นยำกว่าการดู old score เพียงอย่างเดียว
