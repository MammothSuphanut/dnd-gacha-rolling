# Investigator Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Investigator subclass ทั้งหมดในโปรเจกต์ — Valda's Spire ล้วน ยึด 2024 เป็นหลัก ทุกสายจาก 2014 มีเวอร์ชัน 2024 ครบ ไม่มี orphan (Infernal Agent'14 → Infernum'24 แค่เปลี่ยนชื่อ)
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, `Mage Hand Press; Valda's Spire of Secrets - 2024.json`
**กลไกคลาสหลัก**: **Trinkets** (ไอเทมความสามารถพิเศษ) + **Grimoire** (ritual-based casting) — Investigator เป็น class สายสืบสวน/นักล่าเหนือธรรมชาติ

## A Tier — พลิกเกมได้ชัดเจน

### Time Operative 🟢 — Extra action every turn
- **จุดเด่น**: Borrowed Time ให้ action เสริมทุกเทิร์น (Attack/Dash/Disengage/Hide/อื่นๆ) ได้ 2 ครั้ง/วัน เป็น action economy boost ระดับเดียวกับ Chronurgy Magic ของ Wizard
- **จุดด้อย**: จำกัดแค่ 2 ครั้ง/long rest ใช้หมดแล้วกลับไปเป็น investigator ปกติ
- **วิธีเล่น**: เก็บ Borrowed Time ไว้ใช้ตอนจังหวะสำคัญ (เปิดฉากไฟต์บอส/ปิดจ๊อบ) เพิ่มการโจมตี/หนีพิเศษ

### Medium 🟢 — Portent-style reroll
- **จุดเด่น**: Foretelling ทอย d20 สองลูกไว้ล่วงหน้าทุกเช้า แล้วแทนที่ผล d20 ของใครก็ได้ทีหลัง — กลไกเดียวกับ Portent ของ Divination Wizard ซึ่งจัดเป็นหนึ่งใน passive ที่แรงที่สุดในเกม
- **จุดด้อย**: ต้องเลือกใช้ก่อนเห็นผล d20 จริง (เหมือน Portent) เสี่ยงเก็บผิดจังหวะถ้าวางแผนไม่ดี
- **วิธีเล่น**: ทอย foretelling ทุกเช้าแล้วใช้แทนที่ save/attack/check สำคัญของตัวเองหรือศัตรูตามจังหวะวิกฤต

### Occultist 🟢 — Extra pact spellcasting layer
- **จุดเด่น**: Pact Magic เพิ่มระบบสเปลคาสติ้งแบบ warlock ซ้อนทับบน Grimoire ปกติ เป็นสายเดียวที่ได้ "สอง layer" ของคาถา เพิ่ม flexibility สูงมาก
- **จุดด้อย**: ต้องบริหารทั้ง pact slot และ grimoire ritual แยกกัน ซับซ้อนกว่า investigator สายอื่น
- **วิธีเล่น**: ใช้ pact magic เป็นคาถาต่อสู้หลัก ควบคู่กับ grimoire ritual สำหรับ utility/สืบสวนนอกคอมแบต

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Archivist 🟢 — Flexible spell thesis
- **จุดเด่น**: Thesis ให้เลือกกลุ่มคาถาเฉพาะทาง (Corpus/Mentis ฯลฯ) และเปลี่ยนได้ทุกครั้งที่เลื่อนเลเวล ยืดหยุ่นสูง
- **จุดด้อย**: ต้องวางแผนล่วงหน้าว่าจะเปลี่ยน thesis เมื่อไหร่ ไม่ใช่ปรับกลางไฟต์ได้ทันที
- **วิธีเล่น**: เลือก thesis ให้ตรงกับภารกิจ/แคมเปญปัจจุบัน แล้วสลับเมื่อสถานการณ์เปลี่ยนไปตามจังหวะเลเวลอัป

### Conspiracy Theorist 🟢 — Initiative reliability
- **จุดเด่น**: Paranoid Instincts ให้ advantage บน initiative ตลอดเวลา เพิ่มโอกาสได้เทิร์นก่อนศัตรูอย่างสม่ำเสมอ
- **จุดด้อย**: ไม่มีดาเมจ/utility เสริมโดยตรงนอกเหนือ initiative
- **วิธีเล่น**: ใช้ข้อได้เปรียบ initiative เปิดฉากไฟต์ก่อนเสมอ วางแผน control/debuff ก่อนศัตรูได้ตัวเลือก

### Detective 🟢 — Skill check booster
- **จุดเด่น**: Uncanny Hunch เพิ่มโบนัสให้ Int/Insight check เท่ากับเลเวล investigator ใช้ได้หลายครั้ง/วัน เป็น skill-monkey ที่แข็งมาก
- **จุดด้อย**: ประโยชน์เอียงไปทาง investigation/social ไม่มีดาเมจเสริมโดยตรง
- **วิธีเล่น**: ใช้ Uncanny Hunch การันตี success บน check สำคัญ (สืบเบาะแส/อ่านใจศัตรู) ตามจังหวะที่จำเป็น

### Exterminator 🟢 — Monster-hunting specialist
- **จุดเด่น**: Silvered Shield เสริมความสามารถล่ามอนสเตอร์เฉพาะทาง (aberration/fiend/undead) เหมาะแคมเปญสยองขวัญ/ล่าปีศาจ
- **จุดด้อย**: โบนัสเฉพาะกับประเภทมอนสเตอร์ที่กำหนด ศัตรูทั่วไป (มนุษย์/สัตว์) ไม่ได้ประโยชน์เต็มที่
- **วิธีเล่น**: ใช้เป็นตัวจัดการเฉพาะทางเมื่อเจอ aberration/fiend/undead พึ่งความสามารถพื้นฐานกับศัตรูทั่วไป

### Infernum 🟢 — Fiend familiar companion
- **จุดเด่น**: Fiendish Familiar ให้ Find Familiar ฟรีร่ายเร็วผ่าน Rushed Incantation เพิ่ม companion/utility โดยไม่เสีย resource มาก
- **จุดด้อย**: ธีมสัญญาปีศาจอาจไม่เข้ากับตัวละครฝ่ายธรรมะ ต้องปรับ flavor
- **วิธีเล่น**: เรียก familiar ปีศาจมาช่วยสอดแนม/เสริม utility ระหว่างสืบสวน ควบคู่กับบทบาทหลักของ investigator

### Inquisitor 🟢 — Anti-fiend combat specialist
- **จุดเด่น**: Exorcist's Doctrines เสริมการต่อสู้กับปีศาจ/สิ่งชั่วร้ายโดยเฉพาะ เหมาะบทบาท "นักล่าปีศาจ" เต็มตัว
- **จุดด้อย**: โบนัสเฉพาะทางกับปีศาจ/สิ่งลี้ลับ ศัตรูทั่วไปได้ประโยชน์น้อยกว่า
- **วิธีเล่น**: ใช้เป็นหัวหอกไฟต์บอสธีมปีศาจ/นอกรีต พึ่งความสามารถพื้นฐานกับศัตรูทั่วไป

### Kid Sleuth 🟢 — Animal familiar companion
- **จุดเด่น**: Animal Sidekick ให้ Find Familiar ฟรีร่ายเร็วเหมือน Infernum แต่เป็นสัตว์ธรรมดา เหมาะธีมสืบสวนสายอ่อนโยนกว่า
- **จุดด้อย**: กลไกใกล้เคียง Infernum มาก ต่างแค่ flavor ของ familiar
- **วิธีเล่น**: ใช้สัตว์คู่ใจสอดแนม/หาเบาะแสในที่ที่ตัวเองเข้าไม่ถึง เหมาะบทบาทนักสืบเด็ก/ผู้บริสุทธิ์

## C Tier — utility เฉพาะทาง/combat impact ต่ำ

### Antiquarian 🟢 — Resource booster
- **จุดเด่น**: Artifact Hoarder เพิ่มจำนวนครั้งใช้ Trinket ได้อีก 1 ครั้ง/วัน เสริมทรัพยากรพื้นฐานของคลาส
- **จุดด้อย**: เป็นแค่ resource booster ไม่มีฟีเจอร์เฉพาะตัวที่โดดเด่นเทียบสายอื่น
- **วิธีเล่น**: เลือกสายนี้ถ้าต้องการใช้ Trinket บ่อยกว่าปกติโดยไม่มีธีม/กิมมิกเฉพาะทางเพิ่ม

### Containment Specialist 🟢 — Social recovery
- **จุดเด่น**: Cover Story ให้แก้ตัวจากการโกหกที่ถูกจับได้ เป็น utility social ที่มีประโยชน์เฉพาะสถานการณ์
- **จุดด้อย**: ใช้ได้เฉพาะตอนโดนจับโกหก ไม่มีผลกระทบคอมแบตเลย
- **วิธีเล่น**: ใช้เป็นตัวช่วยตอน infiltration/สืบสวนที่เสี่ยงถูกจับได้ ไม่เหมาะเป็นตัวเลือกหลักถ้าเน้นคอมแบต

### Spy 🟢 — Social check booster
- **จุดเด่น**: Bravado เพิ่มโบนัส Deception/Persuasion ตาม Int modifier เสริม social encounter ได้ดี
- **จุดด้อย**: ไม่มีฟีเจอร์คอมแบต/utility อื่นเสริมเลยนอกจาก social check
- **วิธีเล่น**: ใช้เป็นตัวเจรจา/แทรกซึมหลักของปาร์ตี้ พึ่งความสามารถพื้นฐานของ investigator ในไฟต์

## สรุปเร็วตามบทบาท

| บทบาท | สายที่เด่นสุด |
|---|---|
| Action economy | Time Operative |
| Passive control (reroll) | Medium |
| สเปลคาสติ้งซ้อน 2 layer | Occultist |
| Skill/investigation | Detective, Conspiracy Theorist |
| Companion/familiar | Infernum, Kid Sleuth |
| Anti-monster เฉพาะทาง | Exterminator, Inquisitor |
| ยืดหยุ่นคาถา | Archivist |
| Social encounter | Spy, Containment Specialist |
| Resource booster ทั่วไป | Antiquarian |

**จุดสังเกต**: Medium เป็นอีกตัวอย่างที่ homebrew "ยืม" กลไก Portent จาก official Divination Wizard มาใช้ตรงๆ (คนละคลาสแต่ effect เดียวกัน) — ยืนยันแพทเทิร์นที่เจอซ้ำๆ ในลิสต์นี้ว่า passive reroll แบบ Portent มักถูกจัดเป็นหนึ่งในกลไกที่แรงที่สุดไม่ว่าจะอยู่ใน class ไหนก็ตาม
