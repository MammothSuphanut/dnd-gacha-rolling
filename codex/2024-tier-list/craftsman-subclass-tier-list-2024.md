# Craftsman Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Craftsman subclass (Guild) ทั้งหมดในโปรเจกต์ — Valda's Spire ล้วน ยึด 2024 เป็นหลัก ทุกสายจาก 2014 (10 guild) มีเวอร์ชัน 2024 ครบ ไม่มี orphan บวก Wintercarvers' Guild ที่เป็นสายใหม่เฉพาะ 2024
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, `Mage Hand Press; Valda's Spire of Secrets - 2024.json`
**กลไกคลาสหลัก**: Craftsman คือ class ช่างฝีมือที่คราฟต์ **Masterwork weapon/armor** เป็นพื้นฐาน แต่ละ Guild เพิ่มทิศทางการคราฟต์และของที่ได้ต่างกัน

## Legend
- 🟢 Valda's Spire

## S Tier — พลิกโครงสร้างคลาสได้เลย

### Mechanauts' Guild 🟢 — Pilot a mech
- **จุดเด่น**: สร้าง Mechanaut's Apparatus (รีสกิน Apparatus of the Crab) เป็นยานพาหนะ/mech ให้ขับขี่ พร้อม Cockpit Upgrade เลือกได้ ถือเป็น power spike ที่แรงกว่า companion ทั่วไปมาก เพราะแทบจะเปลี่ยนตัวละครเป็นครีเจอร์ตัวใหญ่ทั้งตัว
- **จุดด้อย**: ต้องมีพื้นที่ให้ mech เข้าถึง (ดันเจี้ยนแคบใช้ยาก); การขับ mech อาจดึงตัวเองออกจาก action ปกติของ Craftsman บางส่วน
- **วิธีเล่น**: ขับ Mechanaut's Apparatus เข้าไฟต์ใหญ่/บอสไฟต์เป็นหลัก ใช้ HP/ดาเมจของ mech แทนตัวเองในช่วงวิกฤต

## A Tier — พลิกเกมได้ชัดเจน

### Clockworkers' Guild 🟢 — Double companion
- **จุดเด่น**: ได้ Clockwork Construct **สองตัวพร้อมกัน** (เลือก Bolter หรือ Macer ต่อตัว) เพิ่ม action economy เท่าตัวเทียบ companion class ทั่วไปที่ได้แค่ 1 ตัว; Mechanical Arm เสริม utility ให้ตัวเองถืออาวุธ/โล่เพิ่ม
- **จุดด้อย**: ต้องเสียเวลา long rest ประกอบ construct ก่อน ถ้า construct ตายกลางไฟต์ต้องรอพักถึงจะได้กลับมา
- **วิธีเล่น**: ปล่อย construct ทั้งสองลุยคู่กันตลอดไฟต์ (Bolter ระยะไกล/Macer ประชิด) ตัวเองอยู่หลังคุมสถานการณ์

### Bladeworkers' Guild 🟢 — Melee reliability + damage
- **จุดเด่น**: Weapon Versatilist ให้ advantage การโจมตีฟรีต่อประเภทอาวุธ (รีเซ็ตทุก long rest); Bane Weapons เพิ่มดาเมจเสริมต่อประเภทครีเจอร์เฉพาะ ปรับตัวได้ตามศัตรูที่เจอ
- **จุดด้อย**: Weapon Versatilist ใช้ได้ 1 ครั้งต่อประเภทอาวุธต่อการพัก ถ้าถืออาวุธเดียวตลอดจะใช้ advantage ได้ไม่บ่อย
- **วิธีเล่น**: เปลี่ยนรูนบนอาวุธก่อนบุกดันเจี้ยนตามประเภทศัตรูที่คาดว่าจะเจอ แล้วใช้ advantage ฟรีเปิดฉากไฟต์สำคัญ

### Armigers' Guild 🟢 — Armor tank
- **จุดเด่น**: +3 AC จากโล่ (แทน +2 ปกติ) เพิ่ม AC พื้นฐานถาวร; Armored Slam ให้ล้มศัตรูฟรีแทนการโจมตีปกติ 2 ครั้ง/พัก เสริม control ให้แทงค์
- **จุดด้อย**: ต้องถือโล่ตลอดเวลาถึงจะได้ AC bonus เสีย build ทางเลือกสำหรับ two-handed weapon
- **วิธีเล่น**: ถือโล่+อาวุธมือเดียวยืนแนวหน้า ใช้ Armored Slam ล้มศัตรูอันตรายก่อนให้ทีมรุมจัดการ

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Calibarons' Guild 🟢 — Ranged reliability
- **จุดเด่น**: Zeroed Sights เจาะ cover ได้ (half/three-quarters) เพิ่มโอกาสโดนจากระยะไกลมาก; Exotic Ammunition สร้างกระสุนพิเศษฟรีทุก long rest
- **จุดด้อย**: ต้องใช้ Masterwork weapon เฉพาะทางถึงจะได้ประโยชน์เต็มที่ ไม่ generic เท่า Bladeworkers
- **วิธีเล่น**: ยิงเจาะ cover ของศัตรูที่หลบซ่อนได้ตรงๆ ไม่ต้องเสียเปรียบจากภูมิประเทศเหมือน ranged build ทั่วไป

### Forgeknights' Guild 🟢 — Fire weapon utility
- **จุดเด่น**: Portable Forge ให้คราฟต์ได้ทุกที่ไม่ต้องพึ่งร้าน; Explosive Armory (lv6) เพิ่ม property ระเบิดให้อาวุธไฟ เสริม AoE damage
- **จุดด้อย**: ธีมไฟจำกัดเฉพาะอาวุธที่ทำดาเมจไฟ ศัตรู resist ไฟจะลดประโยชน์ลง
- **วิธีเล่น**: ดัดแปลงอาวุธหลักให้ทำดาเมจไฟ+ระเบิด ใช้เป็นดาเมจ AoE เสริมนอกเหนือการตีปกติ

### Thunderlords' Guild 🟢 — Lightning weapon utility
- **จุดเด่น**: Electric Armory (lv6) เพิ่ม property ไฟฟ้าให้อาวุธได้แม้ไม่ใช่อาวุธไฟฟ้าเดิม ยืดหยุ่นกว่า Forgeknights เพราะไม่ผูกกับ damage type เดิมของอาวุธ
- **จุดด้อย**: ต้องมี Power Cell ที่อาจเสียหาย/ต้องซ่อมด้วยทรัพยากร (100+ GP) เป็นภาระด้าน economy
- **วิธีเล่น**: เติม Jolt property ให้อาวุธหลักไม่ว่าจะเป็นอาวุธประเภทไหน เสริมเอฟเฟกต์ไฟฟ้าได้อเนกประสงค์กว่าธีมไฟ

### Trappers' Guild 🟢 — Trap control + defense
- **จุดเด่น**: Traps ให้วางกับดักได้เป็นระบบ (control พื้นที่); Danger Sense ให้ advantage บน Dex save แทบตลอดเวลา เสริมความอยู่รอดจาก AoE
- **จุดด้อย**: การวางกับดักต้องใช้เวลาเตรียมล่วงหน้า ใช้กะทันหันกลางไฟต์ได้จำกัด
- **วิธีเล่น**: วางกับดักรอบจุดที่คาดว่าศัตรูจะผ่าน ก่อนล่อให้เข้ามาติดกับ แล้วใช้ Danger Sense ป้องกันตัวเองจาก AoE ที่ตามมา

### Wintercarvers' Guild 🟢 — Flexible ice crafting
- **จุดเด่น**: Ice Sculpting สร้างอาวุธ/ของใช้จากน้ำแข็งได้ทันทีด้วย action เดียว ยืดหยุ่นสูง (สร้างอาวุธใหม่กลางไฟต์ได้ถ้าจำเป็น) เสริม cold damage ให้อาวุธด้วย
- **จุดด้อย**: ของที่สร้างเป็นน้ำแข็งอาจละลาย/แตกง่ายในสภาพแวดล้อมร้อน ต้องคำนึงถึงบริบท
- **วิธีเล่น**: สร้างอาวุธน้ำแข็งเฉพาะกิจกลางไฟต์เมื่ออาวุธหลักเสีย/ไม่เหมาะกับสถานการณ์ เสริมดาเมจ cold ให้ทะลุ resistance ประเภทอื่น

### Arcane Maesters' Guild 🟢 — Magic item crafting + wizard cantrips
- **จุดเด่น**: คราฟต์ magic item ได้ตรงตามตาราง (utility นอกคอมแบตสูง); ได้ True Strike + cantrip wizard เสริม 2 ตัวฟรี เพิ่มออปชันคาถาให้ class ที่ปกติไม่มีสเปลคาสติ้ง
- **จุดด้อย**: cantrip ที่ได้จำกัดปริมาณ ไม่ได้ทำให้กลายเป็น caster เต็มตัว; การคราฟต์ magic item ต้องใช้เวลา/ทรัพยากรเยอะ เอียงไปทาง downtime
- **วิธีเล่น**: ใช้ cantrip เสริมความยืดหยุ่นระหว่างไฟต์ แล้วพึ่งการคราฟต์ magic item เป็นตัวเสริมพลังปาร์ตี้ระยะยาวนอกคอมแบต

## C Tier — utility เฉพาะทาง/combat impact ต่ำ

### Courtiers' Guild 🟢 — Social/fashion utility
- **จุดเด่น**: Fashionable + Cosmetic Enchantments เสริม social encounter/skill check ที่เกี่ยวกับภาพลักษณ์ได้ดี เหมาะแคมเปญที่เน้นเมือง/ราชสำนัก
- **จุดด้อย**: ไม่มีฟีเจอร์ดาเมจ/แทงค์/utility คอมแบตที่ชัดเจนเลยเทียบ guild อื่นทั้ง 10 สาย
- **วิธีเล่น**: ใช้เป็นตัวเสริมบทบาท social/การเจรจาของปาร์ตี้ พึ่งอาวุธ Masterwork พื้นฐานของ Craftsman เป็นดาเมจหลักในไฟต์

## สรุปเร็วตามบทบาท

| บทบาท | guild ที่เด่นสุด |
|---|---|
| Vehicle/mech power spike | Mechanauts' Guild |
| Companion/action economy | Clockworkers' Guild |
| Melee damage/reliability | Bladeworkers' Guild |
| Tank/AC | Armigers' Guild |
| Ranged reliability | Calibarons' Guild |
| Elemental weapon utility | Forgeknights' Guild, Thunderlords' Guild, Wintercarvers' Guild |
| Control พื้นที่ | Trappers' Guild |
| Magic item crafting | Arcane Maesters' Guild |
| Social/roleplay | Courtiers' Guild |

**จุดสังเกต**: Mechanauts' Guild เป็นตัวอย่างชัดว่า Valda's Spire บางสายไม่ได้แค่ "ปรับกลไกเดิม" แต่เพิ่ม "ประเภทความสามารถใหม่" ให้ทั้งคลาส (ขับ mech) คล้ายกับ Dynamo Engineer ของ Alchemist ที่เพิ่มสเปลคาสติ้งให้ — pattern นี้มักเป็นตัวที่แรงที่สุดในแต่ละ class เพราะไม่ใช่แค่ modify baseline แต่เปิด playstyle ใหม่ทั้งหมด
