# Witch — Subclass Level Overlay (ชั้น 2)

**อ้างอิง**: [witch-level-baseline.md](witch-level-baseline.md) (Class Baseline, ชั้น 1) + [witch-subclass-scorecard-2024.md](witch-subclass-scorecard-2024.md) (แหล่งข้อมูล feature-text หลัก)
**ขอบเขต**: 13 subclass — gate lv3/6/10/14 (มาตรฐาน Witch) — ทั้งหมดเป็น ValdaSpire24/24Extras 2024-native ไม่มีตัวไหนเป็น 2014-only orphan
**รูปแบบ**: delta-only แบบย่อ (>10 subclass) — list เฉพาะ axis/เลเวลที่เกรดเปลี่ยนจาก baseline เท่านั้น ไม่ระบุ = เท่า baseline

**Baseline โดยสรุป**: Damage B(1-20) flat · Control B(1-19)→S(20) · Support C(1-20) flat · Survivability C(1-20) flat · Action Economy D(1-8)→C(9-17)→B(18-20) (**tie-break 2-2 ที่ lv9-17** ครั้งที่ 25 ในระบบ — Bonus Action+Hastened Hex=เหนือ vs Reaction+Extra Action=ต่ำ) · Utility B(1-20) flat · Versatility C(1)→B(2-20)

## Black Magic (ValdaSpire24)

- Damage: **A(14-20)** — Grim Sacrifice (สังเวย familiar เป็น AoE 8d10 Necrotic, refill ด้วย slot)
- Survivability: **B(10-20)** — Life Tether (reaction โอนครึ่งดาเมจไปเป้าที่ Hex ไว้)
- Action Economy: **B(10-20)** — Undeath Command (สั่ง familiar+undead ทั้งหมดด้วย bonus action เดียว) เป็น flip ใหม่ที่พลิก tie-break lv9-17

## Blood Magic (ValdaSpire24)

- Damage: **S(14-20)** — Sanguine (แลก HP เป็นดาเมจ Necrotic สูงสุด 6d8) ซ้อน Arcane Bloodletting
- Action Economy: **A(3-20)** — Arcane Bloodletting (แลกดาเมจเปลี่ยน casting time action→bonus action) = ตัวคูณ action ที่แรงสุดในคลาส — cast คาถาได้ 2 ครั้ง/เทิร์นจริง
- Utility: **A(3-20)** — Deathseeker (ตรวจจับเป้าบาดเจ็บ/มองทะลุ Invisible 60ft+Adv tracking)

## Blue Magic (ValdaSpire24Extras)

- Damage: **A(14-20)** — Cerulean Reflection (reaction redirect คาถาที่ save ผ่านไปเป้าใหม่)
- Control: **A(3-20)** — Blue Magic Duplication (เตรียมคาถาอะไรก็ได้ที่เคยโดนใส่ รวม control spell ศัตรู)
- Survivability: **B(6-20)** — Turquoise Efficiency (lv6, Adv save คาถาเตรียมไว้+คืน slot ถ้า save ผ่าน)
- Action Economy: **A(3-20)** — Duplication/Cerulean Reflection ทั้งหมดเป็น Reaction ไม่เสีย action หลัก
- Utility: **A(3-9) → S(10-20)** — Copycat(lv10, ขโมย skill/save prof reactively)+Arcane Awareness+Duplication = กว้างที่สุดในคลาส
- Versatility: **S(3-20)** — "ยืดหยุ่นที่สุดในบรรดา subclass ของ Witch ทั้งหมด" ตามที่ old scorecard ระบุตรงๆ

## Fragrant Magic (ValdaSpire24Extras)

- Control: **A(3-20)** — Sulfur(AoE Disadv Con)+Dizzying Fog(lv10, AoE Poisoned ต่อเนื่อง)
- Support: **A(3-9) → S(14-20)** — Frankincense/Smelling Salts(บัฟ ally 30ft)→Olfactory Aura(lv14, aura ถาวร +d4 D20 Test ให้ทีม) = always-on
- Utility: **A(3-20)** — Perfumed Charisma(Adv Cha check aura)+Incense Casting(componentless)
- Versatility: **A(3-20)** — 3 โหมด Fragrant Aura+aura เสริมทีมถาวร+control breadth

## Gingerbread Magic (ValdaSpire24Extras)

- Support: **A(3-9) → S(14-20)** — Sugar Rush(bonus action Dash/Disengage ฟรีให้ ally)→Candy Land(lv14, โซนฮีล 10HP/เทิร์นต่อเนื่อง 1 นาที)
- Survivability: **B(3-9) → A(10-20)** — Sugar-Coat (lv10, reaction ยกเลิก weapon attack ทั้งหมดโดยแปลงอาวุธเป็นลูกอม) = **cancel-the-hit instance ที่ 6 ในระบบ**
- Action Economy: **B(3-8) → A(9-20)** — Sugar Rush มอบ action ฟรีให้ ally ทุกครั้ง
- Versatility: **A(3-20)** — debuff+support+ป้องกัน ในตัวเดียว

## Green Magic (ValdaSpire24)

- Damage: **A(6-20)** — Twin Familiar (lv6, familiar 2 ตัวแชร์ HP pool ใช้ Quick Attack ได้ทั้งคู่ = ดาเมจ pet ×2)
- Support: **A(10-20)** — Vital Nourishment (lv10, temp HP+ล้าง 1 condition ให้ 6 คนทุก long rest)
- Survivability: **B(3-13) → A(14-20)** — Sacrificial Familiar (lv14, redirect attack ไปที่ familiar Cha mod ครั้ง/วัน)
- Action Economy: **B(6-20)** — Twin Familiar สั่งงานทั้งสองตัวพร้อมกัน = โจมตี pet 2 ครั้ง/เทิร์น
- Versatility: **A(3-20)** — pet-build+support+utility ภาษา

## Purple Magic (ValdaSpire24)

- Control: **S(14-20)** — Waking Nightmare (lv14, Hex:Hallucination fail→Frenzied โจมตีสุ่มรวมพวกเดียวกัน) = **"control ที่แรงที่สุดในบรรดา class นี้" ตามที่ old scorecard ระบุตรงๆ**

## Red Magic (ValdaSpire24)

- Damage: **A(3-13) → S(14-20)** — Elemental Annihilation (lv14, แลก slot เพื่อการันตีดาเมจสูงสุดคาถาธาตุ)

## Sky Magic (ValdaSpire24Extras)

- Control: **A(10-20)** — Vortex (lv10, AoE difficult terrain+ranged disadv+กันบิน) = battlefield control หลายมิติ

## Steel Magic (ValdaSpire24)

- Damage: **A(6-9) → S(10-20)** — **Extra Attack (lv6, real!)** — full-caster ตัวที่ 4 ในระบบที่ได้ Extra Attack จริงจาก subclass (ต่อจาก Necromancer/Tactician/Warlock's Symbiont) — บวก Insidious Smite (lv10, nova ผ่านแลก slot)
- Survivability: **B(3-13) → A(14-20)** — Martial Training(medium armor+shield)→Hexplate(lv14, resist B/P/S จากเป้าที่ Hex ไว้)
- Action Economy: **B(3-5) → A(6-20)** — Extra Attack เองยกระดับ Primary ตั้งแต่ lv6 บวกตัวเลือกแทนที่โจมตีด้วยคาถา

## Tea Magic (ValdaSpire24)

## ข้อค้นพบสำคัญ

1. **Survivability ขยับ 10/13 (77%) กว้างที่สุดในไฟล์** ทั้งที่ baseline เป็น C-flat ไม่มีจุดกู้เลย — Witch เป็นคลาส full-caster ตัวที่ 3 ติดต่อกัน (ต่อจาก Warlock/Warmage) ที่ Survivability floor กลายเป็นจุดขยับกว้างสุด ยืนยัน pattern "generic-caster floor หลวม" เป็นเรื่องปกติของกลุ่ม full-caster ทั้งหมด ไม่ใช่ข้อยกเว้น
2. **⚠️ พบ cancel-the-hit-adjacent mechanism ถึง 3 ครั้งในไฟล์เดียว** (Gingerbread's Sugar-Coat #6, Sky Magic's Cloud Dancer 25% auto-miss #7, Technicolor's Positivity +10AC #8) — Witch เป็นคลาสที่มีความหนาแน่นของกลไกนี้สูงสุดเท่าที่เคยเจอในไฟล์เดียว
3. **Steel Magic เป็น full-caster subclass ตัวที่ 4 ในระบบทั้งหมดที่ได้ Extra Attack จริงจาก subclass** (ต่อจาก Necromancer's Black Rider/Death Knight, Tactician's War Mind, Warlock's Symbiont) — ดัน Damage ตรงไป S ตั้งแต่ lv10
4. **Tea Magic's Tasseography เป็น universal-reliability-tool pattern ตัวที่ 3 ในระบบ** (ต่อจาก Warlock's Future You Patron/Undead Patron) — แทนที่ D20 Test อะไรก็ได้ของใครก็ได้ที่เห็น ดัน Utility ตรงไป S
5. **White Magic เป็น Support สูงสุดในทั้งไฟล์ (9/10) และเป็นครั้งแรกที่ old scorecard เปรียบเทียบ subclass ตรงๆ กับ "dedicated healer ของ Cleric"** — ยืนยันว่าธีม healer เต็มรูปแบบทะลุ floor ได้แม้ในคลาสที่ baseline ไม่มี Support theme เลย (เหมือน Warlock's Celestial, Warmage's House of Kings/Go)
6. **Purple Magic's Waking Nightmare ถูก old scorecard เรียกว่า "control ที่แรงที่สุดในบรรดา class นี้" ตรงๆ** — ดัน Control ทะลุจาก B ไป S ที่ lv14 ก่อนแม้แต่ baseline's Hexmaster(lv20) เอง
7. **Action Economy ขยับ 9/13 (69%)** ยืนยัน tie-break 2-2 ของ baseline (ครั้งที่ 25 สะสมในระบบ) ไม่ใช่ ceiling ตายตัว — ส่วนใหญ่พลิกผ่านกลไก Reaction ใหม่หรือ companion-command-via-bonus-action ที่ตรงกับ pattern ซ้ำๆ ที่เจอมาตลอดทั้งโปรเจกต์
