# Warden Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Warden subclass (Call) ทั้งหมดในโปรเจกต์ — Valda's Spire ล้วน ยึด 2024 เป็นหลัก รวม 2014-only orphan ด้วย (Fey Trailblazer, Hellkeeper, Iceheart Bastion, Loreseeker, Soulblood Shaman ไม่มีเวอร์ชัน 2024)
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, VSS 2014/2024
**กลไกคลาสหลัก**: **Guardian Tactics** (Block/Challenge/Grasp — ระบบ tank-control) เดิมชื่อ Warden's Mark/Grasp ในเวอร์ชัน 2014 — subclass ส่วนใหญ่ modify option ใดตัวหนึ่ง

## A Tier — พลิกเกมได้ชัดเจน

### Diabolist 🟢 — Free Command control
- **จุดเด่น**: Infernal Command ร่าย Command ฟรีผ่าน bonus action ไม่ใช้ spell slot 2 ครั้ง/พัก เป็น control ที่ไม่เสียทรัพยากรเลย
- **จุดด้อย**: Command เป็นคาถา 1st level เอฟเฟกต์เบา ใช้ได้ผลดีกับศัตรูที่ save ต่ำเท่านั้น
- **วิธีเล่น**: ใช้ Infernal Command สั่งศัตรูให้ล้ม/หนี/ยืนนิ่งฟรีทุกไฟต์ที่ต้องการ control เพิ่ม

### Drake-Blooded 🟢 — Caster-tank hybrid
- **จุดเด่น**: ได้ spellcasting เต็มรูปแบบ + Metamagic ที่ใช้ Hit Point Dice แทน sorcery point เป็นระบบทรัพยากรที่ไม่เหมือนใคร ผสม tank และ caster ในตัวเดียว
- **จุดด้อย**: ใช้ Hit Point Dice เป็นทรัพยากร metamagic แข่งกับการฟื้น HP ยามพักสั้น
- **วิธีเล่น**: ใช้ HD แลก Metamagic ปรับแต่งคาถาให้ตรงสถานการณ์ ควบคู่กับบทบาทแทงค์ปกติของ Warden

### Nightgaunt 🟢 — Execute mechanic
- **จุดเด่น**: Death's Gambit ทำให้เป้าที่โดน Challenge และ HP ต่ำพอตายได้ทันทีจากดาเมจปกติ เป็น execute ที่ทรงพลังมาก
- **จุดด้อย**: ต้องใช้ Challenge option ก่อนถึงจะเปิด execute ได้ ไม่ standalone
- **วิธีเล่น**: ใช้ Challenge ล็อกเป้าก่อน แล้วจบด้วยดาเมจปกติที่กลายเป็น instant kill เมื่อ HP เป้าต่ำพอ

### Stoneheart Defender 🟢 — Tank + AoE knockdown
- **จุดเด่น**: Stonewall เสริม Block ให้ป้องกันแรงขึ้นถ้าถือโล่; Earthshatter ล้มศัตรูหลายตัวพร้อมกันผ่านการโจมตี ผสมทั้งแทงค์และ control กลุ่ม
- **จุดด้อย**: Stonewall ต้องถือโล่ถึงจะได้ประโยชน์เต็มที่
- **วิธีเล่น**: ถือโล่ป้องกันพวกพ้องด้วย Block ที่เสริมพลัง แล้วใช้ Earthshatter ล้มกลุ่มศัตรูรอบตัวเป็นระยะ

### Storm Sentinel 🟢 — AoE lightning damage
- **จุดเด่น**: Thunderblast เสริม Grasp ให้ทำดาเมจ AoE แก่ทุกเป้าในรัศมี เป็นดาเมจกลุ่มที่ Warden ทั่วไปไม่มี
- **จุดด้อย**: ต้องใช้ Grasp option ก่อนถึงจะเปิดดาเมจ AoE ได้
- **วิธีเล่น**: ใช้ Grasp ดึงกลุ่มศัตรูเข้ามาใกล้แล้วปล่อย Thunderblast ทำดาเมจ AoE พร้อมกัน

### Loreseeker (VSS'14🕰️) 🟢 — Spellcasting unlock
- **จุดเด่น**: ปลดล็อกสเปลคาสติ้งเต็มรูปแบบให้ Warden ที่ปกติไม่มี เป็นการเพิ่ม "ความสามารถประเภทใหม่" ให้คลาส
- **จุดด้อย**: ต้องบริหาร spell slot เพิ่มเติมจากกลไก Guardian Tactics ปกติ
- **วิธีเล่น**: ใช้คาถาเสริม utility/ดาเมจนอกเหนือบทบาทแทงค์ปกติ เปิดทางเล่น Warden แบบ caster-lean

### Soulblood Shaman (VSS'14🕰️) 🟢 — Spellcasting unlock (ancestral theme)
- **จุดเด่น**: ปลดล็อกสเปลคาสติ้งเช่นเดียวกับ Loreseeker แต่ธีมวิญญาณบรรพบุรุษ/ปกป้อง เหมาะ build ที่เน้น support
- **จุดด้อย**: ต้องบริหาร spell slot เพิ่มเติมจากกลไก Guardian Tactics ปกติเหมือนกัน
- **วิธีเล่น**: ใช้คาถาธีมวิญญาณเสริม support/protection ให้ทีม ควบคู่กับบทบาทแทงค์ปกติ

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Beastblood Guardian (เดิมชื่อ Bloodwrath Guardian'14) 🟢 — Fear opener
- **จุดเด่น**: Roar ทำให้ศัตรูรอบตัวหวาดกลัวได้ฟรีผ่าน bonus action เป็น control เปิดฉากที่ดี
- **จุดด้อย**: fear ใช้ไม่ได้กับศัตรู immune to frightened
- **วิธีเล่น**: เปิด Roar ก่อนเข้าประชิดกลุ่มศัตรู ลดจำนวนศัตรูที่กล้าเข้าตีตัวเอง

### Carrion King 🟢 — Vermin companion debuff
- **จุดเด่น**: Infest ให้ vermin โจมตี+debuff เป้าได้; Versatile Vermin เสริม utility จัดการสิ่งของระยะไกล
- **จุดด้อย**: ดาเมจจาก Infest ค่อนข้างเบา (1d6) เอียงไปทาง debuff มากกว่าดาเมจ
- **วิธีเล่น**: ใช้ Infest ลดความสามารถเป้าก่อนบุกประชิด ควบคู่กับ utility จัดการของผ่าน vermin

### Godsworn 🟢 — Ally buff via Block
- **จุดเด่น**: Anointed Block เสริม Block ให้พวกพ้องได้ +1d4 attack/save เพิ่มเติม เป็น support ที่ผูกกับ tank role
- **จุดด้อย**: ประโยชน์ต้องใช้ Block option ก่อน ไม่ standalone
- **วิธีเล่น**: ใช้ Block ป้องกันพวกพ้องพร้อมแจกบัฟ +1d4 attack/save ไปด้วยในตัว

### Rimekeeper 🟢 — Forced movement control
- **จุดเด่น**: North Wind ดึง/ผลักเป้าได้ผ่าน Block/Challenge เสริม control ตำแหน่งให้ Warden
- **จุดด้อย**: ใช้ได้แค่เป้า Large หรือเล็กกว่า เป้ายักษ์ใหญ่กว่าจะไม่ได้ผล
- **วิธีเล่น**: ใช้ North Wind ดึงเป้าอันตรายออกจากแนวหลังปาร์ตี้ หรือผลักเป้าลงหลุม/ออกจากขอบ

### Grey Watchman 🟢 — Tactical maneuvers
- **จุดเด่น**: Maneuver Options เสริมออปชันแทคติกแบบ Battle Master; Siege Defender เสริมการป้องกัน
- **จุดด้อย**: ต้องเรียนรู้ maneuver หลายแบบให้คล่องถึงจะใช้ประโยชน์เต็มที่
- **วิธีเล่น**: เลือก maneuver ให้ตรงสถานการณ์ ผสมกับบทบาทป้องกันของ Warden

### Verdant Protector 🟢 — Extended control zone
- **จุดเด่น**: Grasping Vines ขยายรัศมี Grasp ให้กว้างขึ้น เพิ่มพื้นที่ควบคุมได้มากกว่าปกติ
- **จุดด้อย**: ธีมพืชอาจไม่เหมาะกับสภาพแวดล้อมในร่ม/เมือง
- **วิธีเล่น**: ใช้ Grasp ที่ขยายรัศมีคุมพื้นที่กว้างขึ้นในไฟต์กลุ่มใหญ่

### Witchbane Hunter 🟢 — Anti-caster challenge
- **จุดเด่น**: Spiteful Challenge ให้ advantage ต้าน save จากเอฟเฟกต์ของเป้าที่ Challenge ไว้ เสริม anti-caster utility
- **จุดด้อย**: ประโยชน์เต็มที่ต้องเจอศัตรู caster/มีเอฟเฟกต์เวทมนตร์เป็นหลัก
- **วิธีเล่น**: Challenge เป้า caster สำคัญก่อน แล้วใช้ advantage ต้านเอฟเฟกต์ของมันตลอดไฟต์

### Iceheart Bastion (VSS'14🕰️) 🟢 — Cold tank utility
- **จุดเด่น**: Icy Grasp ให้ temp HP ทุกครั้งที่ใช้ Grasp; Snowshoes เดินฝ่าหิมะ/น้ำแข็งได้ฟรี
- **จุดด้อย**: Snowshoes มีประโยชน์เฉพาะแคมเปญที่มีภูมิประเทศหิมะ/น้ำแข็งเยอะ
- **วิธีเล่น**: ใช้ Grasp เก็บ temp HP สะสมระหว่างควบคุมศัตรู เหมาะแคมเปญอาร์กติก/หนาวเย็น

## C Tier — situational หรือ combat impact ต่ำ

### Fey Trailblazer (VSS'14🕰️) 🟢 — Situational charm mark
- **จุดเด่น**: Alluring Mark ให้ mark แบบ charm-based เสริม control ทางเลือกนอกเหนือ mark ปกติ
- **จุดด้อย**: charm มีจุดอ่อนร่วมกับ subclass charm อื่นทั้งหมด (immune ต่อ undead/construct)
- **วิธีเล่น**: ใช้ Alluring Mark กับเป้าที่ charm ได้ผล เป็นทางเลือกแทน mark ปกติเฉพาะสถานการณ์

### Hellkeeper (VSS'14🕰️) 🟢 — Social intimidation niche
- **จุดเด่น**: Tormenter เพิ่ม proficiency bonus x2 สำหรับ Intimidation check เสริม social ด้านข่มขู่
- **จุดด้อย**: ประโยชน์จำกัดเฉพาะ social encounter ที่ต้องข่มขู่ ไม่มีผลต่อคอมแบตโดยตรง
- **วิธีเล่น**: ใช้เป็นตัวข่มขู่หลักของปาร์ตี้ในฉาก social พึ่งความสามารถแทงค์พื้นฐานในไฟต์จริง
