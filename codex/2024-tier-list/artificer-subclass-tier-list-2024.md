# Artificer Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Artificer subclass ทั้งหมดในโปรเจกต์ เฉพาะ edition 2024 — official ล้วน ไม่มีเวอร์ชัน Grim Hollow/Valda's Spire ให้เทียบ ทุกสายจาก 2014 (Alchemist, Armorer, Artillerist, Battle Smith) มีเวอร์ชัน 2024 ครบ ไม่มีสายไหนตกหล่นจาก 2014

## A Tier — เสริมพลังคลาสได้ชัดเจนที่สุด

### Battle Smith (TCE) 🔵 — Companion melee hybrid
- **จุดเด่น**: Steel Defender เป็นตัวช่วยรบที่ยืนระยะได้ตลอดไฟต์ ซ่อมเองได้ (Repair) และแบ่งความสนใจศัตรูออกจากตัวเอง; Battle Ready ให้ใช้ Int แทน Str/Dex ตีอาวุธได้ ทำให้เล่นแนว melee โดยไม่ต้องดัมพ์ Int
- **จุดด้อย**: Steel Defender เป็น concentration-free แต่ยังตายได้จาก AoE/focus fire ถ้าตายกลางไฟต์ต้องรอจนพักถึงเรียกกลับ; DPR โดยรวมยังต่ำกว่ามาร์เชียลแท้ๆ
- **วิธีเล่น**: ปล่อย Steel Defender ยืนหน้าดึงเป้า ตัวเองตีประชิดด้วย Int แล้วใช้ infusion/สเปลเสริมจากด้านหลัง

### Armorer (TCE) 🔵 — Power-armor combatant
- **จุดเด่น**: Arcane Armor แปลงตัวเองเป็นนักสู้ full-time ไม่ต้องพึ่ง weapon infusion แยก; Infiltrator model ให้ extra damage die ทุกครั้งที่โจมตี + speed เสริม ส่วน Guardian model ได้ thorns reaction (ดันดาเมจกลับ) + จำกัดศัตรูด้วย reaction
- **จุดด้อย**: ต้องเลือก model ตั้งแต่ lv3 (Guardian แทงค์ vs Infiltrator ดาเมจ) ปรับเปลี่ยนกลางเกมไม่ได้; พึ่ง Arcane Armor ตลอดเวลาทำให้ build ทางเลือกแคบกว่า subclass อื่น
- **วิธีเล่น**: สวม Arcane Armor ก่อนไฟต์แล้วเล่นเป็นแนวหน้าเต็มตัว เลือก Infiltrator ถ้าเน้นดาเมจ หรือ Guardian ถ้าเน้นดึงเป้า/แทงค์

### Artillerist (TCE) 🔵 — Ranged sustained damage + party shield
- **จุดเด่น**: Eldritch Cannon เป็นเทอร์เร็ตยิงเสริมทุกเทิร์นโดยไม่เสีย action หลัก; Protector cannon แจก temp HP ให้ปาร์ตี้ทุกเทิร์นเป็น sustain เสริมทั้งทีม
- **จุดด้อย**: cannon มี HP จำกัดตายได้จาก AoE เช่นกัน; ต้องเสีย bonus action คุมทิศทาง/สั่งยิงบางโหมด แย่งเวลากับฟีเจอร์อื่น
- **วิธีเล่น**: ตั้ง Eldritch Cannon ยิงเสริมดาเมจทุกเทิร์นควบคู่กับ spellcasting ของตัวเอง เลือก Protector mode ตอนปาร์ตี้ต้องการ sustain เพิ่ม

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Reanimator (RHW) 🔵 — Necromancer companion
- **จุดเด่น**: Reanimated Companion คล้าย Steel Defender ของ Battle Smith (ตัวช่วยรบ+tank) แถมมาพร้อมธีม necromancy/สเปลเสริมด้านนี้; Reanimator's Skill Set เพิ่ม utility (skill/tool proficiency)
- **จุดด้อย**: การสร้างตัวใหม่หลังตายต้องเสีย action หรือ spell slot ไม่ built-in เหมือน Steel Defender ที่เรียกกลับได้ฟรีกว่า; เป็น subclass ใหม่ (2024) ยังไม่มี track record การเทสยาวเท่า Battle Smith
- **วิธีเล่น**: สร้าง companion ก่อนไฟต์สำคัญให้ยืนหน้าแทน แล้วใช้ spell slot สำรองสร้างใหม่หากตัวเดิมตายกลางไฟต์ที่จำเป็นจริงๆ

### Alchemist (TCE) 🔵 — Flexible support
- **จุดเด่น**: Experimental Elixir สุ่มได้เอฟเฟกต์เสริม (heal, adv, resist, speed ฯลฯ) ยิ่งเลเวลสูงยิ่งเลือกผลได้มากกว่าสุ่มเดียว ยืดหยุ่นเป็นทั้งฮีลเลอร์และบัฟเฟอร์ในตัวเดียว
- **จุดด้อย**: เวอร์ชัน lv3 early ยังต้องสุ่มผล (roll d8 บนตาราง) ควบคุมผลลัพธ์ไม่ได้เต็มร้อยจนกว่าจะถึงเลเวลสูงที่เลือกได้เอง; ฮีลเป็นค่าคงที่ไม่สเกลแรงเท่าสเปลฮีลตรงๆ
- **วิธีเล่น**: ชง Experimental Elixir แจกก่อนไฟต์ใหญ่หรือใช้ระหว่างไฟต์เพื่อฮีล/บัฟตามจังหวะ เป็นซัพพอร์ตหลักของปาร์ตี้ที่ไม่มีฮีลเลอร์แท้

## C Tier — utility/exploration เด่น แต่ combat impact จำกัด

### Cartographer (EFA) 🔵 — Exploration/travel utility
- **จุดเด่น**: Adventurer's Atlas แจกบัฟเดินทาง/สำรวจให้ปาร์ตี้ทั้งกลุ่มผ่านแผนที่วิเศษ (ถือของหลายคนพร้อมกันได้); Cartographer Spells เพิ่มคาถาสายสำรวจ/สื่อสารเข้าประจำ เหมาะแคมเปญที่เน้นเดินทาง/สำรวจโลกเยอะ
- **จุดด้อย**: ฟีเจอร์หลักแทบไม่แตะคอมแบตเลย เทียบกับ Battle Smith/Armorer/Artillerist ที่ผสมทั้งดาเมจ/แทงค์ Cartographer แทบไม่มีอะไรช่วยไฟต์ตรงๆ
- **วิธีเล่น**: ใช้เป็น utility support หลักของแคมเปญ hexcrawl/สำรวจ แจกแผนที่บัฟให้ทีมก่อนออกเดินทางไกล ส่วนในไฟต์พึ่ง spellcasting พื้นฐานของ Artificer เป็นหลัก

## สรุปเร็วตามบทบาท

| บทบาท | subclass ที่เด่นสุด |
|---|---|
| Companion/pet tank | Battle Smith, Reanimator |
| Melee combatant เต็มตัว | Armorer |
| Ranged sustained damage + shield ทีม | Artillerist |
| Healer/support ยืดหยุ่น | Alchemist |
| Exploration/travel utility | Cartographer |

**จุดสังเกต**: Artificer เป็น class เดียวในลิสต์นี้ที่ทุก subclass (รวม 2024 ใหม่อย่าง Cartographer/Reanimator) ยังไม่มีตัวไหนอ่อนแบบ "D tier ชัดเจน" เท่า Wizard — อย่างแย่สุดคือ Cartographer ก็ยังมีประโยชน์เต็มที่ในแคมเปญที่เน้นสำรวจ ไม่ใช่ dead weight แบบ subclass ที่ตกกราฟจริงจัง
