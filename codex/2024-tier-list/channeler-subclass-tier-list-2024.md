# Channeler Subclass Tier List (Edition 2024)

**วันที่**: 2026-08-05
**ขอบเขต**: Channeler subclass ทั้งหมดในโปรเจกต์ — Valda's Spire ล้วน **ทั้ง 4 สายเป็น 2014-only orphan** ไม่มีเวอร์ชัน 2024 เลย (รวมทุกสายตามกติกา 2014-only)
**แหล่งข้อมูล**: `codex/General/class-subclass-index.md`, `Mage Hand Press; Valda's Spire of Secrets - 2014.json`
**กลไกคลาสหลัก**: subclass เลือกตั้งแต่ lv1 ผ่าน **Portal Key** (ไอเทมประจำตัวที่กำหนดทั้งสไตล์การต่อสู้และธีมคาถา) — ต่างจาก class อื่นที่เลือก subclass ที่ lv3

---

## Legend
- 🟢 Valda's Spire — 🕰️ 2014-only (ไม่มี 2024)

---

## A Tier — เสริมพลังคลาสได้ชัดเจนที่สุด

### Order of Wild Hunters 🟢🕰️ — Ranged spell-channeler
- **จุดเด่น**: Portal Key เป็นแล่งธนูไม่จำกัดกระสุน + สามารถแทน spell attack ด้วยการยิงธนู/หน้าไม้ได้ตั้งแต่ lv2 (channel คาถาผ่านอาวุธระยะไกล) รวมความแม่นยำของ weapon attack เข้ากับเอฟเฟกต์คาถาในนัดเดียว
- **จุดด้อย**: ต้องพกอาวุธระยะไกลตลอดเวลาถึงจะใช้ mechanic หลักได้ ถ้าโดนปลดอาวุธเสียเปรียบทันที
- **วิธีเล่น**: ยิงธนู/หน้าไม้แทน spell attack ปกติเพื่อเลี่ยงจุดอ่อนของ spell attack roll ที่ต่ำ ใช้แล่งไม่จำกัดกระสุนเป็นข้อได้เปรียบด้าน sustain

### Order of Titanfists 🟢🕰️ — Dual-gauntlet striker
- **จุดเด่น**: Portal Key เป็นถุงมือคู่ที่ตีได้ทั้งสองข้าง แถมตีข้างที่สองเป็น bonus action ได้ฟรีตั้งแต่ lv1 (ไม่ต้องรอ Extra Attack) เพิ่ม DPR ตั้งแต่เลเวลต้น
- **จุดด้อย**: ผูกกับอาวุธ battlefist เฉพาะทาง เปลี่ยนไปใช้อาวุธอื่นแล้วเสียจุดเด่นทันที
- **วิธีเล่น**: ตีด้วย battlefist ทั้งสองข้างทุกเทิร์นตั้งแต่ lv1 เป็นดาเมจหลักแบบ melee gish แน่นๆ

---

## B Tier — มั่นคง ใช้งานได้ดีสม่ำเสมอ

### Order of Blinknights 🟢🕰️ — Weapon-bonded gish
- **จุดเด่น**: Portal Key เป็นอาวุธที่ซ่อนไว้ใน Ethereal Plane เรียกออกมาได้ทันที + นับเป็นอาวุธเวทมนตร์ทะลุ resistance ได้ตั้งแต่ lv1 ผสมทั้งความสะดวก (ไม่ต้องพกอาวุธตลอด) และดาเมจ
- **จุดด้อย**: ยังไม่เห็นฟีเจอร์ดาเมจ/utility เสริมที่โดดเด่นกว่า Titanfists/Wild Hunters ในข้อมูลระดับต้นที่มี
- **วิธีเล่น**: เก็บอาวุธไว้ในมิติกลางจนต้องใช้ แล้วเรียกออกมาฟันแบบไม่ต้องกังวลเรื่องโดนปลดอาวุธหรือลืมพก

### Order of Dimensional Magi 🟢🕰️ — Ritual scholar
- **จุดเด่น**: Portal Key เป็นสมุดคาถาที่จดคาถา ritual จาก class list ไหนก็ได้ฟรี (ไม่ผูกแค่ Channeler list) เพิ่มความยืดหยุ่นด้าน utility/exploration สูงมาก
- **จุดด้อย**: เน้น ritual spell/utility เป็นหลัก ดาเมจ combat โดยตรงต่ำกว่าสาย weapon-bonded ทั้งสาม
- **วิธีเล่น**: สะสมคาถา ritual ข้าม class list ไว้ในสมุดสำหรับแก้ปัญหานอกคอมแบต ควบคู่กับบทบาทดาเมจ/utility พื้นฐานของ Channeler

## สรุปเร็วตามบทบาท

| บทบาท | สายที่เด่นสุด |
|---|---|
| Ranged spell-weapon hybrid | Wild Hunters |
| Melee DPR ตั้งแต่ lv1 | Titanfists |
| Weapon-bond convenience | Blinknights |
| Ritual/utility caster | Dimensional Magi |

**จุดสังเกต**: Channeler เป็น class เล็กที่สุดในลิสต์นี้ (4 สายเท่านั้น) และทั้งหมดเป็น 2014-only — ยังไม่เคยถูกอัปเดตเป็น 2024 เลยสักสาย ต่างจาก class อื่นส่วนใหญ่ที่อย่างน้อยมี 1 สายที่ยังใช้งานได้ในเวอร์ชัน 2024
