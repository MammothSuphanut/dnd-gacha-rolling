# Wizard Subclass Scorecard (Edition 2024)

**วันที่**: 2026-08-07
**สถานะ**: 🧪 PILOT — class แรกที่ทำตามระบบให้คะแนนราย axis รอ feedback ก่อนลุยที่เหลืออีก 27 class
**ขอบเขต**: Wizard subclass ทั้งหมด 26 ตัวในโปรเจกต์ (เหมือนกับ [wizard-subclass-tier-list-2024.md](wizard-subclass-tier-list-2024.md) — ไฟล์นี้เป็นไฟล์คู่กัน ให้คะแนนราย axis เพิ่มเติมจากไฟล์เดิมที่มีแค่ Overall Tier + จุดเด่น/จุดด้อย/วิธีเล่น)
**Overall Tier**: เป็นดุลยพินิจแยกต่างหาก **ไม่ใช่ค่าเฉลี่ยของ 7 axis** — อาจไม่ตรงกับค่าเฉลี่ยราย axis เสมอไป

---

## วิธีให้คะแนน (7 axis, M/R/B methodology)

ทุก axis ให้คะแนน 0-10 จาก 3 มิติ: **Magnitude (0-4)** ผลลัพธ์แรงแค่ไหนตอนทำงาน + **Reliability (0-3)** ใช้ได้บ่อย/แน่นอนแค่ไหน + **Breadth (0-3)** ครอบคลุมสถานการณ์กว้างแค่ไหน — แปลงคะแนนรวมเป็นเกรด: **S=9-10 · A=7-8 · B=5-6 · C=3-4 · D=0-2**

1. **Damage** — พลังทำลายล้างในคอมแบต
2. **Control** — ลดประสิทธิภาพศัตรู (CC/debuff/บังคับผลลัพธ์)
3. **Support** — เสริมพวกพ้อง (ฮีล/บัฟ/utility ให้ทีม)
4. **Survivability** — เอาตัวรอด (HP/AC/resist/หนี)
5. **Action Economy** — ความคุ้มค่าต่อ action/resource ที่เสีย **รวมทั้ง 2 มิติ**: (ก) ต้นทุนต่อครั้งที่ใช้ (เสีย action/BA/reaction ไหม หรือฟรี) และ (ข) ความยั่งยืนตลอดวัน (ใช้ได้กี่ครั้ง/วัน ฟื้นเร็วแค่ไหน — subclass ที่ "จ่ายตูมทีเดียวแล้วแห้งทั้งวัน" จะได้คะแนนต่ำกว่าที่ sustain ได้สม่ำเสมอ แม้ magnitude ต่อครั้งจะสูงกว่า)
6. **Utility** — exploration/social/downtime นอกคอมแบต
7. **Versatility** — ใช้ได้ทุกสถานการณ์/ทุกช่วงเลเวล ไม่ผูก build ตายตัว

## S Tier (1)

### Bladesinger (TCE / FRHoF'24) 🔵 — Gish caster
**ภาพรวม**: ได้ S เพราะ Bladesong แก้จุดอ่อนคลาสสิกของ wizard (HP/AC ต่ำ) ได้เบ็ดเสร็จ โดยไม่เสีย combat power เลย — เป็น full caster ที่ tank ได้ในตัว ไม่มี subclass อื่นใน 2024 ทำแบบนี้ได้ครบเท่า

| Axis | Score | Grade | เหตุผล |
|---|---|---|---|
| Damage | 5/10 | B | ตีอาวุธพร้อมร่าย cantrip ได้ (lv6+) แต่ไม่มีดาเมจเสริมพิเศษจาก subclass เอง อาศัย weapon dmg ปกติ |
| Control | 0/10 | D | ไม่มีฟีเจอร์ควบคุมศัตรูเลย |
| Support | 0/10 | D | ไม่มีฟีเจอร์ช่วยพวกพ้องเลย ทุกอย่างเน้นตัวเอง |
| Survivability | 8/10 | A | Bladesong เพิ่ม AC เท่า Int mod (สูงสุดในกลุ่ม caster) + speed +10ft + กันโดน advantage ตอนถูกล้อม — จุดอ่อนคลาสสิกของ wizard หายไปเกือบหมด |
| Action Economy | 7/10 | A | ตีอาวุธ+ร่าย cantrip ในการกระทำเดียวกันได้ (lv6) ไม่เสีย action พิเศษ + Bladesong ฟื้นตอน short rest ใช้ได้สม่ำเสมอตลอดวัน ไม่ใช่แค่ nova ทีเดียว |
| Utility | 3/10 | C | ไม่มี utility เฉพาะตัวนอกเหนือสเปล wizard ปกติทั่วไป |
| Versatility | 4/10 | C | ผูก build ตายตัว (ใส่ light armor, ถืออาวุธมือเดียว ไม่มีโล่) เปลี่ยนแนวเล่นยาก |

## A Tier (4)

### Diviner (XPHB'24, เดิมชื่อ School of Divination'14) 🔵 — Passive control
**ภาพรวม**: Portent คือกลไก "บันทึกผล d20 ล่วงหน้าแล้วแทนที่ทีหลัง" ต้นแบบของทั้งซีรีส์ — แรงเพราะไม่เสีย action เลยและใช้พลิกได้ทั้งเกมรุกและเกมรับ แต่จำกัดแค่ 2 ครั้ง/วันเลยไม่ถึง S

| Axis | Score | Grade | เหตุผล |
|---|---|---|---|
| Damage | 0/10 | D | ไม่มีดาเมจเสริมเลย |
| Control | 7/10 | A | บังคับ attack/save ของศัตรู fail ได้แน่นอน (แทนที่ d20 roll) — ผลลัพธ์การันตี ไม่ต้องพึ่ง save เพิ่ม |
| Support | 6/10 | B | ใช้แบบเดียวกันช่วยพวกพ้อง auto-hit/auto-save ได้เหมือนกัน แต่แชร์ budget เดียวกับฝั่ง control |
| Survivability | 1/10 | D | ป้องกันตัวเองได้ทางอ้อมผ่าน save เท่านั้น ไม่มีกลไกตรง |
| Action Economy | 7/10 | A | ไม่เสีย action/reaction เลยตอนใช้ (แทนที่ผลได้ทันทีหลังทอย) แต่ Portent มีแค่ 2 ครั้ง/long rest ไม่ฟื้นระหว่างวัน ต้องเลือกจังหวะใช้ให้คุ้มถ้าเจอหลายไฟต์ |
| Utility | 4/10 | C | มีฟีเจอร์ divination อื่นเสริมเล็กน้อย ไม่ใช่จุดขายหลัก |
| Versatility | 8/10 | A | ใช้ได้ทุกสถานการณ์ (attack/save/check) ทุกช่วงเลเวล ไม่ผูก build |
