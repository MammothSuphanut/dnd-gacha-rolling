## ROX Skill Reference — Swordsman → Knight/Crusader

#### Swordsman (1st Class)

| Skill | ความสามารถคร่าวๆ |
|---|---|
| Bash | โจมตีกายภาพเป้าเดียว ดาเมจสูง (สกิลเปิดคอมโบหลักของสาย) |
| Provoke | ยั่วยุ ดึง aggro + ลด DEF เป้าหมาย |
| Magnum Break | ระเบิดไฟรอบตัว ดาเมจ AoE เผาอาวุธเป็นธาตุไฟชั่วคราว |
| Endure | ทนดาเมจ ไม่ถูก stagger/knockback ชั่วคราว เสริม DEF/MDEF |
| Sword Mastery | Passive เพิ่มดาเมจเมื่อถืออาวุธประเภทดาบ (มือเดียว/สองมือ) |
| Two-Handed Sword Mastery | Passive เพิ่มดาเมจเฉพาะดาบสองมือเพิ่มเติมจาก Sword Mastery |
| Increase HP Recovery | Passive เพิ่มอัตราฟื้น HP ตามธรรมชาติ/จากไอเทมฮีล |
| HP Recovery While Moving | Passive ฟื้น HP ได้แม้กำลังเดิน (ปกติต้องหยุดนิ่งถึงจะฟื้น) |
| Auto Berserk | Passive เมื่อ HP ต่ำกว่าเกณฑ์ เพิ่มดาเมจอัตโนมัติ + ต้านสถานะ stun/freeze/stone ชั่วคราว |
| Battle Will *(ROX)* | Passive โจมตีปกติติดเป้าหมายสะสมบัฟดาเมจ (stack ได้หลายชั้น) |
| Fatal Blow *(ROX)* | Passive เสริม Bash ให้มีโอกาสทำให้เป้าหมาย stun + ลด DEF เพิ่ม |

*Source:* [Ragnarok X: Next Generation Swordman Skill Database](https://hthgaming.com/ragnarok-x/swordman-skill-database-6274.html), [Ragnarok Online (Renewal) Swordman Skills](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=2)
