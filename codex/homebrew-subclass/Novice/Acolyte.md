## ROX Skill Reference — Acolyte → Priest/Monk

#### Acolyte (1st Class)

| Skill | ความสามารถคร่าวๆ |
|---|---|
| Heal | ฟื้น HP เป้าหมาย/ตัวเอง หรือสร้างดาเมจใส่ undead |
| Increase AGI | บัฟเพิ่ม AGI/Movement Speed เป้าหมาย 2 เท่าชั่วคราว |
| Blessing | บัฟเพิ่ม STR/INT/DEX ชั่วคราว + ล้าง curse/stone curse |
| Cure | ล้าง status ผิดปกติ (cursed, silence, chaos, blind) |
| Decrease AGI | ดีบัฟลด AGI/Movement Speed เป้าหมาย (ไม่มีผลกับ boss) |
| Angelus | บัฟเพิ่ม DEF ให้ตัวเองและปาร์ตี้รอบตัว |
| Signum Crucis | ลด DEF ของ undead/shadow property เป็นวงกว้าง |
| Demon Bane | Passive เพิ่มดาเมจใส่ undead/demon |
| Divine Protection | Passive เพิ่ม DEF ต้าน undead/demon |
| Holy Light | โจมตีเวทระยะไกลธาตุ holy เป้าเดียว |
| Pneuma | สร้างพื้นที่กันการโจมตีระยะไกลชั่วคราว |
| Ruwach | สร้างแสงศักดิ์สิทธิ์รอบตัว ตรวจจับ+ดาเมจศัตรูซ่อนตัว |
| Aqua Benedicta | สร้าง Holy Water จากแหล่งน้ำธรรมดา |
| Teleport | เทเลพอร์ตตัวเองในระยะสั้น หรือกลับจุดเซฟ |
| Warp Portal | สร้างประตูวาร์ปเชื่อมสถานที่ ใช้ Blue Gemstone |

*Source:* [Ragnarok Online (Renewal) Acolyte Skills](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=7)
