# 🗺️ วิธีเปิดแคมเปญ (สำหรับ 🍳 Chef)

1 แคมเปญ = 1 โพสต์ในห้องนี้ ใช้โพสต์นั้นเป็นที่คุยของโต๊ะทั้งหมด (นัดเวลา, OOC, สรุปเซสชัน)

**ชื่อโพสต์:** ชื่อแคมเปญ เช่น `Aeorian Cataclysm`
**Tag:** 🟢 รับสมัคร / 🟡 เต็มแล้ว / 💤 พักชั่วคราว / ⚫ จบแล้ว

```
🗺️ แคมเปญ: 
🍳 Chef: @
🔊 ห้องเล่น: (ห้อง voice ของ Chef)
📅 เล่นทุก: (เช่น เสาร์เว้นเสาร์ 20:00)
⚔️ เลเวลเริ่ม: 
👥 ผู้เล่น: @ @ @
🎲 ระบบ: 
📖 เรื่องย่อ:

📌 ลิงก์สำคัญ: (Foundry / ชีท / โลก)
```

**ระหว่างแคมเปญ**
• สรุปหลังจบแต่ละเซสชัน ให้ขึ้นต้นข้อความด้วย `📓 Session N` จะได้ค้นง่าย
• ข้อความในบทบาท (IC) ขึ้นต้นด้วย 🎭 ข้อความนอกบทบาทไม่ต้องใส่อะไร
• ปักหมุด (Pin) ข้อความสำคัญในโพสต์ได้ Chef มีสิทธิ์จัดการโพสต์ของตัวเอง
