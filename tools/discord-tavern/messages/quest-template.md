# 🧨 วิธีโพสต์เควส (สำหรับ 🍳 Chef)

**ชื่อโพสต์:** `[วันที่] ชื่อเควส` เช่น `[15 พ.ย.] หมูป่าคลั่งแห่งหุบเขา`
**Tag:** เลือก 🟢 รับสมัคร + ระดับเลเวล + รูปแบบ (One-shot / แคมเปญ / ออนไลน์ / ออฟไลน์)

ก๊อปข้างล่างนี้ไปกรอกได้เลย 👇

```
🧨 เควส: 
🍳 Chef: @
📅 วันเวลา: (วัน วันที่ เวลาเริ่ม – เวลาจบโดยประมาณ)
📍 สถานที่: (ห้อง voice ไหน / ร้านไหน)
⚔️ เลเวล: 
👥 ที่นั่ง: 0 / (จำนวน)
🎲 ระบบ: D&D 2024 / 2014 / อื่น ๆ
📖 เนื้อเรื่องย่อ:
(2-4 บรรทัด ไม่สปอยล์)

⚠️ เนื้อหาที่อาจมี: (เช่น สยองขวัญ, ความรุนแรง — ถ้าไม่มีใส่ "-")
📝 สมัครอย่างไร: ตอบในโพสต์นี้ บอกชื่อตัวละคร คลาส เลเวล
```

**ขั้นตอนหลังโพสต์**
1. Ping `@🔔 Quest Ping` ในโพสต์ เพื่อแจ้งคนที่รับข่าว
2. ผู้เล่นตอบในโพสต์เพื่อสมัคร → Chef เลือกแล้วตอบรับในโพสต์
3. ที่นั่งเต็ม → เปลี่ยน Tag เป็น 🟡 เต็มแล้ว
4. เล่นจบ → เปลี่ยน Tag เป็น ⚫ จบแล้ว และปิดโพสต์ (Close Post)
