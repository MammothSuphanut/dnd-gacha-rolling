# Journal Format Template

คู่มือ + ตัวอย่างสำหรับแปลง adventure outline (ผลลัพธ์จาก `/build-adventure`) ให้กลายเป็น **"Journal" แบบเต็ม** — สไตล์ published module / VTT journal entry ที่มี boxed read-aloud text, DC/stat block ระบุอินไลน์, และ breakdown ห้องต่อห้อง (ดูตัวอย่างต้นแบบจาก official *Frozen Sick* module)

## กฎบังคับตอนขยาย (ห้ามข้าม)

> ส่วนนี้คือคำสั่งตรงถึง Claude (หรือ AI ที่อ่านไฟล์นี้) — ทำตามทุกข้อเป็นค่าเริ่มต้นเสมอ ไม่ต้องรอให้ผู้ใช้เตือนซ้ำ เว้นแต่ผู้ใช้ขอให้ย่อ/เจาะจงแค่บางฉากไว้ชัดเจน

1. **ถามก่อนเดาเอง — ห้ามแต่งรายละเอียดที่ไม่มีใน outline ทันทีโดยไม่ถาม** ก่อนเริ่มเขียน ให้ไล่ดูว่า EP นี้มี "ส่วนที่ต้องเติมเอง" กี่จุด (ดูลิสต์หมวดหมู่ด้านล่าง) แล้วถามผู้ใช้เป็นชุดเดียว (ใช้ AskUserQuestion ถ้ามี ไม่งั้นถามเป็นข้อความ) ว่าแต่ละจุดอยากให้ **AI คิดให้เลย** หรือ **ผู้ใช้จะออกแบบเอง** — ถ้าเลือกออกแบบเอง ให้รอคำตอบก่อนเขียนจุดนั้น อย่าเดาไปก่อนแล้วค่อยถามทีหลัง

   หมวดหมู่ที่ควรเช็ค (ถามเฉพาะจุดที่ outline เดิมไม่ได้ระบุไว้แล้ว):
   - **Treasure** — จำนวน gp และไอเทมเฉพาะ (magic item ควรมีผลอะไร/rarity ระดับไหน)
   - **NPC tactics** — เงื่อนไขหนี/เรียกเพื่อน/เป้าหมายที่ศัตรูเล็งก่อน
   - **เอกสาร/ของกลางในเกม** — เนื้อหาจดหมาย บันทึก ใบเสร็จที่ผู้เล่นจะได้อ่านจริง
   - **สถานที่ซ้อนสถานที่ที่ outline พูดถึงแค่ลอยๆ** — เช่น "บ้าน NPC" ไม่มีรายละเอียด ผังภายในเป็นยังไง มี feature อะไรน่าสนใจ
   - **ชื่อ/รายละเอียดของ named object** — ไอเทม/จุดสนใจเฉพาะในห้องที่ยังไม่มีชื่อ
   - **DC ที่ outline เดิมไม่ได้ระบุ** (ถ้า outline มี DC อยู่แล้วให้ใช้ตามเดิม ไม่ต้องถามซ้ำ)

   ถ้าผู้ใช้ตอบว่า "ให้ AI คิดเอง" สำหรับจุดไหน ค่อยไปทำตามข้อ 2-6 ด้านล่างสำหรับจุดนั้น
2. **ทุกไฟล์ EP journal ต้องขึ้นต้นด้วยตาราง `## NPC ประจำ EP`** (ชื่อ / บทบาท / หมายเหตุ) วางไว้ทันทีหลังบรรทัด metadata ตัวเอียงบนสุด (level/session) ก่อนเนื้อเรื่อง — รวม NPC ที่มีชื่อทุกตัวที่ปรากฏใน EP นี้ (ไม่นับมอนสเตอร์ทั่วไปที่ไม่มีชื่อเฉพาะ เช่น "Ice Mephit x4") แถวละ 1 ตัว สรุปบทบาท + จุดสำคัญที่ต้องรู้ก่อนรัน session สั้นๆ พออ่านเร็วได้ — ข้อบังคับนี้ใช้เหมือนกันทุก EP ไม่ว่าจะมีไฟล์ outline เดิมมาก่อนหรือไม่
3. **ไล่ทีละ bullet ในไฟล์ outline เดิม** (หัวข้อ "เหตุการณ์/ฉากสำคัญ", "ช่วงที่ N", "NPC ประจำ EP" ฯลฯ) — ทุกสถานที่ที่ถูกพูดถึง แม้แค่ประโยคเดียว (เช่น "บ้านของ X", "ร้านค้าในเมือง", "จุดพักระหว่างทาง") **ต้อง**กลายเป็น `##`/`###` section ของตัวเองในไฟล์ journal ห้ามรวบเป็นย่อหน้าเดียวเพื่อความสั้น
4. **ทุก NPC ที่ให้ข้อมูล/เบาะแสแก่ผู้เล่น** ต้องมีหัวข้อ `### What [ชื่อ] Knows` เป็นของตัวเอง
5. **ทุก encounter/มอนสเตอร์** ต้องมีอย่างน้อย 1 ประโยคระบุ tactics (เงื่อนไขที่จะหนี, จะเรียกเพื่อน, เป้าหมายที่เล็งก่อน ฯลฯ) — ห้ามระบุแค่ชื่อ stat block เฉยๆ
6. **ทุกจุดที่มี loot** (แม้ไฟล์ outline เดิมจะเขียนแค่ "ของมีค่า"/"หลักฐาน" ลอยๆ) ต้องขยายเป็น `### Treasure` พร้อม gp และไอเทมที่ระบุชื่อ/จำนวนชัดเจน — รายละเอียดมาจากคำตอบข้อ 1 (ถ้าผู้ใช้เลือกให้ AI คิดเอง ค่อยคิดให้สมเหตุสมผลกับ level/theme)
7. **ก่อนส่งไฟล์**: ไล่ทวนกลับไปที่ไฟล์ outline เดิมอีกรอบ 1 ครั้ง — ถ้ามีชื่อสถานที่/NPC/เหตุการณ์ไหนที่ไม่ปรากฏเป็น section ในไฟล์ journal ที่เขียนออกมา ให้เพิ่มก่อนส่งงาน (รวมถึงเช็คว่าตาราง NPC ประจำ EP จากข้อ 2 ครบทุกตัวแล้ว) ห้ามส่งไฟล์ที่ยังขาดอยู่
8. **ชื่อสถานที่/NPC/องค์กรที่ซ้ำหรือใกล้เคียงกับ Critical Role canon** (เช่น Rexxentrum, Uthodurn, Kryn Dynasty, Dwendalian Empire) ให้ค้น Critical Role Wiki ก่อนแต่งรายละเอียดเอง — ดูกฎเต็มที่ [canon-reference.md](./canon-reference.md)

## วิธีใช้ไฟล์นี้

ไฟล์นี้**ไม่ผูกกับ adventure ไหนโดยเฉพาะ** — เป็น reference กลางที่หยิบไปอ้างอิงได้กับทุก adventure ในโปรเจกต์ วิธีใช้งานจริง:

1. รัน `/build-adventure` จนได้โฟลเดอร์ `adventures/<slug>/` พร้อมไฟล์ outline (00-overview, EP01-...md ฯลฯ) ตามปกติ
2. เมื่ออยากขยาย EP ไหน (หรือฉากไหน) ให้เป็น journal เต็ม ให้สั่ง Claude แบบนี้:
   > "ขยาย EP1 ให้เป็น journal format ตาม adventure-builder/journal-template.md"
3. Claude จะอ่าน convention + ตัวอย่างในไฟล์นี้ แล้วแปลงเนื้อหา outline ที่มีอยู่ (ช่วงที่/ฉากสำคัญ, DC, NPC, encounter) ให้กลายเป็น boxed text + room breakdown แบบเดียวกับตัวอย่างด้านล่าง — ไม่ต้องเขียนเนื้อเรื่องใหม่ แค่ "แต่งเติม" ให้เป็น prose พร้อมอ่านออกเสียงหน้าโต๊ะได้จริง
4. ผลลัพธ์บันทึกเป็นไฟล์ `EP01 - ชื่อตอนเต็ม.md` (ดูรูปแบบชื่อไฟล์เต็มที่ [structure-guide.md](./structure-guide.md)) — **EP หนึ่งเลขมีไฟล์เดียวเสมอ** ถ้ามีไฟล์ outline เดิมของ EP นี้อยู่แล้ว (`EP01-slug.md`) ให้รวมส่วนที่มีประโยชน์จากไฟล์นั้น (เช่นตาราง NPC ประจำ EP) เข้ามาในไฟล์ journal ใหม่ แล้วลบไฟล์ outline เดิมทิ้ง ไม่ปล่อยให้ค้างอยู่คู่กันสองไฟล์

## Syntax ที่ใช้ (Legend)

| ใช้ทำอะไร | Markdown syntax | ตัวอย่าง |
|---|---|---|
| หัวเรื่อง adventure | `#` | `# ชื่อ Adventure` |
| หัวข้อใหญ่ (Overview, Summary, ชื่อสถานที่) | `##` | `## Story Overview` |
| หัวข้อย่อย/ห้องในดันเจี้ยน | `###` | `### C1. ชื่อห้อง` |
| **Boxed read-aloud text** — สิ่งที่ DM อ่านออกเสียงให้ผู้เล่นฟังตรงๆ | blockquote + ตัวเอียง `> *...*` | `> *เสียงลมหวีดหวิว...*` |
| DC / skill check / stat block / ชื่อเฉพาะที่ DM ต้องสังเกต | ตัวหนา `**...**` | `ทอย **Perception (DC 13)**` |
| ตัวเลือกบทสนทนา NPC | bullet list ใต้หัวข้อ | `- "ประโยคที่ NPC พูด"` |
| ข้อมูลที่ผู้เล่นได้ถ้าถาม/สำเร็จ check | bullet list | `- ข้อมูล...` |
| กติกา/hazard ที่ใช้ซ้ำหลายจุด | หัวข้อย่อยเดี่ยว ก่อนเข้าห้อง | `## Frigid Pools` (นิยามกติกาไว้ครั้งเดียว แล้วอ้างถึงในห้องย่อย) |
| **สิ่งที่ NPC รู้/บอกได้** — จัดเป็น pattern มาตรฐาน ไม่ใช่บรรยายลอยๆ | หัวข้อย่อย `### What [ชื่อ NPC] Knows` + bullet list | `### What Old Maren Knows` |
| **พฤติกรรม/tactics ของศัตรู** — ไม่ใช่แค่ชื่อ stat block เฉยๆ ต้องบอกว่ามันจะทำอะไรเมื่อไหร่ | ประโยคในย่อหน้า encounter | "เมื่อ HP เหลือครึ่งหนึ่ง จะพยายามหลบหนี", "จะแจ้งเตือนพวกอื่นก่อนเข้าปะทะเสมอ" |
| **ของรางวัล/ทรัพย์สิน** — ระบุจำนวน gp และไอเทมชัดเจน ไม่ปล่อยเป็น "ของมีค่า" ลอยๆ | หัวข้อย่อย `### Treasure` ท้ายห้อง/สถานที่ | `### Treasure` + bullet รายการ+มูลค่า |
| **ของ/จุดที่น่าสนใจเป็นพิเศษ** — วัตถุที่ผู้เล่นน่าจะอยากค้น/ถามถึงเจาะจง ให้แยกหัวข้อของตัวเอง แทนที่จะฝังในย่อหน้าห้อง | หัวข้อย่อยสั้นๆ ตามชื่อวัตถุ | `### Locked Coffer`, `### Old Ledger` |
| **เอกสาร/ของกลางในโลกเกม** (จดหมาย, ใบเสร็จ, บันทึก) — แยกจาก narration ให้ชัดว่านี่คือ "ข้อความที่ผู้เล่นจะได้อ่านเป็นลายลักษณ์อักษร" ไม่ใช่คำบรรยายของ DM | code block หรือ blockquote ต่างระดับจาก boxed text | ดูตัวอย่าง "Torn Ritual Page" ด้านล่าง |
| **การอ้างอิงข้าม section** — เชื่อมจุดที่เกี่ยวข้องกันในเอกสารเดียวกัน | วงเล็บอิตาลิกท้ายประโยค | *(ดูหัวข้อ "Treasure" ด้านล่าง)* |
| **สถานที่ซ้อนสถานที่** (เช่น บ้าน NPC ที่อยู่ในหมู่บ้านอีกที) — อย่าฝังทุกอย่างไว้ในย่อหน้าเดียว แยกเป็นหัวข้อของตัวเองพร้อม feature ย่อยตามจริง | `##`/`###` ซ้อนกันตามลำดับชั้นสถานที่ | `## Old Maren's House` → bullet นำด้วย **Loft:**, **Door:**, **Chest:** |

**หลักการ**: บรรยาย (narration) แยกจาก กลไก (mechanics) แยกจาก บทสนทนา (dialogue) แยกจาก ของกลาง/เอกสาร (handout) เสมอ — DM กวาดตาหาแต่ละส่วนได้เร็วระหว่างเล่นจริง ไม่ต้องอ่านทั้งย่อหน้าเพื่อหา DC ตัวเดียว ถ้าสถานที่มีรายละเอียดเยอะ (บ้าน, ร้านค้า, ถ้ำ) ให้แตกเป็นหัวข้อย่อยตามจริง อย่ากลัวเอกสารยาว — เอกสารสั้นเกินไปมักแปลว่าข้อมูลสำคัญ (loot, tactics, เบาะแส) หายไป

# Silentwater Landing

บางสิ่งกำลังกัดกินท่าเรือเล็กๆ แห่งนี้ และหากเหล่าตัวละคร (Characters) ไม่หยุดมัน หมู่บ้านทั้งหมู่บ้านอาจไม่เหลือใครให้เล่าเรื่องต่อ "Silentwater Landing" เป็นการผจญภัยที่พาตัวละครจากเลเวล 1 ไปถึงเลเวล 3 และแนะนำให้ผู้เล่นได้รู้จักภูมิภาค **Greywater Marsh**

## Story Overview

**Old Maren** ผู้ใหญ่บ้านประจำ Silentwater Landing เพิ่งสูญเสียหลานชายไปกับ "หมอกกัดกร่อน" ที่ลอยขึ้นจากบึงทุกคืนข้างขึ้น ชาวบ้านเริ่มหวาดกลัวจะไม่กล้าออกจากบ้านยามค่ำ ทั้งที่ฤดูเก็บเกี่ยวใกล้เข้ามาแล้ว

ความจริงแล้ว หมอกนั้นเกิดจากพิธีกรรมที่ผิดเพี้ยนของนักบวชนอกรีตกลุ่มเล็กๆ ที่หลบซ่อนอยู่ในถ้ำใต้โรงสีร้าง — พวกเขาพยายามปลุกวิญญาณโบราณขึ้นมาโดยไม่รู้ว่ากำลังทำให้หมอกพิษรั่วไหลออกมาด้วย

## Adventure Summary

ตัวละครมาถึง Silentwater Landing พอดีกับคืนงานศพหลานชายของ Old Maren ระหว่างงานจะได้ยินเบาะแสจากชาวบ้านและสามารถซักถามได้ว่าเกิดอะไรขึ้น จากนั้นตามรอยหมอกไปจนถึงโรงสีร้างริมบึง บุกถ้ำใต้โรงสี ฝ่ากับดักและสัตว์กลายพันธุ์จากหมอกพิษ จนไปพบกลุ่มนักบวชนอกรีตและหยุดพิธีกรรมได้ทันเวลา

## Mystery in Silentwater Landing

การผจญภัยเริ่มต้นที่งานศพในหมู่บ้าน (คุณสามารถอ่านหรือสรุปข้อความนี้ให้ผู้เล่นฟัง):

> *กลุ่มชาวบ้านยืนเงียบล้อมหลุมศพใหม่ Old Maren หญิงชราผู้เป็นทั้งหมอและผู้นำหมู่บ้าน วางดอกไม้ป่าลงบนโลงไม้อย่างสั่นเทา "ขอบคุณที่มาร่วมงานของ Tomas นะ" เธอกล่าวกับตัวละคร เสียงแหบเครือ "ฉันเสียใจที่ต้องพูดเรื่องเศร้าแบบนี้ แต่ฉันเชื่อว่าหมู่บ้านนี้อาจตกอยู่ในอันตราย และฉันหวังว่าพวกคุณจะช่วยเราได้"*

### What Old Maren Knows

ถ้าตัวละครซักถาม Old Maren ต่อ (ไม่ต้องทอย check ใดๆ — เธออยากเล่าอยู่แล้ว) เธอบอกได้ว่า:

- เมื่อสามคืนก่อน Tomas กลับมาจากการหาปลาที่บึงด้วยอาการเพ้อคลั่ง ผิวหนังเริ่มเป็นแผลไหม้แปลกๆ และเสียชีวิตในเช้าวันถัดมา
- นักบวชประจำหมู่บ้านใช้เวทมนตร์รักษาทุกทีที่ทำได้ แต่ไม่ผลกับแผลนี้ ร่างกายเขากลายเป็นเถ้าถ่านละเอียดในที่สุด
- Maren สังเกตเห็นแสงสีเขียวจางๆ ลอยอยู่เหนือโรงสีร้างริมบึงมาสองสามสัปดาห์แล้ว แต่ไม่มีใครกล้าไปดู

ข้อมูลที่ตัวละครอาจได้จากชาวบ้านคนอื่นถ้าสืบเพิ่ม (Persuasion/Insight, **DC 12**):

- นักเดินทางแปลกหน้ากลุ่มหนึ่งผ่านมาซื้อเสบียงเมื่อเดือนก่อน แล้วหายเข้าไปในป่าฝั่งโรงสี ไม่มีใครเห็นออกมาอีก
- เด็กในหมู่บ้านเล่าว่าได้ยินเสียงสวดแว่วมาจากทิศโรงสีในคืนพระจันทร์เต็มดวง

## Old Maren's House

ตัวอย่างสถานที่ซ้อนสถานที่ — บ้านของ NPC ที่ตัวละครอาจเดินเข้าไปหาข้อมูลเพิ่มก่อนออกเดินทาง ให้แยกเป็นหัวข้อของตัวเอง พร้อม feature ย่อยที่ตัวละครอาจถามถึง/ตรวจสอบเฉพาะจุด:

> *กระท่อมไม้หลังเล็กกลิ่นสมุนไพรตากแห้งลอยอบอวล หม้อต้มยาแขวนอยู่เหนือเตาผิงที่ยังคุอยู่ ชั้นวางเรียงรายด้วยขวดโหลป้ายชื่อด้วยลายมือสั่นๆ*

- **Herb Shelf**: ทอย **Nature หรือ Medicine (DC 12)** สำเร็จจะรู้ว่าสมุนไพรครึ่งหนึ่งบนชั้นถูกใช้ไปหมดแล้วในช่วงสัปดาห์ที่ผ่านมา — Maren พยายามรักษา Tomas ทุกวิถีทางจริงๆ
- **Locked Drawer**: ลิ้นชักใต้โต๊ะทำงานล็อกอยู่ (**Thieves' Tools DC 13** หรือ Maren ยอมไขให้ถ้าตัวละครขอดีๆ) ข้างในมีจดหมายจากลูกชายของ Maren ที่ออกเรือไปเมื่อหลายปีก่อนไม่กลับมาอีก — ไม่เกี่ยวกับปมหลัก แค่ให้มิติตัวละคร Maren เพิ่มเติม (DM เลือกใช้หรือข้ามได้)

## Old Mill Cave

### Light

ภายในถ้ำไม่มีแหล่งกำเนิดแสงใดๆ ยกเว้นในพื้นที่ **area C3** เนื่องจากผู้อ่านอาศัยอยู่ในโพรงที่มีรอยร้าวสู่ผิวดิน ผู้ที่ไม่มี darkvision ต้องพกแหล่งกำเนิดแสงเอง

### Corrosive Mist

หมอกสีเขียวจางๆ ลอยอยู่ตามพื้นที่ต่ำในถ้ำเป็นหย่อมๆ สิ่งมีชีวิตใดก็ตามที่เริ่มเทิร์นของตนอยู่ในหมอกนี้ต้องทอย **Constitution saving throw (DC 12)** มิฉะนั้นจะได้รับ **2d6 acid damage** และมีสถานะ **poisoned** จนถึงเทิร์นถัดไปของตน

### C1. Collapsed Entrance

> *ประตูไม้ผุพังของโรงสีเปิดอ้าครึ่งหนึ่ง ลมพัดพาไอหมอกสีเขียวจางๆ ออกมาจากรอยแยกพื้นด้านใน กลิ่นเหมือนโลหะไหม้ลอยแตะจมูกคุณ*

พื้นที่นี้เป็นโรงสีชั้นบนที่ทรุดโทรม ครึ่งหนึ่งของพื้นไม้ผุพังจนมองเห็นถ้ำด้านล่าง ตัวละครที่ทอย **Perception (DC 13)** สำเร็จจะสังเกตเห็นรอยเท้าเดินลงบันไดหินที่ซ่อนอยู่หลังกองกระสอบข้าวเก่า

### C2. Guard Post

> *ทางเดินแคบแยกออกเป็นสองทาง กองไฟเล็กๆ ยังคุกรุ่นอยู่ในซอกหิน ข้างๆ วางเสื้อคลุมสีเทาเปื้อนดินไว้บนก้อนหิน*

กลุ่มนักบวชนอกรีต 2 คน (ใช้ stat block **Cultist**, MM) เฝ้าอยู่ตรงนี้ ถ้าตัวละครเดินเข้ามาแบบไม่ระวังตัว (ไม่ผ่าน Stealth) ให้ทอย initiative ทันที นักบวชจะพยายามส่งเสียงเตือนไปยัง **area C3** ก่อนสู้เสมอ และถ้า HP เหลือน้อยกว่าครึ่ง จะพยายามล่าถอยไปรวมกลุ่มที่ C3 แทนที่จะสู้ตาย (ทำให้ boss fight ที่ C3 หนักขึ้นถ้าตัวละครปล่อยให้หนีทัน)

### Cultist's Satchel

ถ้าตัวละครค้นตัวนักบวชหลังต่อสู้ (ไม่ต้องทอย check) จะพบเอกสารต่อไปนี้ — อ่านหรือส่งให้ผู้เล่นอ่านเองได้ *(ดูหัวข้อ "Torn Ritual Page" — ตัวอย่างการนำเสนอเอกสารในเกม)*:

### Torn Ritual Page

```
...เมื่อดวงจันทร์เต็มดวงอีกครั้ง วิญญาณแห่งบึงจะตื่น
เราต้องเร่งพิธีให้เสร็จก่อนรอบนั้น มิเช่นนั้นประตูจะปิดอีกร้อยปี
— รวบรวมพลังจาก "the Hollow Choir" ให้ครบทั้งสี่
```

*(เอกสารแบบนี้ใช้แทนของกลาง/หลักฐานที่ผู้เล่นเก็บสะสมได้ — ถ้า adventure มีปริศนาที่ต้องรวบรวมเบาะแสหลายจุด ให้ใช้ pattern เดียวกันนี้ในแต่ละจุด)*

### C3. The Hollow Choir

> *โพรงถ้ำกว้างเปิดสู่ท้องฟ้าผ่านรอยร้าวเหนือหัว แสงจันทร์สีเขียวอมฟ้าสาดลงมาต้องแท่นหินกลางห้องที่แกะสลักเป็นวงกลมซ้อนกัน กลุ่มคนคลุมผ้าคลุมยืนสวดเป็นภาษาที่คุณไม่คุ้นเคย ขณะที่หมอกสีเขียวพวยพุ่งขึ้นจากรอยแยกกลางแท่น*

หัวหน้าลัทธิ (ใช้ stat block **Cult Fanatic**, MM) และสาวก 3 คน (**Cultist**) กำลังประกอบพิธี ถ้าตัวละครบุกเข้ามาก่อนพิธีเสร็จ (เช่น ภายใน 3 เทิร์นหลังเข้าห้อง) พิธีจะถูกขัดจังหวะและกลุ่มลัทธิหันมาสู้ทันที — ถ้าปล่อยให้พิธีเสร็จก่อน ให้เพิ่ม hazard พิเศษ (เช่น หมอกพ่นออกมาทั่วห้องทุกเทิร์น) ตามความเหมาะสมกับ table หัวหน้าลัทธิสู้จนตาย (ไม่หนี) เพราะเชื่อว่าพิธีนี้คือจุดหมายชีวิตของตน

### Ritual Altar

แท่นหินกลางห้องมีร่องเก็บของฝังอยู่ ทอย **Investigation (DC 13)** เพื่อพบว่ามีของมีค่าซุกอยู่ใต้แท่น *(ดูหัวข้อ "Treasure" ด้านล่าง)*

### Treasure

- 340 gp (เหรียญเงินปนทอง จากการบริจาคของเหยื่อที่ถูกลวงมาก่อนหน้า)
- **Amulet of the Still Water** (จี้เงินรูปคลื่น) — ให้ advantage กับ saving throw ต้าน exhaustion จากความเย็น (DM ปรับ rarity/effect ตาม table ได้)
- หนังสือพิธีกรรมเก่าที่เขียนไม่ครบ — เก็บไว้เป็น hook ต่อยอด adventure ถัดไปได้ถ้าต้องการ

หลังจัดการกลุ่มลัทธิได้ หมอกในถ้ำทั้งหมดจะจางหายไปภายในไม่กี่นาที — Silentwater Landing ปลอดภัย

## หมายเหตุการใช้ template นี้

- ตัวอย่างข้างบนคือ**ต้นแบบโครงสร้าง** ไม่ใช่เนื้อหาที่ต้องใช้จริง — แทนที่ชื่อสถานที่/NPC/มอนสเตอร์/DC ด้วยของจาก adventure จริงที่มีอยู่ในไฟล์ outline
- ไม่จำเป็นต้องมี "Mystery in..." section เสมอไป — ถ้า EP ไหนเปิดด้วย combat หรือ dungeon ทันที ให้ตัดส่วนนั้นออกแล้วเริ่มที่ boxed text ของฉากแรกได้เลย
- กติกาที่ใช้ซ้ำ (เช่น hazard, แสง) ให้นิยามไว้ครั้งเดียวก่อนเข้าห้องแรก แล้วอ้างอิงชื่อในห้องถัดๆ ไปพอ ไม่ต้องเขียนซ้ำทุกห้อง
- ความยาว boxed text ต่อห้อง: 2-4 ประโยคพอ — ยาวกว่านี้ผู้เล่นจะฟังไม่ทันตอนอ่านออกเสียงจริง
- **อย่าย่อจนหาย pattern พวกนี้**: "What [NPC] Knows" (ทุก NPC ที่ให้ข้อมูลควรมี), tactics ของศัตรู (ไม่ใช่แค่ชื่อ stat block), Treasure (ทุกจุดที่มี loot ควรระบุ gp/ไอเทมชัดเจน) — ถ้า EP เดิมไม่มีข้อมูลพวกนี้ในไฟล์ outline ให้ถามผู้ใช้หรือเติมให้สมเหตุสมผลเอง อย่าปล่อยว่าง เพราะสิ่งเหล่านี้คือส่วนที่ทำให้อ่านแล้วรู้สึกเป็น module ที่ใช้เล่นได้จริง ไม่ใช่แค่บรรยากาศ
- สถานที่ที่มีรายละเอียดเยอะ (บ้าน NPC, ร้านค้า, ถ้ำหลายห้อง) ให้แตกเป็น location ของตัวเองพร้อม feature ย่อย ไม่ต้องยัดทุกอย่างในย่อหน้าเดียว — แต่ EP ไหนที่ไม่มีสถานที่แบบนั้นจริงๆ (เช่น เป็นแค่ negotiation scene) ก็ไม่ต้องฝืนสร้างขึ้นมา
