# Canon Reference Rule (Critical Role Wiki)

กติกากลางเรื่อง**เมื่อไหร่ควรค้นข้อมูลจาก Critical Role Wiki (criticalrole.fandom.com) ก่อนแต่งเนื้อหาเอง** ใช้กับทุก adventure ในโปรเจกต์ที่อิงกับ setting ของ Critical Role (Wildemount/Tal'Dorei) เช่น `aeorian-cataclysm` (Dwendalian Empire) — ไม่ผูกกับ adventure ใดโดยเฉพาะ

## เมื่อไหร่ต้องเช็ค — ถามก่อนเสมอ ห้ามเดาเอง

**ห้ามตัดสินใจเองจากการเดาว่าชื่อนี้ "ฟังดูเหมือน" canon หรือไม่** ก่อนแต่งรายละเอียดของ **สถานที่ / NPC มีชื่อ / องค์กร / เผ่าพันธุ์ / เหตุการณ์ประวัติศาสตร์** จุดไหนก็ตาม ให้**ถามผู้ใช้ก่อนเสมอ**ว่า "สิ่งนี้มีอ้างอิงจาก Critical Role Wiki ไหม" (ถามรวมเป็นชุดเดียวกับคำถามอื่นๆ ที่ถามอยู่แล้วได้ เช่น ใน `/build-adventure` ตอนถาม setting/NPC หรือใน `/build-ep` ตอนถามส่วนที่ต้องเติมเอง — ใช้ AskUserQuestion ถ้าจำนวนจุดที่ต้องถาม ≤4)

- ผู้ใช้ตอบว่า **"มี"** → ใช้ WebSearch/WebFetch ค้นที่ criticalrole.fandom.com ก่อนแต่งเอง เพื่อดึงรายละเอียดที่มีอยู่แล้ว (ภูมิศาสตร์, ผู้ปกครอง, การเมือง, ย่าน/landmark, NPC มีชื่อ) มาใช้เป็นฐาน แทนการเดาขึ้นใหม่ทั้งหมด
- ผู้ใช้ตอบว่า **"ไม่มี"** → แต่งเองได้ตามปกติทันที ไม่ต้องค้นหา (ถือเป็น homebrew ล้วน)
- เคยถามและได้คำตอบมาแล้วสำหรับชื่อเดิมในเรื่องเดียวกัน → ใช้คำตอบเดิมซ้ำได้ ไม่ต้องถามซ้ำทุกครั้งที่พูดถึงชื่อนั้นอีก

## วิธีอ้างอิงในไฟล์ที่สร้าง

- ถ้าเนื้อหาส่วนไหนอิงจาก wiki จริง ให้ใส่ลิงก์กำกับสั้นๆ ไว้ในไฟล์ (ตัวอย่างจริงที่ใช้อยู่แล้วใน [00-maps.md ของ Act 2](../adventures/aeorian-cataclysm/ACT02-dwendalian-shadow/00-maps.md) แถว Rexxentrum: `อิงจาก [Critical Role Wiki: Rexxentrum](https://criticalrole.fandom.com/wiki/Rexxentrum)`)
- ถ้า canon ไม่มีรายละเอียดพอ (เช่นไม่มีข้อมูลย่าน/NPC ระดับที่ซีนต้องใช้) แต่งเพิ่มเองได้ตามปกติ แต่ห้ามขัดแย้งกับสิ่งที่ canon ระบุไว้ชัดเจนแล้ว (ผู้ปกครอง, ตำแหน่งภูมิศาสตร์, เหตุการณ์ประวัติศาสตร์สำคัญ)
- ถ้าจงใจแต่งขัดกับ canon เพื่อเหตุผลเนื้อเรื่อง (เช่น homebrew เปลี่ยนผู้ปกครองเมือง) ให้เขียนกำกับไว้ชัดว่า "ขัดกับ canon โดยตั้งใจ เพราะ..." กันสับสนภายหลังว่าเป็นความผิดพลาดหรือของตั้งใจ

## ใช้กฎนี้ตอนไหนบ้าง

- `/build-adventure` — ตอนตั้งชื่อ/รายละเอียด setting, NPC, สถานที่ครั้งแรก
- `/build-ep` — ตอนขยายเนื้อเรื่องเต็ม (Story Overview, boxed text บรรยายสถานที่, รายละเอียด NPC)
- แผนที่ (ดู [MAP-WORKFLOW.md](./MAP-WORKFLOW.md)) — ตอนสรุป layout/landmark ของ Region map ที่เป็นสถานที่ canon
- คำถามอิสระระหว่างคุยกับผู้ใช้เกี่ยวกับเนื้อเรื่อง/NPC/สถานที่ใน canon แม้ไม่ได้อยู่ระหว่างรัน `/build-adventure` หรือ `/build-ep`
