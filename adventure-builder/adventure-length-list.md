# รายการ Adventure ทั้งหมด — ความยาว + จำนวน Session

> ถอดจากภาพหน้าจอรายการ Adventure (4 ภาพ) เรียงตามลำดับเดิมในจอ
> **Session = เล่นรอบละ 3-4 ชม.** — ตัวเลขเป็นค่าประมาณ ปาร์ตี้ที่ RP เยอะ/ไปช้าบวกเพิ่มได้ 30-50%

**ประเภท**
- 🎯 **One-shot** — จบใน 1 session (บางเรื่อง 1-2)
- 📗 **Short** — 2-10 session
- 📚 **Long Campaign** — 10 session ขึ้นไป
- 🗂️ **Anthology** — รวมหลายเรื่อง เล่นแยกเป็น one-shot/short ได้ หรือร้อยต่อกันเป็นแคมเปญ
- 📦 **ไม่ใช่ Adventure** — หนังสือเสริม/กฎ/Setting/Bestiary (ไม่มีเนื้อเรื่องให้เล่นตรง ๆ)
- ❓ = ไม่แน่ใจข้อมูล (หนังสือใหม่หรือ 3rd-party ที่ไม่รู้จักดี) ควรเปิดดูในตัวหนังสือก่อน
