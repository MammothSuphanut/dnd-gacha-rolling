# คู่มือแปล Act 2-3 จากต้นฉบับ 5e.tools (PaBTSO)

ใช้คู่มือนี้เป็นมาตรฐานกลางเมื่อแปลเนื้อหาจาก `src/data/5etools/official/adventure/adventure-pabtso.json`
("Phandelver and Below: The Shattered Obelisk") ลงไฟล์ EP ในโฟลเดอร์ adventures/the-descent-of-phandelver/

## เป้าหมาย
แปลเนื้อหาต้นฉบับแบบ **ครบถ้วน ไม่สรุปย่อ ไม่ตัดทอน** — งานนี้คือการแปลภาษา ไม่ใช่การเขียน journal เล่าเรื่องแบบย่อ
ทุกห้อง ทุกเหตุการณ์ ทุกกับดัก ทุกไอเทม ทุกบทสนทนา NPC ทุกตาราง ที่อยู่ใน scope ที่ได้รับมอบหมาย ต้องปรากฏในไฟล์ผลลัพธ์

## รูปแบบไฟล์ผลลัพธ์
- **เก็บ header เดิมไว้**: บรรทัดแรก `# EPn: ชื่อ EP` และบรรทัด `*Level X · ~N session*` (คัดลอกจากไฟล์เดิมก่อนเขียนทับ ถ้ามี)
- **ตัดทิ้ง**: ส่วน `## NPC ประจำ EP`, `## Story Overview`, `## Adventure Summary`, `## จบ EP ด้วย`, `## หมายเหตุสำหรับ DM` ที่มีอยู่ในไฟล์เดิม — ส่วนเหล่านี้เป็นของเก่าที่สรุปย่อ ไม่ใช่ต้นฉบับ ให้ลบทิ้งทั้งหมด
- ที่เหลือคือเนื้อหาแปลเต็มจาก JSON ตาม scope ที่ได้รับ

## โครงสร้าง entries ใน JSON และวิธีแปลงเป็น Markdown
- `"type": "section"` ที่มี `"name"` → หัวข้อใหญ่ `##`
- `"type": "entries"` ที่มี `"name"` → หัวข้อย่อย `###` หรือ `####` ตามความลึก (นับจาก section แม่)
- `"type": "entries"` ที่ไม่มี `"name"` → ไม่ต้องใส่หัวข้อ ให้เนื้อหาไหลต่อเป็นย่อหน้า
- string ธรรมดาใน array `entries` → ย่อหน้าเนื้อความปกติ แปลไทยตรงตัว
- `"type": "insetReadaloud"` หรือ `"type": "inset"` → boxed text แปลงเป็น blockquote ตัวเอียง: `> *ข้อความ...*`
- `"type": "list"` → bullet list; ถ้า item เป็น `{"type":"item","name":"X","entry":"Y"}` ให้เขียน `- **X**: Y`
- `"type": "table"` → แปลงเป็น Markdown table (แปล header และเนื้อหาทุกช่อง)
- `"type": "image"` / `"type": "gallery"` → **ข้ามทิ้งทั้งหมด** ไม่ต้องบรรยายภาพหรือแผนที่
- `"type": "statblock"` หรือการอ้างอิงมอนสเตอร์แบบเต็ม → **ไม่ต้องแปล stat block** ให้ใส่แค่ชื่อมอนสเตอร์ตัวหนา เช่น "**Klarg** (bugbear)" พอ

## ห้อง/โลเคชันแบบมีรหัส (dungeon keys)
ห้องที่มีรหัสในต้นฉบับ เช่น "H1: Cave Mouth", "T5: Sparring Chamber", "Z12: Mining Tunnels Entrance"
→ เขียนเป็นหัวข้อ `### H1: Cave Mouth` **เก็บรหัสและชื่ออังกฤษไว้ตามเดิม** (ไม่ต้องแปลชื่อห้องเป็นไทย เพราะ DM ใช้อ้างอิงกับแผนที่) แล้วแปลเนื้อหาข้างในเป็นไทยทั้งหมด

## การแปลง tag ของ 5etools (ต้อง strip markup ให้หมด อย่าปล่อย {@...} หลุดไปในไฟล์ผลลัพธ์)
| Tag | แปลงเป็น |
|---|---|
| `{@creature Name\|source}` หรือ `{@creature Name\|\|display}` | ชื่อ (ใช้ display text ถ้ามี) ตัวหนา เช่น **Goblin** |
| `{@item Name\|source}` | ชื่อไอเทม (คงอังกฤษ) |
| `{@spell Name}` | ชื่อคาถา (คงอังกฤษ) |
| `{@skill Name}` | ชื่อ skill (คงอังกฤษ เช่น Perception, Persuasion) |
| `{@condition Name}` | ชื่อ condition (คงอังกฤษ เช่น prone, restrained) |
| `{@dc N}` | "DC N" |
| `{@hit N}` | "+N" |
| `{@dice XdY}` / `{@damage XdY}` | คงสัญกรณ์ลูกเต๋าเดิม เช่น "2d6" |
| `{@b text}` / `{@bold text}` | **text** |
| `{@i text}` / `{@italic text}` | *text* |
| `{@area text\|id\|x}` | ใช้แค่ text เฉยๆ (plain text ไม่ต้องทำลิงก์) |
| `{@adventure text\|...}` | ใช้แค่ text เฉยๆ |
| `{@table Name\|...}` | ถ้าตารางอยู่ใน scope เดียวกันให้แปลตารางนั้นมาแสดง ถ้าอยู่นอก scope ให้เขียนว่า "(ดูตาราง Name)" |
| tag อื่นๆที่ไม่อยู่ในลิสต์นี้ | ให้ตีความจากบริบทแล้วแปลงเป็นข้อความธรรมดา ห้ามเหลือ `{@...}` ค้างในผลลัพธ์เด็ดขาด |

## ชื่อเฉพาะ — คงภาษาอังกฤษเสมอ
ชื่อคน (Gundren Rockseeker, Sildar Hallwinter, Nezznar), ชื่อสถานที่ (Phandalin, Wave Echo Cave, Cragmaw Castle),
ชื่อเผ่า/กลุ่ม (Cragmaw, Redbrand), ชื่อมอนสเตอร์ (Goblin, Bugbear, Mind Flayer) — **ไม่แปลเป็นไทย** ให้คงไว้เป็นภาษาอังกฤษฝังอยู่ในประโยคไทย
ตามสไตล์ที่ไฟล์ EP อื่นๆ ในโปรเจกต์นี้ใช้อยู่แล้ว (ดูตัวอย่างได้จาก Act 1 EP1 หรือ Act 2 EP1 เดิม)

## Cross-reference ข้ามไฟล์
ถ้าเนื้อหาต้นฉบับอ้างถึงส่วนที่อยู่ใน EP อื่นในแคมเปญนี้ (เช่นอ้างถึง Cragmaw Castle ตอนอยู่ใน Chapter ก่อนหน้า)
ให้เขียนเป็นข้อความอ้างอิงธรรมดา ไม่ต้องสร้างลิงก์ markdown ข้ามไฟล์ (กัน link พัง)

## หมายเหตุสำคัญ
- นี่คืองานแปล **ห้ามสรุปย่อ ห้ามตัดรายละเอียดกลไก/ตัวเลข/บทสนทนาออก** แม้จะดูยาว ให้แปลให้ครบ
- ถ้า entries ยาวมาก ให้ทยอยเขียนไฟล์ต่อเนื่องได้ (ใช้ Edit เพิ่มท้ายไฟล์) ไม่ต้องกังวลเรื่องความยาวไฟล์ผลลัพธ์
- ตรวจทานตัวเองก่อนจบงานว่าไม่มี `{@` หลงเหลืออยู่ในไฟล์ และไม่มีหัวข้อย่อยที่หายไปจาก scope ที่ได้รับมอบหมาย
