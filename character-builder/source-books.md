# เล่มที่ใช้สร้างตัวละคร (Player-Facing Source Books)

> อัปเดตล่าสุด: 2026-10-14
> ขอบเขต: เฉพาะฝั่งสร้าง/อัปเลเวลตัวละครผู้เล่น
> ใช้: **D&D เล่มหลักทั้งหมด (WotC) + Valda's Spire of Secrets + Grim Hollow**

## กติกา Edition

1. ใช้ได้ทั้ง **2014 และ 2024** ปนกัน
2. ถ้าตัวเลือกเดียวกันมีทั้ง 2 edition ให้ใช้ **เวอร์ชัน 2024** เสมอ
3. ถ้ามีแค่ 2014 ก็ใช้เวอร์ชัน 2014 ได้ (กำกับว่า **2014 only**)

## วิธีอ่านราคา

ราคาเป็น USD แบบ **digital อย่างเดียว** เช็คจากหน้าร้านจริงเมื่อ 2026-10-14

- **Foundry** = premium module บน Foundry Marketplace ซื้อแล้วใช้ใน FoundryVTT ได้เลย มีข้อมูลครบและ automate ไว้แล้ว
- **DDB** = D&D Beyond ถ้าจะใช้ใน Foundry ต้องดึงเข้าด้วย module **DDB Importer** (ตัวฟรี แต่บางฟีเจอร์ต้องสมัคร Patreon)
- ทั้งสองร้าน **ไม่แชร์กัน** ซื้อร้านหนึ่งแล้วไม่ได้สิทธิ์อีกร้าน
- ✅ = ร้านที่แนะนำ ถ้ามีขายบน Foundry ให้เลือก Foundry ก่อน เพราะใช้งานได้ native ไม่ต้องพึ่ง importer
- — = ร้านนั้นไม่มีขาย
