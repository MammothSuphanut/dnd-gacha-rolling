# Monte Smeraldo

> **ร่าง 2026-10-23 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | เกาะภูเขา |
| ที่ตั้ง | Aldenreich → Costa Mosaica → Isole Smeralde · เกาะสูงที่สุดของสายใต้ของหมู่เกาะ |
| สังกัด | ไม่มีเจ้าของ |
| ขนาด | ~140,000 ตร.ไมล์ |
| ประชากร | ✨ ~200 คน (ชาวพื้นเมือง) |
| เศรษฐกิจ | ปลูกพืชขั้นบันได · ✨ หยกเขียว |
| ภูมิอากาศ | ร้อนชื้น (เฉลี่ย ~24°C) · พื้นที่ส่วนใหญ่เป็นป่าฝนเขตอบอุ่น · ทุ่งหญ้า |
| การเดินทาง | หาดตะวันออก · ทางขึ้นเขาชัน |

## ภาพรวม

เกาะที่มีภูเขาสูงที่สุดในหมู่เกาะ ยอดเขาปกคลุมด้วยป่าเมฆสีเขียวสด — ภูเขาที่ทำให้หมู่เกาะได้ชื่อ "มรกต" ชาวพื้นเมืองกลุ่มสุดท้ายที่ไม่ยอมอยู่ใต้ Concord อยู่บนลาดเขา

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|

| **เหมืองหยก** | ✨ หยกเขียวที่ชาวพื้นเมืองไม่ยอมขาย |
