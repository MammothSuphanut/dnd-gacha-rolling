## ภาพรวม

ป้อมหินบนเนินทุ่งหญ้าแห้งริมทะเลตะวันตก มองลงไปเห็นท่าเรือเล็ก ๆ และถนนดินสีน้ำตาลที่ทอดหายไปทางใต้ — นั่นคือ **Salt Road** เส้นทางบกเส้นเดียวที่เชื่อมแผ่นดินแม่กับอาณานิคม [Saltmarch](../costa-mosaica/saltmarch/_overview.md) ขบวนเกวียนทุกขบวนที่ลงไปอาณานิคมออกจากที่นี่ และเกวียนเกลือทุกเล่มที่กลับมาต้องผ่านด่านที่นี่

เมืองเติบโตจากการเป็น**ทางผ่าน** — คอกม้าใหญ่ โรงตีเหล็กซ่อมล้อเกวียน โกดังเสบียง และโรงเตี๊ยมที่เต็มไปด้วยผู้อพยพซึ่งรอขบวนครั้งต่อไป หลายคนที่มาถึงที่นี่ได้ยินเรื่องไข้ป่าและทางที่ยาวครึ่งปีแล้วเปลี่ยนใจ ไม่ลงไปต่อ

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ป้อมเนิน** | กำแพงหินสองชั้น หอธงที่ชักธงจักรวรรดิกับธงเกลือ (ผืนขาวมีลายผลึก) ของอาณานิคม |
| **ลานขบวน** | ลานกว้างนอกประตูใต้ ที่ขบวนเกวียนรวมตัว — ช่วงก่อนออกเดินทางเต็มไปด้วยคนขายของจำเป็น |
| **ด่านเกลือ** | ชั่งและเก็บภาษีเกลือขาขึ้น |
| **คอกล่อหลวง** | ล่อหลายร้อยตัวสำหรับลากเกวียนลงใต้ |
| **โรงเตี๊ยม "The Last Mile"** | ผู้อพยพนั่งรอขบวนกันเต็ม · ป้ายหน้าร้านเขียนว่า "ไมล์สุดท้ายที่มีเบียร์ดี" |
| **ท่าเรือใต้เนิน** | เรือเล็กส่งเสบียงเลียบฝั่ง — เร็วกว่าทางบกแต่เจอพายุบ่อย |
| **สุสานผู้อพยพ** | หลุมศพคนที่ป่วยตายระหว่างรอขบวน |

## ผู้คน ✨

- **Hauptmann Ortrun Kessler** — ผู้บัญชาการหญิงที่เคยเดิน Salt Road ไปกลับมาแล้วหกรอบ รู้ทุกจุดที่เกวียนจะติดโคลน
- **Lothar Brandt** — หัวหน้าขบวนเกวียนที่มีชื่อที่สุด คิดค่าคุ้มกันแพงแต่ไม่เคยเสียเกวียนสักเล่ม
- **Mother Ilse** — เจ้าของ The Last Mile ทำหน้าที่เหมือนสำนักทะเบียนผู้อพยพไม่เป็นทางการ
- **ผู้อพยพ** — ลูกชาวนาไร้ที่ดิน ทหารปลดประจำการ คนที่อยากหนีอะไรสักอย่างในแผ่นดินแม่

## การเมืองและความสัมพันธ์

- **Saltmarch**: Westerhold คือสายเลือดของอาณานิคม — ถ้าขบวนไม่ออก อาณานิคมจะขาดของภายในปี
- **มาร์เกรฟแห่ง Saltmarch**: ✨ ส่งจดหมายมาขอทหารเพิ่มทุกขบวน แต่ป้อมเองก็ขาดคน
- **Frosthaven และเมืองหลวง**: เกลือจากที่นี่ส่งต่อไปถนอมปลาและเนื้อของกองทัพ
- **โจรทุ่ง** ✨: กลุ่มเล็ก ๆ ดักปล้นขบวนกลางทางที่ไกลจากทั้งสองปลาย
