## ภาพรวม

เมืองที่**ภูเขาทั้งลูกถูกเจาะเป็นรังผึ้ง** — อุโมงค์เหมืองหลายร้อยปากรอบไหล่เขา เกวียนแร่วิ่งลงมาวันละหลายร้อยเที่ยว และกำแพงเมืองสร้างไว้ไม่ใช่เพื่อกันศัตรู แต่เพื่อกันคนงานเหมืองไม่ให้ขโมยแร่ออกไป

คนงานเหมืองส่วนใหญ่เป็นชาวนาที่หนีหนี้ และคนแคระที่ตระกูล Akagane จ้างมาจากนอกทวีปเพราะขุดเก่งกว่า ✨ ชั้นล่างสุดของเหมืองถูกปิดตายตั้งแต่ ~850 PD หลังคนงานขุดไปเจอห้องหินที่ไม่ใช่ฝีมือมนุษย์ และไดเมียวสั่งให้ไม่มีใครพูดถึงอีก

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~420 PD | เปิดเหมืองแรก |
| ✨ ~600 PD | คนแคระกลุ่มแรกมาจ้างงาน |
| ✨ ~850 PD | เจอห้องหินโบราณชั้นล่างสุด — ปิดตาย |
| 935 PD (ปัจจุบัน) | ✨ คนงานได้ยินเสียงเคาะจากชั้นที่ปิดตาย |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ปากเหมืองใหญ่** | อุโมงค์หลักที่มีประตูเหล็ก |
| **ลานล้างแร่** | ลานริมลำธารที่น้ำเป็นสีส้ม |
| **ค่ายคนงาน** | เรือนยาวที่คนงานนอนเรียงกัน |
| **ชั้นปิดตาย** | ประตูหินที่ถูกก่ออิฐทับ — ✨ อิฐแตกจากด้านใน |

## ผู้คน ✨

- **Kaneda Ukon** — ผู้คุมเหมืองที่โหดกับคนงานแต่กลัวชั้นล่าง
- **Brunna Deepvein** — หัวหน้าคนงานคนแคระ ✨ เป็นคนเดียวที่เคยเข้าห้องหินโบราณและยังมีชีวิต
- **Tatsu** — คนงานหนุ่มที่หนีหนี้มาจาก Kurayashiki

## การเมืองและความสัมพันธ์

- **[Akagane](akagane.md)**: ไดเมียวเก็บรายได้ — ✨ และสั่งปิดปากเรื่องชั้นล่าง
- **[Tetsumura](tetsumura.md) / [Hagane](hagane.md)**: แร่จากที่นี่ไปเป็นดาบที่นั่น
- **[Yamikaze](yamikaze.md)**: ✨ เมืองเดียวที่ใกล้หมู่บ้านนินจารับจ้าง (~1,160 ไมล์) — คนงานที่หนีมักไปทางนั้น
