## ภาพรวม

หมู่บ้านเล็กที่เสียงค้อนดังตั้งแต่ก่อนรุ่งสางถึงหลังตะวันตก — **บ้านของสำนักช่างดาบ Masamura** ที่ตีดาบให้ไดเมียวและซามูไรชั้นสูงมาเจ็ดชั่วคน ดาบหนึ่งเล่มใช้เวลาครึ่งปี และราคาเท่าที่ดินทำนาสิบไร่

ช่างดาบที่นี่เชื่อว่าดาบมีวิญญาณ และวิญญาณของดาบรับมาจากใจของช่าง ✨ ดาบของ Masamura รุ่นเก่ามีชื่อเสียงว่า "กระหายเลือด" — เจ้าของหลายคนตายด้วยดาบของตัวเอง และปรมาจารย์รุ่นปัจจุบันพยายามตีดาบที่ "สงบ" มาทั้งชีวิตโดยยังไม่สำเร็จ

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~550 PD | ช่างดาบรุ่นแรกตั้งเตา |
| ✨ ~700 PD | ดาบของสำนักใช้ในศึกรวมแคว้น — ชื่อเสียงกระหายเลือดเริ่มขึ้น |
| ✨ ~880 PD | ดาบหนึ่งพันเล่มสำหรับสงครามสามแคว้น |
| 935 PD (ปัจจุบัน) | ✨ ไดเมียวสั่งดาบเพิ่มทั้งที่ไม่มีสงคราม |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **โรงตีดาบใหญ่** | เตาเจ็ดเตาที่ไฟไม่เคยดับ |
| **ศาลเจ้าดาบ** | ศาลที่ช่างไหว้ก่อนตีดาบ — เก็บดาบแรกของสำนัก |
| **ลำธารชุบ** | ลำธารเย็นจัดที่ใช้ชุบดาบ |
| **หอเก็บดาบคืน** | ✨ ห้องที่เก็บดาบ "กระหายเลือด" ที่ครอบครัวเจ้าของส่งคืน |

## ผู้คน ✨

- **Masamura Tōji** — ปรมาจารย์ช่างดาบวัยหกสิบ เงียบ เคร่ง และกลัวดาบของตัวเอง
- **Masamura Hayate** — ลูกชายที่ตีดาบเก่งกว่าพ่อ ✨ และชอบดาบกระหายเลือด
- **Okane** — ช่างขัดดาบหญิงที่ได้ยินเสียงดาบ
