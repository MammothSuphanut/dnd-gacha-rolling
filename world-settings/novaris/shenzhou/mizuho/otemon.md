## ภาพรวม

เมืองปราสาทที่โชกุนสร้างไว้ตรงที่ถนนหลวงจาก Shirasagi แยกลงใต้ — **ประตูหน้าของ Akitsu ที่หันไปทางเขตมาร** กำแพงหินสองชั้นและปราสาทไม้สีขาวดำมองเห็นได้จากระยะไกล กองทหารซามูไรสายตรงของโชกุนประจำที่นี่ตลอดปี เพราะแคว้นไดเมียวรอบ ๆ ไม่ได้ภักดีเท่าที่โชกุนอยากให้เป็น

ทุกคนที่เดินทางลงใต้ต้องผ่านด่านของ Otemon แสดงใบผ่านทาง และจ่ายภาษีถนน ✨ ข้าหลวงจดชื่อทุกคนที่ผ่าน — และส่งรายชื่อให้หมู่บ้านนินจา [Kumokage](kumokage.md) ทุกเดือน

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~705 PD | โชกุนสร้างปราสาทหลังรวมแคว้น — ปักหมุดอำนาจทางใต้ |
| ✨ ~880 PD | สงครามสามแคว้น — Otemon เป็นที่ตั้งทัพของโชกุน |
| 935 PD (ปัจจุบัน) | ✨ กองทหารเพิ่มเป็นสองเท่า · ข่าวลือว่าโชกุนกลัวไดเมียวมากกว่ากลัวพรรคมาร |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ปราสาทขาวดำ** | ปราสาทไม้ห้าชั้นบนฐานหิน — ที่ทำการข้าหลวง |
| **ประตูโอเทะ** | ประตูใหญ่ที่เป็นที่มาของชื่อเมือง — ด่านตรวจทุกคน |
| **ค่ายซามูไรสายตรง** | เรือนทหารรอบปราสาท |
| **ตลาดเสบียง** | ข้าวและเกลือสำหรับกองทัพ |
| **ห้องทะเบียนผู้ผ่านทาง** | ห้องที่เก็บรายชื่อทุกคนที่ผ่านด่านมาสามสิบปี |

## ผู้คน ✨

- **Sakakibara Kazuma** — ข้าหลวงวัยสี่สิบห้า ระเบียบจัด ภักดีต่อโชกุนแบบไม่ถามคำถาม
- **Ishida Ranmaru** — หัวหน้าหน่วยธนูหนุ่มที่ฝีมือดีเกินตำแหน่ง ✨ ลูกนอกสมรสของไดเมียว Akagane
- **ยาย Otsune** — เจ้าของโรงเตี๊ยมหน้าด่านที่รู้ว่าใครโกหกใบผ่านทางตั้งแต่เห็นหน้า

## การเมืองและความสัมพันธ์

- **[Shirasagi](shirasagi.md)**: โชกุน — Otemon คือมือขวาทางใต้
- **เมืองสายตรง**: [Hatamoto](hatamoto.md) · [Kurayashiki](kurayashiki.md)
- **[Kumokage](kumokage.md)**: ✨ หมู่บ้านนินจาที่รับรายชื่อผู้ผ่านด่าน
- **ตระกูล Kurobane ([Tengudani](tengudani.md))**: เพื่อนบ้านที่ใกล้ที่สุด — ✨ โชกุนไม่ไว้ใจไดเมียวที่ทำสัญญากับเท็งงุ
- **เขตมาร**: ✨ ด่านทางใต้ไม่เคยห้ามคนของพรรคมารผ่าน — แค่จดชื่อ
