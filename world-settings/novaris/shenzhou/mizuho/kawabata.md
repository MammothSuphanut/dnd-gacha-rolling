## ภาพรวม

หมู่บ้านท่าข้ามบนแม่น้ำใหญ่ที่ถนนหลวงจาก Shirasagi ต้องข้าม — ดินแดนแยกของตระกูล Mizuchi ที่ได้มาเพราะ "ทุกทางน้ำเป็นของมังกรน้ำ" ไม่ว่าจะอยู่ห่างจากแคว้นแค่ไหน ใครข้ามแม่น้ำที่นี่ต้องจ่ายค่าข้ามให้ตระกูล Mizuchi และนั่นรวมถึงกองทัพของโชกุนด้วย

แม่น้ำมี**คัปปะ** — โยไคน้ำที่ลากคนลงน้ำได้ ชาวบ้านจึงโยนแตงกวาลงแม่น้ำทุกเช้า และคนข้ามฟากทุกคนต้องโค้งคำนับก่อนขึ้นเรือ ✨ เพราะคัปปะที่สุภาพจะโค้งตอบ และน้ำบนหัวของมันจะหกจนหมดแรง

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~600 PD | ท่าข้ามเกิดขึ้นพร้อมถนนหลวง |
| ✨ ~720 PD | ตระกูล Mizuchi อ้างสิทธิ์ท่าข้าม — โชกุนยอม |
| ✨ ~880 PD | Mizuchi ห้ามทัพ Akagane ข้ามแม่น้ำ — จุดพลิกของสงครามสามแคว้น |
| 935 PD (ปัจจุบัน) | ✨ คัปปะเริ่มขึ้นจากน้ำมาขอแตงกวาเองถึงบ้าน |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ท่าข้ามฟาก** | ท่าไม้และเรือแบนสามลำ |
| **ด่านค่าข้าม** | ศาลาที่มีธงมังกรน้ำ |
| **ศาลเจ้าคัปปะ** | ศาลเล็กริมน้ำที่วางแตงกวาทุกเช้า |
| **ไร่แตงกวา** | ไร่ที่ใหญ่เกินความจำเป็นของหมู่บ้าน |

## ผู้คน ✨

- **Kawai Sukenojō** — นายท่าที่เก็บค่าข้ามจากทุกคน แม้แต่ข้าหลวงของโชกุน
- **Kappei** — คัปปะหนุ่มที่ชอบเล่นซูโม่กับเด็กหมู่บ้าน
- **ยาย Uri** — เจ้าของไร่แตงกวาที่คัปปะเคารพที่สุด

## การเมืองและความสัมพันธ์

- **[Funado](funado.md)**: บ้านใหญ่ของตระกูล — ไกลมากแต่ส่งคนมาเก็บเงินทุกฤดู
- **โชกุน / [Shirasagi](shirasagi.md)**: ✨ ไม่ชอบที่ต้องจ่ายค่าข้ามแม่น้ำในแผ่นดินของตัวเอง
- **คัปปะ**: เพื่อนบ้านที่ต้องรักษามารยาท
