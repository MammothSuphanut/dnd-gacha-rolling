# Haeun-do

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | เกาะ · สำนักลับ |
| ที่ตั้ง | Shenzhou → Jungwon · นอกชายฝั่งตะวันออกใกล้ Mokcheon |
| สังกัด | ✨ **สำนักเมฆทะเล** (Haeun-pa) — ไม่ขึ้นกับฝ่ายใด |
| ขนาด | ~270,000 ตร.ไมล์ |
| ประชากร | ✨ ~80 คน |
| เศรษฐกิจ | ไม่มี — สำนักยุทธภพ |

| การเดินทาง | ไม่มีเรือประจำ — ต้องรู้ทาง |

## ภาพรวม

"เกาะเมฆทะเล" — เกาะที่หมอกทะเลคลุมจนคนบนฝั่งเห็นแค่เป็นเงา ✨ เป็นที่ตั้งของ **สำนักเมฆทะเล** สำนักเล็กที่ฝึกวิชาเดินบนผิวน้ำและกระบี่ในพายุ ไม่รับศิษย์จากฝั่ง — คนที่อยากเข้าต้องว่ายน้ำข้ามมาให้ได้

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ลานฝึกบนโขด** | ลานหินที่คลื่นซัดตลอดเวลา |
| **หอคัมภีร์** | หอไม้ที่เก็บวิชาของสำนัก |

## ผู้คน ✨

- ศิษย์สำนักเมฆทะเล
- เจ้าสำนักที่ไม่มีใครเห็นหน้า
