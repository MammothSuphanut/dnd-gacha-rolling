## ภาพรวม

หมู่บ้านในหุบที่หมอกหนาจนมองไม่เห็นมือตัวเองทุกเช้า กลางหุบคือ**น้ำตกขาว**ที่ผู้คนมายืนใต้สายน้ำเย็นจัดเพื่อชำระกายและใจ (มิโซงิ) ก่อนขอพรใหญ่ มิโกะทุกคนของสำนักต้องผ่านการยืนใต้น้ำตกนี้หนึ่งคืนเต็มก่อนรับพิธีขั้นสุดท้าย

ผู้แสวงบุญที่เคร่งจริงจาก Hinode เดินต่อมาที่นี่ และชาวบ้านอยู่ได้ด้วยการให้ที่พักและปลูกชาบนไหล่เขา ✨ เรื่องเล่าท้องถิ่นว่าคนที่ยืนใต้น้ำตกตอนหมอกหนาที่สุดจะเห็น "ตัวเองอีกคน" ยืนอยู่ในหมอก — และคนที่คุยกับมันจะไม่กลับมาเหมือนเดิม

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ยุค PD ตอนต้น | ชาวเขาเชื่อว่าน้ำตกล้างคำสาปได้ |
| ✨ ~450 PD | สำนักมิโกะกำหนดให้น้ำตกเป็นที่ชำระกายของศิษย์ |
| ✨ ~880 PD | ศิษย์มิโกะหายไปในหมอกสามคนในคืนเดียว |
| 935 PD (ปัจจุบัน) | ✨ หนึ่งในสามคนนั้นเดินกลับลงมาจากหมอก — ไม่แก่ขึ้นเลย |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **น้ำตกขาว** | น้ำตกสูงที่หมอกไม่เคยจางรอบฐาน |
| **ศาลเจ้าหินเปียก** | ศาลเจ้าหลังน้ำตก เข้าได้ทางเดียวคือเดินผ่านสายน้ำ |
| **ไร่ชาขั้นบันได** | ไร่ชาบนไหล่หุบ |
| **เรือนพักสามหลัง** | ที่พักผู้มาชำระกาย — ห้ามพูดหลังพระอาทิตย์ตก |

## ผู้คน ✨

- **Takigawa Sae** — มิโกะผู้เฝ้าน้ำตกที่ไม่เคยออกจากหุบมาสิบห้าปี
- **Rin** — ศิษย์มิโกะที่หายไปเมื่อ ~880 PD และเพิ่งกลับมา ยังดูอายุสิบเจ็ด พูดถึง "อีกฝั่งของหมอก" อย่างคิดถึง
- **Jinbei** — ชาวไร่ชาที่ช่วยพาคนขึ้นน้ำตก รู้ทางในหมอกดีกว่ามิโกะ

## การเมืองและความสัมพันธ์

- **[Asahi](asahi.md)**: ✨ มิโกะใหญ่ส่งคนมาสอบสวนเรื่อง Rin อย่างลับ ๆ
- **[Hinode](hinode.md)**: ผู้แสวงบุญเดินต่อมาที่นี่
- **สำนักคนทรงอีกาดำ**: ✨ คนทรงเคยขอมาเรียกวิญญาณศิษย์ที่หายไป — แต่วิญญาณไม่ตอบ เพราะพวกเธอยังไม่ตาย
