## ภาพรวม

เมืองที่**กระดาษเดินได้** — ตามถนนจะเห็นนกกระดาษบินส่งจดหมาย คนกระดาษกวาดลานวัด และสุนัขกระดาษเฝ้าประตู ทั้งหมดคือ**ชิกิงามิ** วิญญาณเล็ก ๆ ที่องเมียวจิผูกไว้กับกระดาษวาชิซึ่งชาวเมืองทำเองจากเปลือกไม้ริมทะเลสาบ

ชาวเมืองครึ่งหนึ่งทำกระดาษ อีกครึ่งเป็นศิษย์และองเมียวจิสายรองของตระกูล Hoshimi ที่เช่าชิกิงามิให้หมู่บ้านทั่วฝั่งเหนือ กำแพงเมืองไม่ได้สร้างไว้กันคนข้างนอก ✨ — มันสร้างไว้กันชิกิงามิที่หลุดจากการผูกไม่ให้ออกไปข้างนอก

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~400 PD | ตระกูล Hoshimi ตั้งโรงกระดาษเพื่อทำชิกิ |
| ✨ ~650 PD | **ชิกิคลั่ง** — ชิกิงามิร้อยตัวหลุดการผูกพร้อมกัน · สร้างกำแพงหลังจากนั้น |
| ✨ ~900 PD | เริ่มให้เช่าชิกิงามิกับหมู่บ้าน — รายได้ใหญ่ของตระกูล |
| 935 PD (ปัจจุบัน) | ✨ ชิกิงามิบางตัวเริ่มกลับมาหาคนผูกเองหลังถูกเผาทิ้ง |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **โรงกระดาษริมน้ำ** | โรงทำวาชิที่ตากกระดาษเต็มลาน |
| **วัดผูกชิกิ** | วัดที่องเมียวจิผูกวิญญาณกับกระดาษ — ห้ามคนนอกดู |
| **กำแพงยันต์** | กำแพงที่ติดยันต์ซ้อนกันจนกลายเป็นชั้นกระดาษหนา |
| **ลานเผากระดาษ** | ที่เผาชิกิงามิที่หมดอายุ — ✨ ควันลอยไปทางเดียวเสมอ |

## ผู้คน ✨

- **Kamiya Shizuru** — องเมียวจิหญิงที่ผูกชิกิงามิได้มากที่สุดในตระกูล · พูดกับชิกิเหมือนลูก
- **Tomekichi** — ช่างกระดาษชราที่เชื่อว่ากระดาษ "จำ" สิ่งที่ถูกเขียนลงไป
- ✨ **Kami** — ชิกิงามินกกระดาษตัวหนึ่งที่ถูกเผาไปสามครั้งและกลับมาทุกครั้ง

## การเมืองและความสัมพันธ์

- **[Hoshimi](hoshimi.md)**: บ้านใหญ่ — เจ้าตระกูลไม่อยากให้สภาวิหารรู้เรื่องชิกิที่กลับมาเอง
- **[Fudamachi](fudamachi.md)**: ส่งกระดาษให้ทำยันต์
- **สำนักมิโกะ**: ✨ ชี้ว่าเรื่องชิกิคลั่งคือหลักฐานว่าวิชาของตระกูลคือเวท ไม่ใช่พิธี
