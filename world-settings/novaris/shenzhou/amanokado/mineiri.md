## ภาพรวม

เมืองวัดบนที่ราบสูงที่เสียง**แตรหอยสังข์**ดังก้องหุบทุกเช้า — ฐานของ**ยามาบุชิ** นักพรตภูเขาที่บำเพ็ญด้วยการเดินข้ามยอดเขา อดอาหาร ยืนใต้น้ำตก และนั่งสมาธิบนหน้าผา พวกเขาเชื่อว่าภูเขาคือร่างของเทพ และการเดินบนภูเขาคือการสวดด้วยเท้า

ทุกปียามาบุชิรุ่นพี่นำศิษย์ออก**ธุดงค์ใหญ่** เดินข้ามเทือกเขาจาก Mineiri ไปถึงวัด Fire Ashari ที่ **[Enzan](kazan-range/enzan.md)** ในปล่องภูเขาไฟ — เส้นทางที่ใช้เวลาครึ่งปีและมีคนตายระหว่างทางเกือบทุกปี ยามาบุชิเป็นสำนักศักดิ์สิทธิ์ที่สภาวิหารรับรองแต่**ไม่เคยส่งคนไปนั่งในสภา** ✨ — "ภูเขาไม่ประชุม" ผู้นำธุดงค์กล่าว ซึ่งทำให้ทั้งสามสำนักที่แย่งที่นั่งกันอยู่ทั้งรักและรำคาญ

## ประวัติ

| ✨ ~780 PD | ยามาบุชิช่วยตระกูล Kurobane ของ Akitsu เจรจากับเท็งงุใน Tengu Range |
| 935 PD (ปัจจุบัน) | ✨ ธุดงค์ใหญ่ปีนี้เจอทางเดินที่ภูเขาไฟพ่นควันใหม่ — Gyōkai สงสัยว่ารอยรั่วที่ Enzan กำลังขยาย |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **วัดยอดลม** | วัดไม้บนขอบที่ราบสูง เสาไม้ผูกธงสวดนับพันผืน |
| **ประตูธุดงค์** | ประตูหินที่ยามาบุชิเดินออกทุกปี — มีป้ายชื่อคนที่ไม่กลับมา |
| **หน้าผานั่งสมาธิ** | หน้าผาสูงที่ศิษย์ถูกห้อยเชือกลงไปนั่งสมาธิ |
| **ห้องยาภูเขา** | ที่ทำยาจากเห็ดและรากไม้ — ยาที่ดีที่สุดในฝั่งเหนือ |
| **ลานเท็งงุ** | ลานฝึกที่เท็งงุบางตัวมาสอนวิชาดาบแลกกับสาเก |

## ผู้คน ✨

- **Gyōkai** — ผู้นำธุดงค์วัยเจ็ดสิบที่เดินธุดงค์ใหญ่มาสี่สิบครั้ง ยิ้มตลอดเวลา และพูดเป็นปริศนาจนคนอยากตบ
- **Ōmine Tora** — ยามาบุชิหญิงร่างใหญ่ ผู้นำธุดงค์ใหญ่ปีนี้ · เห็นควันใหม่ด้วยตาตัวเอง
- **Kurama** — เท็งงุหนุ่มที่มาเรียนกับยามาบุชิ ✨ ส่งข่าวไปให้ฝูงเท็งงุใน Tengu Range ทุกเดือน

## การเมืองและความสัมพันธ์

- **[Enzan](kazan-range/enzan.md) / Fire Ashari**: ✨ มิตรเก่า — ยามาบุชิเป็นคนนอกกลุ่มเดียวที่ Fire Ashari ยอมให้เข้าใกล้รอยรั่ว
- **สภาวิหาร Kamizono**: รับรองแต่ไม่มีที่นั่ง — ✨ ทั้งสามสำนักพยายามดึงยามาบุชิมาเป็นพวก
- **[Tengu Range](../unspecified/tengu-range.md) / เท็งงุ**: สัญญาสงบ · ยามาบุชิคือคนกลางระหว่างเท็งงุกับมนุษย์
- **[Kitsunebi](kitsunebi.md)**: ✨ จิ้งจอกชอบแกล้งยามาบุชิที่เดินผ่าน
