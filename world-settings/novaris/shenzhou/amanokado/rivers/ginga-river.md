# Ginga River

> origin: แม่น้ำจากแผนที่ Azgaar (เดิม `Gwang River`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-24 · อ่านว่า กิน-งะ 銀河 (ทางช้างเผือก)
> **ร่าง 2026-10-24 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | แม่น้ำ |
| ที่ตั้ง | Shenzhou → Amanokado · ทุนดราเหนือสุด |
| ต้นน้ำ → ปลายน้ำ | ทุนดรารอบหอดาว [Kitaboshi](../kitaboshi.md) → ทะเลสาบน้ำแข็งทางเหนือของ [Tenmon](../tenmon.md) |
| ความยาว | ~1,870 ไมล์ |
| กระแสน้ำ | ตื้น ใสเหมือนแก้ว · แข็งตัวครึ่งปี |
| เมืองริมน้ำ | [Kitaboshi](../kitaboshi.md) |
| การเดินทาง | เลื่อนบนน้ำแข็ง · เรือหนังของชนเผ่าในฤดูร้อน |

## ภาพรวม

แม่น้ำบนทุนดราที่**สะท้อนดาวทั้งฟ้าได้ในคืนฤดูหนาว** — นักดาราศาสตร์ของตระกูล Hoshimi ที่ประจำหอดาว Kitaboshi ตั้งชื่อว่า Ginga เพราะคืนที่น้ำนิ่งและฟ้าใส ทางช้างเผือกบนฟ้ากับในแม่น้ำต่อกันจนดูเหมือนแม่น้ำไหลขึ้นฟ้า หอดาวใช้ผิวน้ำเป็นกระจกสังเกตดาวที่อยู่ต่ำเกินกว่าจะเห็นจากทางใต้ และส่งบันทึกลงไปถึงสำนักงานปฏิทินที่ Tenmon ✨ คนในตระกูลที่ถูกส่งมาประจำส่วนใหญ่คือคนที่ตระกูลอยากให้อยู่ไกล ๆ — และแม่น้ำคือสิ่งเดียวที่ทำให้พวกเขาไม่บ้า

## ตลอดสาย ✨

| ช่วง | ภาพที่เห็น |
|---|---|
| **ต้นน้ำ** | น้ำซึมจากทุ่งตะไคร่ หอดาวไม้หลังเดียว |
| **ช่วงทุนดรา** | แม่น้ำคดเคี้ยวเป็นเส้นเงิน ฝูงกวางเรนเดียร์ของชนเผ่าข้าม |
| **ปลายน้ำ** | ทะเลสาบน้ำแข็งกว้าง แสงเหนือสะท้อนน้ำแข็ง |

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **วังกระจก** | ช่วงน้ำนิ่งหน้าหอดาว — ใช้สังเกตดาว |
| **ด่านค้าขนสัตว์** | ลานริมน้ำที่ชนเผ่ามาแลกขนสัตว์ |
| **ทะเลสาบแสงเหนือ** | ปลายน้ำ — ตกปลาผ่านน้ำแข็ง |

## ผู้คนและสิ่งมีชีวิต ✨

- **องเมียวจิประจำหอ** — คนที่ตระกูลไม่ต้องการ แต่รู้เรื่องดาวมากที่สุด
- **ชนเผ่า Tsagaan Tal** — มาค้าขาย
- **นกฮูกหิมะ** — เกาะบนหลังคาหอดาว

## ไอเดียฉาก ✨

- **ดาวในน้ำที่ไม่มีบนฟ้า** — วังกระจกสะท้อนดาวดวงหนึ่งที่ไม่มีบนท้องฟ้าจริง
- **บันทึกที่ไม่ถึง Tenmon** — ผู้ส่งสารหายระหว่างทาง บันทึกนั้นมีอะไร
- **ข้ามน้ำแข็งบาง** — การเดินทางปลายฤดูหนาว
