> **ร่าง 2026-10-22 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน · ภูมิภาคย่อยของ [Amanokado](../_overview.md)

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | ภูมิภาคย่อย — ป่า |
| ทวีป | Shenzhou · Amanokado |
| การปกครอง | สภาวิหาร Kamizono |
| ระดับอารยธรรม | 1–2 |
| ภูมิประเทศ | ป่าสนทึบ ทะเลสาบในพื้นที่ชุ่มน้ำ ภูเขายอดคู่ · ทางเหนือกลายเป็นทุนดรา |
| ภูมิอากาศ | หนาว แสงสนธยาเกือบทั้งวันใต้ร่มไม้ |
| การเดินทาง | ทางป่าเชื่อมเมือง · ถนนเหนือสู่ Kanmon |

## ภาพรวม

ป่าสนที่ทึบจนแสงใต้เรือนยอดเป็นสีสนธยาเกือบทั้งวัน — ที่มาของชื่อ Yūgure ใจกลางป่าคือภูเขาที่ตั้งนครเทพ Kamizono ✨ ชาวบ้านเชื่อว่าโยไคและวิญญาณป่าอาศัยอยู่ในส่วนที่มืดที่สุด และนักเดินทางที่หลงทางให้ตามเสียงระฆังจากวิหาร
