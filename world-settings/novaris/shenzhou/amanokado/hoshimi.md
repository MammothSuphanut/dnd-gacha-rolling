## ภาพรวม

เมืองริมทะเลสาบที่ท้องฟ้ากลางคืนใสที่สุดในแผ่นดินญี่ปุ่น — และนั่นคือเหตุผลที่ **ตระกูล Hoshimi** ตั้งบ้านใหญ่ที่นี่มาเจ็ดร้อยปี องเมียวจิของตระกูลอ่านดาว คำนวณปฏิทิน ดูฤกษ์งานแต่ง งานศพ และการสร้างบ้าน เขียนยันต์ป้องกันโยไค และผูก**ชิกิงามิ** (วิญญาณรับใช้จากกระดาษ) มาทำงานแทนคน

ปัญหาเดียวคือ Amanokado **ระแวงเวทอาร์เคน** — และสิ่งที่องเมียวจิทำนั้นดูเหมือนเวทมาก **สภาวิหารรับรองอย่างเป็นทางการว่าวิชาของตระกูลคือ "พิธี" ไม่ใช่เวท** ✨ คำรับรองนี้แลกมาด้วยการที่ตระกูลต้องส่งปฏิทินหลวงให้นครเทพฟรีทุกปี และยอมให้นักบวชตรวจตำราทุกเล่ม — คนนอกหลายคน รวมถึงมิโกะของสำนักรุ่งอรุณ ยังเถียงว่ามันคือเวทแปะป้ายใหม่

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~230 PD | บรรพบุรุษตระกูลตั้งหอดูดาวริมทะเลสาบ |
| ✨ ~480 PD | สภาวิหารรับรองวิชาของตระกูลเป็น "พิธี" · ได้สิทธิ์ทำปฏิทินหลวง |
| ✨ ~600 PD | สภาวิหารฝากเมืองฝั่งเหนือให้ตระกูลดูแล |
| ✨ ~870 PD | ดาวดวงหนึ่งหายไปจากฟ้า — ปีเดียวกับ "ปีอีกาเงียบ" ที่ Karasuma |
| 935 PD (ปัจจุบัน) | ✨ Tokiharu ทำนายว่า "ดาวเก้าดวงจะเรียงกัน" ในอีกไม่กี่ปี — และไม่ยอมบอกว่าแปลว่าอะไร |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **หอดาวทะเลสาบ** | หอไม้ห้าชั้นริมน้ำ — ชั้นบนสุดเปิดหลังคาได้ |
| **คฤหาสน์ Hoshimi** | บ้านใหญ่ของตระกูล รั้วติดยันต์ทุกช่วงแขน |
| **ห้องกระดาษ** | ห้องที่ชิกิงามิถูกเก็บระหว่างไม่ได้ใช้ — กระดาษนับพันแผ่นที่บางครั้งขยับเอง |
| **ศาลาปฏิทิน** | ที่คัดลอกปฏิทินหลวงส่งทั่วประเทศ |
| **ท่าเรือทะเลสาบ** | เรือไปเมืองในสังกัดรอบทะเลสาบ |

## ผู้คน ✨

- **Hoshimi Tokiharu** — เจ้าตระกูลวัยหกสิบห้า เยือกเย็น มองคนเหมือนมองดาว — ห่างและคำนวณได้
- **Hoshimi Kaguya** — ลูกสาวคนโต ทายาทที่เก่งกว่าพ่อ ✨ แอบติดต่อกับวิญญาณจิ้งจอกที่ [Kitsunebi](kitsunebi.md)
- **Hoshimi Saku** — น้องชายของเจ้าตระกูลที่ถูกส่งไปเฝ้าหอดาวที่ [Kitaboshi](kitaboshi.md) หลังทำนายผิดเรื่องใหญ่

## การเมืองและความสัมพันธ์

- **สภาวิหาร Kamizono**: ✨ คำรับรองว่าเป็น "พิธี" คือเส้นชีวิตของตระกูล — ถ้าถูกถอน ตระกูลทั้งตระกูลจะกลายเป็นจอมเวทที่ประเทศไม่ยอมรับ
- **เมืองในสังกัด**: [Tenmon](tenmon.md) · [Shikimura](shikimura.md) · [Fudamachi](fudamachi.md) · [Yuimori](yuimori.md) · [Hokuto](hokuto.md) · [Kitsunebi](kitsunebi.md) · [Kitaboshi](kitaboshi.md)
- **สำนักมิโกะ / สำนักคนทรง**: ✨ แย่งที่นั่งในสภาวิหาร — สำนักมิโกะอยากให้ถอนคำรับรอง สำนักคนทรงซื้อยันต์จากตระกูลเงียบ ๆ
- **Akitsu Shogunate**: ✨ โชกุนจ้างองเมียวจิของตระกูลดูฤกษ์ยกทัพ — สภาวิหารไม่รู้
