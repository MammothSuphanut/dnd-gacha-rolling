# Hoshikage-jima

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | เกาะในทะเลสาบ |
| ที่ตั้ง | Shenzhou → Amanokado · เกาะกลางทะเลสาบใกล้ Kitaboshi |
| สังกัด | **Amanokado** — ตระกูล Hoshimi |
| ขนาด | ~13,000 ตร.ไมล์ |
| ประชากร | ✨ 3 คน |
| เศรษฐกิจ | ไม่มี |
| ภูมิอากาศ | หนาวจัด (เฉลี่ย ~-4°C) · พื้นที่ส่วนใหญ่เป็นทุ่งหญ้า |
| การเดินทาง | เรือพายจากฝั่งทะเลสาบ |

## ภาพรวม

"เงาดาว" — เกาะเล็กกลางทะเลสาบที่น้ำนิ่งจนสะท้อนดาวทั้งฟ้า ตระกูล Hoshimi ใช้ผิวน้ำเป็นกระจกสังเกตดาว และมีศาลเล็กของเทพแห่งดาวบนเกาะ
