> origin: เมืองสุ่มจากแผนที่ Azgaar (เดิม `Yeongwang`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-23 · อ่านว่า อา-เคะ-โบะ-โนะ (รุ่งสาง)

## ภาพรวม

ถ้า Asahi คือหัวใจของสำนักมิโกะแห่งรุ่งอรุณ **Akebono คือโรงเรียนของมัน** — เด็กหญิงจากทั่ว Amanokado (และเด็กชายส่วนน้อยที่สำนักเริ่มรับเมื่อร้อยปีก่อน) ถูกส่งมาเรียนร่ายรำ สวด รักษา และฟังเสียงแสงตั้งแต่อายุเจ็ดขวบ ทุกเช้ามีเสียงกระดิ่งซูซุดังพร้อมกันหลายร้อยอัน

เพราะเป็นเมืองของสำนักที่ใกล้ Kamizono ที่สุด Akebono จึงเป็น**สถานทูตของสำนักต่อสภาวิหาร**ด้วย — มิโกะอาวุโสที่นี่เดินทางไปประชุมที่นครเทพเป็นประจำ และกลับมาพร้อมข่าวการเมืองที่ศิษย์ไม่ควรรู้ ✨ ศิษย์รุ่นนี้ลือกันว่าครูใหญ่กำลังคัดเลือก "มิโกะแห่งตะวัน" รุ่นใหม่ ซึ่งไม่มีมาสามชั่วคนแล้ว

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~400 PD | สำนักตั้งโรงเรียนใกล้ Kamizono เพื่อให้ศิษย์เข้าร่วมพิธีที่นครเทพได้ |
| ✨ ~830 PD | เริ่มรับศิษย์ชาย — ครึ่งสำนักไม่พอใจ |
| ✨ ~905 PD | "มิโกะแห่งตะวัน" คนสุดท้ายเสียชีวิต |
| 935 PD (ปัจจุบัน) | ✨ ครูใหญ่เริ่มทดสอบศิษย์ทุกคนด้วยพิธีที่ไม่มีใครเคยเห็น |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **หอเรียนกระดิ่ง** | หอไม้สามชั้น — ห้องเรียนร่ายรำ สวด และรักษา |
| **ลานรับแสง** | ลานหินที่ศิษย์ฝึกยืนนิ่งจากตะวันขึ้นถึงเที่ยง |
| **ศาลเจ้าศิษย์** | ศาลเจ้าเล็กที่ศิษย์ทุกคนแขวนป้ายไม้ชื่อตัวเองตอนเข้าสำนัก |
| **เรือนทูต** | บ้านพักของมิโกะอาวุโสที่เดินทางไป Kamizono · ✨ เก็บจดหมายของสภาวิหาร |
| **ป้อมประตู** | ป้อมไม้ที่ประตูเมืองเดียว — คุ้มกันศิษย์ ไม่ใช่เมือง |

## ผู้คน ✨

- **Kiyose Natsume** — ครูใหญ่เข้มงวดที่จำชื่อศิษย์ได้ทุกคน · เชื่อว่า "มิโกะแห่งตะวัน" คนต่อไปอยู่ในรุ่นนี้
- **Sora** — ศิษย์ชายคนแรกที่สอบผ่านพิธีรับแสงชั้นสูง — ครึ่งสำนักไม่ยอมรับ
- **Hanabusa Mitsuru** — มิโกะอาวุโสผู้ไปประชุมสภาวิหารเป็นประจำ รู้ความลับของนครเทพมากกว่าที่ควร

## การเมืองและความสัมพันธ์

- **[Asahi](asahi.md)**: บ้านแม่ — ศิษย์ที่จบจากที่นี่ไปรับพิธีสุดท้ายที่ Asahi
- **สภาวิหาร Kamizono**: ✨ ช่องทางหลักที่สำนักใช้ล็อบบี้สภา
- **ครอบครัวขุนนาง**: ส่งลูกสาวมาเรียนเพื่อชื่อเสียง — บางครอบครัวพยายามซื้อตำแหน่งในสำนัก
- **[Tamayobi](tamayobi.md)**: ✨ เมืองคนทรงที่ห่างไป ~190 ไมล์ — ศิษย์ถูกสอนให้ระวังคนทรง แต่ไม่ให้เกลียด
