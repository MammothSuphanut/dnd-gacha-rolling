## ภาพรวม

เมืองที่**คนตายกลับบ้านปีละหนึ่งคืน** — ในคืนจันทร์เต็มดวงปลายฤดูร้อน คนทรงอีกาดำทั้งสำนักมารวมกันที่ Tamayobi เปิด "ประตูโคม" และวิญญาณคนตายของครอบครัวที่ลงทะเบียนไว้จะเดินลงมาตามถนนโคมกระดาษนับพัน มานั่งกินข้าวกับญาติหนึ่งมื้อ แล้วกลับไปก่อนรุ่งสาง

**คืนเรียกวิญญาณ** คือเทศกาลใหญ่ที่สุดของฝั่งตะวันออก ผู้คนเดินทางมาจากทั่ว Amanokado และบางครั้งจากทวีปอื่น ตลอดปีที่เหลือชาวเมืองทำโคม ทำนายพราน และจดทะเบียนชื่อผู้ตายที่ญาติอยากพบ ✨ กฎข้อเดียวของเทศกาลคือ**ห้ามพาวิญญาณออกนอกถนนโคม** — และทุกปีจะมีคนหนึ่งคนที่ฝ่าฝืน

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~500 PD | สำนักคนทรงจัดคืนเรียกวิญญาณครั้งแรก |
| ✨ ~620 PD | สร้างกำแพงหลังปีที่วิญญาณที่ไม่ได้ถูกเชิญเดินเข้ามาด้วย |
| ✨ ~900 PD | ผู้มาเยือนจาก Voxaria เริ่มมาเทศกาล — บางคนมาเพื่อถ่ายภาพวิญญาณ |
| 935 PD (ปัจจุบัน) | ✨ วิญญาณสามดวงที่ลงทะเบียนไว้ไม่มาปีที่แล้ว — ครอบครัวมาทวงถามสำนัก |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ถนนโคม** | ถนนหลักที่แขวนโคมกระดาษตลอดสาย — ทางเดินของวิญญาณ |
| **ประตูโคม** | ประตูไม้ใหญ่บนเนินท้ายเมือง เปิดปีละคืนเดียว |
| **หอทะเบียนผู้ตาย** | ที่ญาติมาลงชื่อผู้ตาย — สมุดทะเบียนเก่าแก่ที่สุดย้อนไป 500 PD |
| **ป้อมศาลเจ้า** | ป้อมที่คนทรงประจำการในคืนเทศกาล — ไว้ส่งวิญญาณที่ไม่ยอมกลับ |
| **ถนนช่างโคม** | ร้านทำโคมกระดาษที่ทำงานทั้งปีเพื่อคืนเดียว |

## ผู้คน ✨

- **Ishigami Tae** — คนทรงที่ดูแลประตูโคมมายี่สิบปี เข้มงวดเรื่องกฎถึงขั้นตีญาติที่พยายามกอดวิญญาณ
- **Hamada Kyūzō** — ช่างโคมชราที่ภรรยาตายไปสามสิบปี และมาเทศกาลทุกปีโดยไม่เคยลงทะเบียนชื่อเธอ
- **Aoi** — เด็กสาวที่ปีที่แล้วพาวิญญาณแม่ออกนอกถนนโคม ✨ ตอนนี้แม่ยังอยู่กับเธอ และไม่มีใครในเมืองรู้

## การเมืองและความสัมพันธ์

- **[Karasuma](karasuma.md)**: บ้านแม่ — คนทรงทั้งสำนักมารวมกันที่นี่ปีละครั้ง
- **สภาวิหาร Kamizono**: ✨ เก็บภาษีเทศกาล — เงินที่สำนักไม่ชอบจ่าย
- **ผู้มาเยือนต่างทวีป**: ✨ สำนักกำลังจะห้ามเครื่องบันทึกภาพจาก Voxaria เพราะ "วิญญาณที่ถูกถ่ายไม่ยอมกลับ"
