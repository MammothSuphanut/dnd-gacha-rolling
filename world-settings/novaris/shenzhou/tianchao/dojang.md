## ภาพรวม

เมืองที่**ทุกอาคารคือบ่อน** — ลูกเต๋า ไพ่ ไก่ชน ม้าแข่งบนชายหาด และในห้องลับใต้ดิน การประลองยุทธที่คนดูแทงพนันว่าใครจะรอด เงินจากการปล้นของ Suro-chae เงินเกลือของ Heukryong-bang และของจากเรือแตกที่ Amcho ล้วนไหลมาจบที่โต๊ะพนันของที่นี่

Dojang เป็นของ Haomun — บ่อนทุกแห่งโกงอย่างมีระดับ ไม่มากพอให้ลูกค้าเลิกมา ✨ ห้องลับชั้นล่างสุดรับเดิมพันที่ไม่ใช่เงิน: ปีของชีวิต ความทรงจำ หรือคำสัญญา และไม่มีใครรู้ว่าเจ้าบ่อนเก็บของพวกนั้นไว้ที่ไหน

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~650 PD | บ่อนแรกของโจรสลัด |
| ✨ ~800 PD | Haomun รับเป็นเมืองในเครือ |
| ✨ ~900 PD | ห้องลับชั้นล่างเปิด — ✨ เจ้าบ่อนคนปัจจุบันชนะเดิมพันครั้งแรกตอนนั้น และยังดูอายุเท่าเดิม |
| 935 PD (ปัจจุบัน) | ✨ จอมยุทธฝ่ายธรรมะคนหนึ่งเดิมพันวิชาของสำนักตัวเองและแพ้ |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **บ่อนเก้าชั้น** | บ่อนที่ใหญ่ที่สุด — ยิ่งขึ้นสูงเดิมพันยิ่งใหญ่ |
| **ลานประลองพนัน** | ลานใต้ดินที่จอมยุทธสู้ให้คนแทง |
| **ห้องเดิมพันสุดท้าย** | ✨ ห้องลับชั้นล่างสุด |
| **ร้านปล่อยกู้** | ดอกเบี้ยรายชั่วโมง |

## ผู้คน ✨

- **Cha Il-gu** — เจ้าบ่อนที่ไม่เคยแพ้ ✨ อาจมีสัญญากับบางอย่างที่ไม่ใช่มนุษย์
- **Min Ho-jun** — จอมยุทธจาก Jeomchang-pa ที่เดิมพันกระบวนกระบี่ของสำนักแล้วแพ้ — ✨ อาจเป็นที่มาของกระบวนที่หายไป
- **Ppal-gang-i** — เด็กส่งไพ่ที่จำทุกใบได้
