# Huzhou 湖州

> origin: เมืองสุ่มจากแผนที่ Azgaar (`Huzhou`) — ไม่มีใน CR · อ่านว่า หู-โจว (เมืองทะเลสาบ) · ชื่อเดิมตรงธีมจีนอยู่แล้ว จึงไม่เปลี่ยน
> **ร่าง 2026-10-23 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ภาพรวม

เมืองขุนนางเล็กริมทะเลสาบที่**ใหญ่เกินจำนวนคน** — ที่ว่าการมณฑล ศาล คุก หอเก็บภาษี และบ้านพักขุนนางเรียงตามถนนหินที่กว้างเกินเหตุ Huzhou คือหนึ่งในสองเมืองที่ราชสำนักปกครองเองจริงในแผ่นดินฝั่งตะวันออก ที่เหลือทั้งหมดเป็นของสำนักยุทธและฝ่ายอธรรมที่ไม่สนใจราชสำนัก

เจ้าเมืองส่งรายงานไป Yujing ทุกเดือนว่ามณฑลสงบเรียบร้อย ภาษีเก็บได้ครบ ✨ ทั้งสองข้อไม่จริง แต่ไม่มีใครใน Yujing อยากรู้ความจริง ยกเว้น**องครักษ์เสื้อแพร** ที่ตั้งสำนักงานลับในเมืองนี้ และเขียนรายงานอีกฉบับที่ไปถึงจักรพรรดิโดยตรง

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~450 PD | ราชสำนักตั้งเมืองมณฑลริมทะเลสาบ |
| ✨ ~700 PD | สำนักยุทธรอบมณฑลเลิกจ่ายภาษี — ราชสำนักไม่ส่งทัพ |
| ✨ ~800 PD | องครักษ์เสื้อแพรตั้งสำนักงานลับ |
| 935 PD (ปัจจุบัน) | ✨ Li Wenhao ได้คำสั่งลับให้ "นับจำนวนจอมยุทธในมณฑล" — งานที่เขาไม่รู้จะเริ่มอย่างไร |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ที่ว่าการมณฑล** | อาคารราชการหลังคาเหลืองที่ใหญ่ที่สุด |
| **ศาลมณฑล** | ที่ตัดสินคดี — ✨ ไม่เคยตัดสินจอมยุทธได้สักคน |
| **ร้านผ้าไหมหน้าทะเลสาบ** | ✨ หน้าฉากของสำนักงานองครักษ์เสื้อแพร |
| **ท่าคลองหลวง** | ท่าเรือที่ส่งภาษี (ส่วนที่เก็บได้) ไป Yujing |

## ผู้คน ✨

- **Li Wenhao** — เจ้าเมืองหนุ่มที่ฉลาด ซื่อสัตย์ และไม่รู้วิชายุทธเลย
- **Shen Yue** — เจ้าของร้านผ้าไหม — ✨ หัวหน้าองครักษ์เสื้อแพรประจำมณฑล
- **Wang Fu** — หัวหน้าเก็บภาษีที่เก็บภาษีจากชาวบ้านได้ แต่ไม่กล้าเคาะประตูสำนักยุทธ

## การเมืองและความสัมพันธ์

- **[Yujing](../unspecified/yujing.md)**: ราชสำนัก — รับรายงานสองฉบับที่ไม่ตรงกัน
- **[Pingyang](pingyang.md)**: เมืองราชสำนักอีกแห่ง — กองทหารที่ Huzhou ขอกำลังได้
- **สำนักยุทธรอบมณฑล**: ✨ ไม่ยุ่งกับราชสำนักตราบที่ราชสำนักไม่ยุ่ง
- **[Ami-san](ami-san.md)**: ✨ หญิงที่หนีการแต่งงานจาก Huzhou ไปที่นั่น — ขุนนางในเมืองไม่พอใจ
