# Heuksu River

> origin: แม่น้ำจากแผนที่ Azgaar (เดิม `Zhenping River`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-24 · อ่านว่า ฮึก-ซู 黑水 (น้ำดำ)
> **ร่าง 2026-10-24 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |

| ที่ตั้ง | Shenzhou → จากเขตมาร [Heukseong](../../heukseong/_overview.md) → Tianchao |
| ต้นน้ำ → ปลายน้ำ | หุบในเขตมารใกล้ [Tengu Range](../../unspecified/tengu-range.md) → ทะเลใกล้ [Hwangbo-seong](../hwangbo-seong.md) |

| การเดินทาง | ไม่มีเรือ · ชาวประมงไม่ลงอวน |

## ภาพรวม

แม่น้ำที่**ไหลออกจากเขตมาร** — ต้นน้ำอยู่ลึกในดินแดนของพรรคมารสวรรค์ที่ไม่มีใครบุกมาตั้งแต่ยุคแรก น้ำดำเหมือนหมึก ไม่มีใครรู้ว่าดำเพราะดิน เพราะพิษ หรือเพราะสิ่งที่พรรคทำในหุบต้นน้ำ ชาวยุทธภพเรียกมันตามสีอย่างตรงไปตรงมา และถือตามคำเตือนเก่า "อย่าแตะเกล็ดย้อนของมังกร" — **ไม่มีใครทวนน้ำ Heuksu ขึ้นไป** ✨ ปลายน้ำไหลลงทะเลใกล้ป้อมตระกูล Hwangbo ที่สร้างหอเฝ้าเล็ง Heuksu โดยเฉพาะ และนับศพที่ลอยลงมาทุกเดือน

## ตลอดสาย ✨

| ช่วง | ภาพที่เห็น |
|---|---|
| **ต้นน้ำ** | หุบในเขตมาร — ไม่มีใครนอกพรรคเคยเห็นแล้วกลับมาเล่า |
| **ช่วงเขตแดน** | จุดที่แม่น้ำออกจากเขตมาร มีหลักหินแกะอักษร "止" (หยุด) |
| **ช่วงที่ราบ** | ทุ่งร้างสองฝั่ง ต้นไม้ริมน้ำใบดำ |
| **ปลายน้ำ** | ปากแม่น้ำ น้ำดำแผ่เป็นวงในทะเล หอเฝ้าของ Hwangbo บนเนิน |

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **หลักหยุด** | หลักหินที่บอกว่าเลยจากนี้คือเขตมาร |
| **หอเฝ้าน้ำดำ** | หอของตระกูล Hwangbo ที่บันทึกทุกอย่างที่ลอยลงมา |
| **วังศพ** | โค้งน้ำที่ศพมักไปติด |

## ผู้คนและสิ่งมีชีวิต ✨

- **ยามหอเฝ้าของ Hwangbo** — นับศพ จดเครื่องแต่งกาย ส่งรายงานให้พันธมิตรยุทธภพ
- **สาวกพรรคมาร** — บางครั้งเห็นเดินเลียบฝั่งออกมานอกเขต (ไล่ล่าได้ตามธรรมเนียม)
- **ปลาดำ** — กินได้ แต่ไม่มีใครกล้ากิน

## ไอเดียฉาก ✨

- **ศพจากต้นน้ำ** — ศพที่ลอยมาเดือนนี้ใส่ชุดศิษย์สำนักฝ่ายธรรมะที่หายไป — ✨ เข้ากับข่าวว่าพรรคกำลังเตรียมอะไรบางอย่าง
- **ไล่ล่านอกเขต** — สาวกพรรคมารหนีออกมาตามแม่น้ำ ผู้เล่นตามได้จนถึงหลักหยุดเท่านั้น
- **น้ำใสขึ้น** — เช้าหนึ่งน้ำ Heuksu ใสเป็นครั้งแรกในประวัติศาสตร์ ทั้งยุทธภพตื่นตระหนก
