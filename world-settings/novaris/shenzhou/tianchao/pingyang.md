## ภาพรวม

เมืองป้อมที่ล้อมด้วย**อุทยานล่าสัตว์หลวง** — ป่าฝนผืนใหญ่ที่เสือ ช้าง และนกยูงเป็นของจักรพรรดิ ราชวงศ์เคยเสด็จมาล่าสัตว์ที่นี่ทุกสิบปี (ครั้งสุดท้ายเมื่อสามสิบปีก่อน) และกองทหารที่ประจำการไว้ "เฝ้าอุทยาน" คือกองทัพราชสำนักกองเดียวในแผ่นดินฝั่งตะวันออก

ทหารที่นี่ไม่ได้รบมานาน พวกเขาฝึกช้างศึก ล่าสัตว์ส่งวัง และจ้องมองฝ่ายอธรรมบนหมู่เกาะตะวันออกด้วยความหงุดหงิด เพราะได้รับคำสั่งว่า "อย่ายุ่งกับยุทธภพ" ✨ แม่ทัพคนใหม่ไม่ชอบคำสั่งนั้น และเริ่มฝึกทหารแบบที่ไม่ได้มีไว้เฝ้าป่า

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~500 PD | ราชวงศ์ประกาศอุทยานล่าสัตว์หลวง |
| ✨ ~600 PD | สร้างป้อมและกองทหารเฝ้าอุทยาน |
| ✨ ~905 PD | การเสด็จล่าสัตว์ครั้งสุดท้าย — ✨ เจ้าชายองค์หนึ่งหายไปในป่า |
| 935 PD (ปัจจุบัน) | ✨ Zhou Yan ขอกำลังเพิ่มจาก Yujing เพื่อ "ปราบโจรบนเกาะ" |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ป้อมตะวันสงบ** | ป้อมหินที่ทหารประจำ |
| **โรงช้างหลวง** | ช้างศึกสามสิบเชือก |
| **ตำหนักล่าสัตว์** | ตำหนักไม้ที่ว่างมาสามสิบปี — ฝุ่นจับ |
| **ประตูอุทยาน** | ✨ ห้ามชาวบ้านเข้า — แต่ขอทานของ Gaebang เดินเข้าออกได้ |

## ผู้คน ✨

- **Zhou Yan** — แม่ทัพวัยสี่สิบ ทะเยอทะยาน เชื่อว่าราชสำนักอ่อนแอเกินไปกับยุทธภพ
- **Lao Gui** — ควาญช้างชราที่อยู่ตั้งแต่การเสด็จครั้งสุดท้าย ✨ รู้ว่าเจ้าชายไม่ได้หายไปในป่า
- **Mei Lan** — ล่ามที่พูดภาษาฝ่ายอธรรม ✨ สายลับของพรรคกระยาจกในป้อม

## การเมืองและความสัมพันธ์

- **[Yujing](../unspecified/yujing.md)**: ✨ ราชสำนักยังไม่ตอบคำขอกำลังเพิ่ม
- **[Gaebang-chon](gaebang-chon.md)**: เพื่อนบ้านที่ใกล้ที่สุด — พรรคกระยาจกรู้ทุกอย่างที่เกิดในป้อม
- **ฝ่ายอธรรมบนหมู่เกาะ**: ✨ เป้าหมายที่แม่ทัพอยากปราบ — ถ้าเขาลงมือ ยุทธภพอาจมองว่าราชสำนักผิดสัญญา
- **[Huzhou](huzhou.md)**: เมืองราชสำนักคู่กัน
