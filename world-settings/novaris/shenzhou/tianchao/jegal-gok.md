## ภาพรวม

หุบที่**เข้าได้ทางเดียว และหลงได้ทุกทาง** — ตระกูล Jegal วางค่ายกลแปดประตู (八陣圖) ด้วยหินและต้นไม้ไว้ตลอดทางเข้า คนที่ไม่รู้ลำดับประตูจะเดินวนอยู่ในหมอกจนกว่าคนในตระกูลจะออกมารับ

Jegal คือ**สมองของฝ่ายธรรมะ** — ตระกูลที่วิชายุทธไม่ได้โดดเด่น แต่วางกลยุทธ์ ค่ายกล และกลไกได้ดีที่สุดในทวีป พันธมิตรยุทธภพทุกครั้งที่ยกทัพจะมีคนของ Jegal นั่งในกระโจมแม่ทัพ ✨ และตระกูลภูมิใจที่สุดในเรื่องเดียว — เมื่อ ~410 PD บรรพบุรุษ Jegal คือคนเดียวที่เตือนไม่ให้บุกเขาดำ และไม่มีใครฟัง

## ประวัติ

| ช่วง | เหตุการณ์ |

| ✨ ~410 PD | เตือนไม่ให้บุกเขาดำ — ไม่มีใครฟัง · ตระกูลไม่ส่งคนไป จึงรอดทั้งตระกูล |
| ✨ ~700 PD | วางร่างสัญญาห้ามรบที่ Ssiat |

| 935 PD (ปัจจุบัน) | ✨ Jegal Myeong คำนวณว่าพรรคมารกำลังเตรียมอะไรบางอย่าง |

## ผู้คน ✨

- **Jegal Myeong** — ประมุขวัยห้าสิบห้า พัดขนนกไม่เคยห่างมือ พูดช้า คิดเร็ว
- **Jegal Hwa-rin** — บุตรสาวช่างกลที่สร้างวัวไม้กลเดินได้
- **Seok Dal** — คนแคระช่างกลที่หนีมาจากทวีปอื่น ✨ คิดว่ากลไกของ Jegal ใกล้เคียงของ Voxaria

## การเมืองและความสัมพันธ์
