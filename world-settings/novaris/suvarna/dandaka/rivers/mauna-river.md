# Mauna River

> origin: แม่น้ำจากแผนที่ Azgaar (เดิม `Hatnasimvar River`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-24 · อ่านว่า เมา-นะ (ความเงียบ)
> **ร่าง 2026-10-24 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | แม่น้ำ |
| ที่ตั้ง | Suvarna → Dandaka · ฝั่งใต้ ใกล้ [Velatira](../velatira.md) |
| ต้นน้ำ → ปลายน้ำ | ป่าใต้ [Kamala](../kamala.md) → เนินอาศรมแห่งความเงียบ [Maunagiri](../maunagiri.md) → ทะเลใกล้ท่าเรือ [Velapura](../velapura.md) |
| ความยาว | ~1,620 ไมล์ |
| กระแสน้ำ | **ไหลโดยแทบไม่มีเสียง** · ลึกและนิ่ง |
| เมืองริมน้ำ | [Maunagiri](../maunagiri.md) · ✨ ใกล้ [Velapura](../velapura.md) |
| การเดินทาง | เรือพายของอาศรม |

## ภาพรวม

แม่น้ำที่**ไหลผ่านอาศรมที่ไม่มีใครพูดเลย** — ทุกคนที่เข้าประตู Maunagiri ต้องปฏิญาณความเงียบ และแม่น้ำก็ดูเหมือนจะรับธรรมเนียมนั้นไปด้วย มันไหลลึก นิ่ง ไม่มีเสียงน้ำกระทบหิน ไม่มีเสียงกบ ✨ นักบวชในอาศรมเชื่อว่าแม่น้ำ "ฟัง" และใช้มันเป็นที่สารภาพ — เขียนคำที่พูดไม่ได้ลงใบไม้แล้วลอยน้ำ ปลายน้ำไหลออกสู่ทะเลใกล้ท่าเรือป้อมของ Velapura ที่อยู่ในดินแดนเผ่ามายามากกว่าดินแดนของ Jyoti Marga และใบไม้สารภาพบางใบก็ลอยไปถึงมือคนที่ไม่ควรอ่าน

## ตลอดสาย ✨

| ช่วง | ภาพที่เห็น |
|---|---|
| **ต้นน้ำ** | ป่าฝนใต้ Kamala |
| **ช่วงอาศรม** | Maunagiri — ผู้คนนั่งริมน้ำโดยไม่พูด ใบไม้ลอยเป็นสาย |
| **ปลายน้ำ** | ปากแม่น้ำใกล้ Velapura — เสียงกลับมาทันทีเมื่อถึงทะเล |

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ท่าสารภาพ** | ขั้นหินที่ลอยใบไม้ |
| **ปากเสียง** | จุดที่แม่น้ำเจอทะเล และเสียงคลื่นดังขึ้นเหมือนใครเปิดประตู |

## ผู้คนและสิ่งมีชีวิต ✨

- **ผู้ปฏิญาณความเงียบ** — คนที่หนีเสียงของโลก
- **คนเก็บใบไม้ที่ Velapura** — ✨ เก็บใบสารภาพที่ลอยมาและขายความลับ

## ไอเดียฉาก ✨

- **ความลับในใบไม้** — ใบสารภาพของคนสำคัญถูกขายในตลาด Velapura ผู้เล่นตามย้อนน้ำหาเจ้าของ
- **เสียงในแม่น้ำ** — ผู้เล่นได้ยินเสียงกระซิบจากน้ำ ทั้งที่แม่น้ำไม่เคยมีเสียง

## ความเกี่ยวข้อง

- **[Maunagiri](../maunagiri.md)**: อาศรมแห่งความเงียบ
- **[Velapura](../velapura.md)**: ท่าเรือใกล้ปากแม่น้ำ
- **[Kamala](../kamala.md)**: ป่าต้นน้ำ
