# Ikha River

> origin: แม่น้ำจากแผนที่ Azgaar (เดิม `Waburulu River`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-24 · อ่านว่า อิก-ฮา (น้ำแห่งลม — คำแบบมายา)
> **ร่าง 2026-10-24 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ภาพรวม

แม่น้ำที่**เกิดจากลมหายใจและไหลผ่านประตูโลกใต้ดิน** — ต้นน้ำอยู่ใกล้วัดทรงกลมของ Ikal ที่ทุกคนในเผ่ามายาที่ใกล้ตายอยากถูกพามา เพื่อให้ลมหายใจสุดท้ายออกทางช่องลมทิศตะวันออก ช่วงกลางแม่น้ำมุดลงใต้ดินและโผล่ขึ้นที่บ่อ cenote ลึกที่สุดของ Ekchah ซึ่งชาวมายาเชื่อว่าเป็นประตูสู่โลกใต้ดิน แล้วไหลขาวขุ่นด้วยหินปูนไปจนถึงปากแม่น้ำที่ Sakha ที่น้ำขาวไหลลงทะเลสีน้ำเงิน ✨ นักบวช Kaan บอกว่าน้ำขาวคือ "ลมหายใจของคนตายที่กลายเป็นน้ำ"

## ตลอดสาย ✨

| ช่วง | ภาพที่เห็น |
|---|---|
| **ต้นน้ำ** | ลำธารใต้วัดลม ลมพัดผ่านช่องสี่ทิศเป็นเสียงหวีด |
| **ช่วงใต้ดิน** | แม่น้ำหายเข้าถ้ำหินปูน |
| **ช่วง cenote** | Ekchah — น้ำใสสีฟ้าลึกสิบช่วงตัว นักบวชฝนถวายหยก |
| **ปลายน้ำ** | Sakha — น้ำขาวขุ่นลงทะเลน้ำเงิน นักบวชดูดาวทางใต้ |

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ถ้ำมุดน้ำ** | ที่แม่น้ำหายลงใต้ดิน — ทางเข้าโลกใต้ดินของมายา |
| **บ่อ cenote Ekchah** | ที่ถวายหยกขอฝน |
| **ปากน้ำขาว** | Sakha — ✨ แสงลอยเหนือทะเลใต้ทุกคืนมาสามเดือน |

## ผู้คนและสิ่งมีชีวิต ✨

- **นักบวชลมหายใจ** — ทำพิธีที่ Ikal
- **นักบวชฝน** — รวมตัวที่ Ekchah เตรียมพิธีขอฝนครั้งใหญ่
- **ปลาถ้ำขาว** — ปลาไร้ตาที่ว่ายออกมาจากใต้ดิน

## ไอเดียฉาก ✨

- **พิธีขอฝน** — ✨ ฝนช้าสองปีติด บางคนกลัวว่าพิธีจะต้องถวายมากกว่าหยก ผู้เล่นอยู่ในเหตุการณ์
- **ตามน้ำลงใต้ดิน** — ดันเจี้ยนถ้ำหินปูนจากถ้ำมุดน้ำไปถึงก้นบ่อ cenote
- **แสงเหนือทะเลใต้** — เชื่อมกับคำทำนาย "ดาวที่ถูกกลืน"
