## ภาพรวม

**แม่น้ำที่ยาวที่สุดในโลก** และเป็นแม่ของทุกอย่างใน Himmapan — ชาวบ้านเรียกว่า "แม่น้ำสุวรรณ" เพราะในหน้าน้ำ น้ำขุ่นสีทองจากดินตะกอนที่พามาจากทั่วแผ่นดิน และเพราะชื่อของทวีปเองก็มาจากแม่น้ำนี้ ✨ ตามตำนานของ Pancha Sabha Suwanna ไหลวนรอบแผ่นดินเหมือนพญานาคโอบไข่ ต้นน้ำอยู่ใต้ป้อมศิลาแลงของ Kamphaeng Hin ที่กองทัพช้างศึกตั้งอยู่ ไหลลงหุบเขาทางใต้ที่ติดชายแดน Ulfdal ผ่านเมืองเหมืองเงินของโทรลล์ แล้วไปจบที่ท่าแพของล้านนา คนในลุ่มน้ำนับวันด้วยระดับน้ำ: น้ำขึ้น น้ำเต็มตลิ่ง น้ำลง น้ำแห้ง — ไม่ใช่ด้วยเดือน

## ตลอดสาย ✨

| ช่วง | ภาพที่เห็น |
|---|---|
| **ต้นน้ำ** | ลำธารบนดอยใต้กำแพงศิลาแลง ช้างศึกลงอาบน้ำ |
| **ช่วงหุบใต้** | หุบเขาลึกที่มองเห็นทุ่งแห้งของ Ulfdal อีกฝั่ง — บาร์บาเรียนลงมาดื่มน้ำในหน้าแล้ง |
| **ช่วงเหมืองเงิน** | Muang Ngoen — โทรลล์ทำงานริมฝั่ง Ngoen River ไหลเข้ามาพร้อมตะกอนเงิน |
| **ช่วงป่า** | ป่าดิบสองฝั่ง ลำน้ำสาขาเข้ามาเรื่อย ๆ — ที่ชาวบ้านว่าเห็นสัตว์หิมพานต์บ่อยที่สุด |
| **ปลายน้ำ** | Mae Pha — ท่าแพใต้ผาหินสูง เพลงล่องแพได้ยินไปหลายไมล์ แล้วออกทะเลกว้างเป็นสามเหลี่ยมปากแม่น้ำ |

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ท่าช้าง** | ท่าน้ำใต้ Kamphaeng Hin ที่ช้างศึกอาบน้ำทุกเช้า |
| **วังพญานาค** | วังน้ำลึกที่สุดในแม่น้ำ — ชาวบ้านวางดอกไม้และเงินทุกวันพระ ✨ มีคนเห็นเกล็ดใหญ่เท่าบานประตู |
| **แก่งเสือข้าม** | แก่งหินกลางป่าที่คนล่องแพกลัวที่สุด |
| **ผาแพ** | ผาหินสูงเหนือ Mae Pha ที่คนล่องแพจุดธูปก่อนออกเดินทาง |

## ผู้คนและสิ่งมีชีวิต ✨

- **คนล่องแพของล้านนา** — รู้ทุกแก่งทุกโค้ง ร้องเพลงล่องแพ
- **โทรลล์แห่ง Muang Ngoen** — ว่ายน้ำข้ามแม่น้ำได้ในหน้าน้ำ
- **พญานาค** ✨ — ไม่เคยมีใครยืนยัน แต่ไม่มีใครไม่เชื่อ
- **ปลาบึก** — ปลายักษ์ที่ว่ายทวนน้ำขึ้นไปวางไข่ปีละครั้ง

## ไอเดียฉาก ✨

- **ล่องแพทั้งสาย** — การเดินทางยาวหลายเดือนที่ผ่านทุกวัฒนธรรมของลุ่มน้ำ เป็นทั้ง montage และกรอบให้ episode ย่อย
- **น้ำหลากผิดฤดู** — วังพญานาคเกิดคลื่นใหญ่โดยไม่มีพายุ ชาวบ้านว่าพญานาคโกรธ ใครทำอะไร
- **บาร์บาเรียนในหน้าแล้ง** — นักรบ Ulfdal ข้ามแม่น้ำที่แห้งที่สุดในรอบร้อยปี ด่านล้านนาตั้งรับไม่ทัน
