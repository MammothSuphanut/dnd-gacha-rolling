# Bua River

> origin: แม่น้ำจากแผนที่ Azgaar (เดิม `Do Nam Thuy Branch`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-24 · อ่านว่า บัว
> **ร่าง 2026-10-24 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | แม่น้ำ · สาขาของ [Suwanna River](suwanna-river.md) · ลำน้ำสั้นที่สุดใน Suvarna |
| ที่ตั้ง | Suvarna → Himmapan Wilds · ใกล้ [Muang Ngoen](../muang-ngoen.md) |
| ต้นน้ำ → ปลายน้ำ | บึงบัวในป่า → บรรจบ Suwanna River |
| ความยาว | ~150 ไมล์ |
| กระแสน้ำ | แทบไม่ไหล · บัวปกคลุมทั้งผิวน้ำ |
| เมืองริมน้ำ | — |
| การเดินทาง | เรือพายผ่านดงบัว |

## ภาพรวม

ลำน้ำสั้นที่ไหลออกจาก**บึงบัวหลวงกลางป่า** — บัวบานคลุมผิวน้ำจนมองไม่เห็นน้ำ ชาวบ้านจาก Muang Ngoen มาเก็บดอกบัวไปถวายวัด และโทรลล์คนงานเหมืองมาพักแช่น้ำหลังเลิกงาน ✨ ชาวบ้านเชื่อว่าดอกบัวในบึงนี้บานพร้อมกันทั้งบึงก่อนเกิดเรื่องใหญ่ในลุ่มน้ำ และครั้งสุดท้ายที่มันบานพร้อมกันคือปีน้ำหลากครั้งใหญ่

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **บึงบัวหลวง** | ต้นน้ำ — บัวใหญ่เท่าล้อเกวียน |
| **ลานแช่น้ำโทรลล์** | ที่โทรลล์มานั่งแช่ตอนเย็น |

## ผู้คนและสิ่งมีชีวิต ✨

- **คนเก็บบัว** — พายเรือเล็กในดงบัวตั้งแต่เช้ามืด
- **โทรลล์** — มาแช่น้ำหลังเลิกงาน
- **นกกระสาบัว** — ยืนบนใบบัว

## ไอเดียฉาก ✨

- **บัวบานพร้อมกัน** — เช้านี้ทั้งบึงบาน ชาวบ้านเริ่มเก็บของหนีน้ำ ผู้เล่นต้องหาว่าลางร้ายนี้หมายถึงอะไร
- **ใต้ใบบัว** — สิ่งที่ซ่อนอยู่ใต้ผิวน้ำที่มองไม่เห็น
