## ภาพรวม

เมืองบ้านริมคลองที่**บัวหลวงบานเต็มคลองทุกสาย** — บ้านเรือนไทยใต้ถุนสูงเรียงสองฝั่ง ตลาดน้ำทุกเช้า และวัดไม้สักที่ส่องประกายทองตอนเย็น Bang Bua คือหัวเมืองที่เก่าแก่ที่สุดของ Pancha Sabha และเป็นตัวอย่างของ "เมืองที่ดี" ที่ Benjasila ชอบพาแขกต่างแดนมาดู

เมืองร่ำรวยจากไม้สักที่ล่องคลองลงไปสร้างวัดทั่ว Himmapan ✨ ป่าสักรอบเมืองหมดแล้ว และคนตัดไม้ต้องไปไกลขึ้นทุกปี — ตอนนี้ไปถึงป่าหลังหาด Laem Sai ซึ่งเป็นป่าไม้เรือของชาวเล

## ประวัติ

| ช่วง | เหตุการณ์ |
|---|---|
| ✨ ~450 PD | หมู่บ้านริมคลอง |
| ✨ ~620 PD | Seren แต่งตั้งเจ้าเมืองคนแรก — หัวเมืองชั้นในแห่งแรก |
| ✨ ~800 PD | การค้าไม้สักรุ่งเรือง |
| 935 PD (ปัจจุบัน) | ✨ ป่าสักหมด · คนตัดไม้ไปถึง Laem Sai |

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ตลาดน้ำ** | ตลาดบนเรือทุกเช้า |
| **วัดสักทอง** | วัดไม้สักที่ลงรักปิดทอง |
| **ท่าซุง** | ที่รวมไม้ก่อนล่องคลอง |
| **บึงบัวหลวง** | บึงใหญ่ที่บัวบานทั้งปี — ✨ กินรีมาเล่นน้ำตอนเช้ามืด |

## ผู้คน ✨

- **ขุนบัวบาน** — เจ้าเมืองที่ภักดีต่อ Benjasila และไม่ชอบปัญหา
- **Nai Choei** — หัวหน้าคนตัดไม้ที่ไปตัดป่าของชาวเล
- **Kinnaree Saeng** — กินรีสาวที่เป็นครูสอนรำในวัด

## การเมืองและความสัมพันธ์

- **[Benjasila](pancha-sabha.md)**: นายเหนือหัว
- **[Ban Nong](ban-nong.md)**: เพื่อนบ้านใกล้ที่สุด — แลกปลากับข้าว
- **ชาวเล ([Laem Sai](laem-sai.md))**: ✨ ความขัดแย้งเรื่องป่าไม้เรือ
- **หัวเมืองหลวงอื่น**: [Nakhon Phet](nakhon-phet.md) · [Khao Kaeo](khao-kaeo.md) · [Kamphaeng Hin](kamphaeng-hin.md)
