## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | เกาะภูเขาไฟ |
| ที่ตั้ง | Aldenreich → Costa Mosaica · Isole Smeralde ตะวันตกเฉียงใต้ของ Belmare |
| สังกัด | ไม่มี |
| ระดับอารยธรรม | 1 |
| ประชากร | ✨ ~200 คน |
| เผ่าพันธุ์ | หลากหลาย — คนที่จำไม่ได้ว่ามาจากไหน |
| ผู้ปกครอง | ✨ ผู้นำหมู่บ้าน — แต่จริง ๆ คือสิ่งที่อยู่ในภูเขา |
| เศรษฐกิจ | ยังชีพ |
| ภูมิอากาศ | ร้อน แผ่นดินไหวเบา ๆ เสมอ |
| การเดินทาง | เรือ |

## ภาพรวม

เกาะภูเขาไฟที่ชาวบ้านจำไม่ได้ว่าตัวเองเป็นใครหรือมาจากไหนก่อนมาตั้งรกรากที่นี่ เพราะมีบางสิ่งบนเกาะลบความทรงจำเพื่อกักพวกเขาไว้รับใช้ — สิ่งมีชีวิตโบราณในภูเขาไฟ (Vokodo ในฉบับ CR) ชาวบ้านบางคนบอกว่าเกาะนี้คือจุดศูนย์กลางของโลก

## ผังและจุดสำคัญ

| จุด | เป็นอย่างไร |
|---|---|
| **หมู่บ้านลืม** | บ้านไม้ที่ไม่มีใครจำได้ว่าสร้างเมื่อไร |
| **ปล่องภูเขาไฟ** | ที่อยู่ของสิ่งที่ลบความทรงจำ |

## ผู้คน

- ชาวบ้านไร้ความทรงจำ · ✨ บางคนเป็นกะลาสีที่เรือแตกเมื่อไม่กี่ปีก่อน

## การเมืองและความสัมพันธ์

- ✨ เรือที่แวะเกาะนี้บางลำไม่ได้กลับ — และลูกเรือไม่รู้ตัวว่าไม่ได้กลับ
