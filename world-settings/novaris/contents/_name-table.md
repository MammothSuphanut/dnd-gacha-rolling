# ตารางชื่อ Novaris ← Exandria (CR)

> **ตารางกลางไฟล์เดียว**: ทุกชื่อที่ตั้งใหม่ต้องจดที่นี่ก่อน แล้วค่อยนำไปใช้ในเอกสารและแผนที่
> ลำดับการทำงาน: **ทวีป → ภูมิภาค/ประเทศ → สถานที่** ทีละชั้น
> ช่อง **origin** ชี้ไปไฟล์ต้นฉบับในคลัง Exandria (`world-settings/exandria/`) ซึ่งเป็นข้อมูลอ้างอิงของ CR ห้ามแก้
> สถานะ: ✅ เสร็จ · ☐ ยังไม่ทำ · — ไม่เกี่ยว
> - **ชื่อ** = ตกลงชื่อแล้ว
> - **lore** = เขียนเนื้อหาของที่นั้นใน Novaris แล้ว
> - **เอกสาร** = แทนชื่อในเอกสาร Novaris แล้ว (canon, player guide, overview, Map Brief)
> - **แผนที่** = เปลี่ยนป้ายบน Azgaar (`maps/azgaar/saves/novaris.map` + JSON ใน `heightmaps/`) แล้ว — **ทำทีเดียวตอนท้ายสุด**
