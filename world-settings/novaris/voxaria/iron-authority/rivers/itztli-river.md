# Itztli River

> origin: แม่น้ำจากแผนที่ Azgaar (เดิม `Tlalpan River`) — ไม่มีใน CR · ตั้งชื่อใหม่ 2026-10-24 · อ่านว่า อิตซ์-ตลี (ออบซิเดียน, แบบ Nahuatl)
> **ร่าง 2026-10-24 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | แม่น้ำ |
| ที่ตั้ง | Voxaria → Iron Authority · ตะวันออกเฉียงเหนือของรัฐ |
| ต้นน้ำ → ปลายน้ำ | ดินเถ้าแห้งแล้งรอบนคร [Ashgate](../ashgate.md) → ป่าดิบชายฝั่ง → ทะเล |
| ความยาว | ~2,550 ไมล์ |
| กระแสน้ำ | ปานกลาง · น้ำดำใส ก้นเป็นกรวดออบซิเดียน |
| เมืองริมน้ำ | [Ashgate](../ashgate.md) |
| การเดินทาง | เรือส่งเสบียงของกองทัพ Iron Authority |

## ภาพรวม

แม่น้ำที่**ไหลผ่านดินที่ถูกเผาจนเป็นแก้ว** — รอบ Ashgate ดินแห้งแล้งถาวรมาตั้งแต่ยุค Calamity และไฟที่เผาครั้งนั้นร้อนจนหินหลอมเป็นแก้วดำ ก้นแม่น้ำจึงเต็มไปด้วย**กรวดออบซิเดียน**คมกริบ ชาวบ้านเดินลุยน้ำไม่ได้ถ้าไม่มีรองเท้าหนา ทหารฮอบกอบลินของ Iron Authority เก็บกรวดไปทำหัวลูกศรเพื่อพิธีของ Bane และกลางนครยังมีต้นไม้เอลฟ์ที่กลายเป็นหินยืนมองแม่น้ำมาหลายพันปี ✨ ช่วงล่างแม่น้ำเข้าสู่ป่าดิบที่เป็นถิ่นของนักล่า Riftwild ที่ใช้ภาษาแบบ Quetza

## ตลอดสาย ✨

| ช่วง | ภาพที่เห็น |
|---|---|
| **ต้นน้ำ** | ทุ่งเถ้าสีเทา หินแก้วดำโผล่จากดิน ต้นไม้เอลฟ์หินกลางนคร |
| **ช่วงกองทัพ** | ท่าเสบียงทหาร ธงของ Bane |
| **ช่วงป่า** | ป่าดิบกลับมาอย่างกะทันหัน — เส้นแบ่งชัดเหมือนมีด |
| **ปลายน้ำ** | ปากแม่น้ำ ทรายดำปนเศษแก้ว |

## จุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **ลานกรวดแก้ว** | ตลิ่งที่ทหารเก็บออบซิเดียน |
| **เส้นมีด** | จุดที่ทุ่งเถ้าจบและป่าเริ่ม — ไม่มีพื้นที่ระหว่างกลาง |
| **หาดดำ** | ปากแม่น้ำ — ทรายบาดเท้า |

## ผู้คนและสิ่งมีชีวิต ✨

- **ทหารฮอบกอบลิน** — มีวินัย เก็บกรวดตามโควตา
- **นักล่า Riftwild** — อยู่ช่วงป่า ไม่ชอบทหาร
- **ปลาแก้ว** — ปลาใสที่เห็นกระดูก

## ไอเดียฉาก ✨

- **ลุยข้ามแม่น้ำ** — การข้ามที่ทุกก้าวบาดเท้า ขณะถูกไล่ล่า
- **หัวลูกศรพิเศษ** — กรวดก้อนหนึ่งมีเงาบางอย่างข้างใน — ของจากยุค Calamity
- **เส้นมีดขยับ** — ทุ่งเถ้าเริ่มลามเข้าป่า ต้นไม้ตายภายในคืนเดียว
