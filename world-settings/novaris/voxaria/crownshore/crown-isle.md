# Crown Isle

> origin: — (เกาะที่ Azgaar สร้าง · ตั้งชื่อ 2026-10-23 · ชื่อ → [name table](../../contents/_name-table.md) หมวดเกาะ)
> **ร่าง 2026-10-23 — รอ DM ตรวจ** · ✨ = ข้อเสนอที่ยังไม่ยืนยัน

## ข้อมูลด่วน

| หัวข้อ | ข้อมูล |
|---|---|
| ประเภท | เกาะส่วนตัว · คฤหาสน์ |
| ที่ตั้ง | Voxaria → Crownshore · นอกชายฝั่งใกล้ Lumen City |
| สังกัด | เอกชน — ✨ ถือครองโดยบริษัทนิรนาม |
| ขนาด | ~94,000 ตร.ไมล์ |
| ประชากร | ✨ ~200 คน (คนรับใช้และยาม) |
| เศรษฐกิจ | ไม่มี — ที่พักผ่อน |
| ภูมิอากาศ | เย็นสบาย ฝนชุก (เฉลี่ย ~10°C) · พื้นที่ส่วนใหญ่เป็นป่าฝนเขตอบอุ่น · ทุ่งหญ้า |
| การเดินทาง | เรือยอชต์และเรือเหาะส่วนตัว |

## ภาพรวม

เกาะส่วนตัวที่มองเห็นได้จากหน้าต่างทุกบานของย่านรวยใน Lumen City คฤหาสน์บนเกาะเป็นที่จัดงานเลี้ยงของนักการเมือง เจ้าของสื่อ และนายทุน ✨ ข้อตกลงซื้อเสียงหลายครั้งสำคัญถูกตกลงกันที่นี่ — เรื่องที่ทุกคนรู้แต่ไม่มีใครพิสูจน์ได้

## ผังและจุดสำคัญ ✨

| จุด | เป็นอย่างไร |
|---|---|
| **คฤหาสน์บนผา** | คฤหาสน์ที่มีลานจอดเรือเหาะ |
| **ท่ายอชต์** | ท่าเรือส่วนตัวที่ยามคุมตลอดเวลา |

## ผู้คน ✨

- คนรับใช้ ยามส่วนตัว และแขกที่ไม่อยากถูกถ่ายรูป
