# Shadycreek Run

เมืองอิสระไร้กฎหมายทางเหนือของ Quannah Breach ใน Greying Wildlands อยู่นอกการควบคุมของ Empire ไม่มีรัฐบาลอย่างเป็นทางการ (ข้อมูลปี 835 PD) — อำนาจแบ่งกันระหว่าง Greytrader Union, Grudge Gang และ "Tribes of Shadycreek Run" สี่ตระกูลอาชญากรรม (อบายมุข, สินค้าเถื่อน, รับซื้อของโจร)
