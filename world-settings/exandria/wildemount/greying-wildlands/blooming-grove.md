# Blooming Grove

สุสานและวิหารแด่ The Wildmother กับ Archeart ใน Savalirwood ห่าง Shadycreek Run ไปทางตะวันตกเฉียงเหนือ 6 ไมล์ ชาว Shadycreek Run เรียกที่นี่ว่า "Bone Orchard" ตระกูล Clay ของ Caduceus Clay เฝ้าดูแลที่นี่มาหลายชั่วอายุคน ดอกไม้เวทมนตร์แต่ละดอกในสวนผูกกับสายเลือดของผู้ที่ฝังอยู่

ความเสื่อมทรามจาก Molaesmyr ที่ลามเข้า Savalirwood กำลังกัดกินพลังปกป้องของสวนแห่งนี้ลงเรื่อย ๆ
