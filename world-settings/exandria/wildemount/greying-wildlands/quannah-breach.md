# Quannah Breach

ช่องเขาที่ตัดผ่านเทือกเขา Dunrock แบ่ง Dwendalian Empire ออกจาก Greying Wildlands เฝ้าโดยกองกำลังตระกูล Uttolot ผู้เก็บค่าผ่านทางจากทุกคนที่จะเข้าประตูสู่ Shadycreek Run

ปลายด้านใต้มีด่านของ Empire คอยเตือนไม่ให้เดินทางเข้าไป ส่วนปลายเหนือมีประตูไม้สูงสิบฟุตกั้นเขต Greying Wildlands เส้นทางภายในเป็นโตรกหินคดเคี้ยวที่ถูกลมกัดเซาะจนเรียบ
