# Odessloe

นิคมประมง/ตัดไม้ริมแม่น้ำ Erdeloch จุดแวะพักส่งเสบียงระหว่าง Empire กับ Pearlbow Wilderness/Bysaes Tyl/Rexxentrum ส่งไม้และปลาให้ Rexxentrum และ Zemni Fields

ทำเลบน Cloakjaunt Path ทำให้กลายเป็นศูนย์กลางลักลอบขนของแบบเงียบๆ ของ **the Myriad**
