# Nogvurot

เมืองชายแดนเหนือของ Empire ทางตะวันออกของ Rexxentrum ทางตะวันตกเฉียงใต้ของ Quannah Breach บน Glory Run Road แบ่งเป็นสามเขต (Peddler's Row, the Scatters, Aegis Block) ประชากร 15,270 คน (ข้อมูลปี 835 PD)

เกี่ยวข้องกับเหตุการณ์คณะละครสัตว์ของ Mollymauk Tealeaf และความขัดแย้งระหว่าง Kryn กับ Empire
