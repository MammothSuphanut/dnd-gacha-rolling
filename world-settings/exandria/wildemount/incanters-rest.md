# Incanter's Rest

ทุ่งหญ้าเวิ้งว้างใน Blightshore สนามรบเก่าจากยุค The Calamity เต็มไปด้วยซากอาวุธเกราะสนิมเขรอะและโครงกระดูกไททันสามตัวที่เป็นจุดสังเกตเพียงอย่างเดียว พื้นดินอาบไปด้วยพลังเนโครแมนซี่และมีวิญญาณอสูรหลอกหลอน ชื่อมาจากนักเวทนิรนามที่เชื่อว่าเป็นต้นเหตุความหายนะของสนามรบ

ในปี 843 PD Caleb กับ Beau เคยถูกส่งมาที่นี่ชั่วครู่จากการเปิดใช้ Malleus Key ที่ไซต์ขุดค้น Tishtan บน Marquet
