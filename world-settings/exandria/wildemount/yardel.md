# Yardel

หมู่บ้านช่างหินเล็กๆ ทางเหนือของ Grimgolir ที่ตีนเขา Dunrock Mountains ใกล้พอที่จะเดินทางไปกลับได้ในวันเดียว เป็นถิ่นของชุมชนช่างอัญมณีเอลฟ์ขนาดเล็ก (บ้านเกิดของ Briyakar Jurrell)

ปรากฏในแคมเปญที่ 3 เป็นสถานที่ที่ Tombtakers มาเยือน ซึ่ง Lucien Tavelle ได้รู้เรื่องบันทึกที่เกี่ยวข้องกับ Somnovem ที่นี่
