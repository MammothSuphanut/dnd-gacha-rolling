# Orencleft

ชุมชนเล็ก ๆ ที่ตั้งอยู่บริเวณเชิงเขา Orencleft Mountain ใน Verdant Expanse ใกล้กับ Syngorn เป็นจุดเริ่มต้นของสายน้ำตกที่ไหลลงมาจากภูเขาแล้วไหลรวมเป็น Feshun River เบื้องหลังสายน้ำตกมีโพรงถ้ำทอดลึกเข้าไปใน Stormcrest Mountains ซึ่งหน่วย Verdant Guard ของ Syngorn ต้องคอยลาดตระเวน บ้างพบสมบัติเก่าแก่จากยุค Calamity บ้างก็หายเข้าไปไม่กลับออกมาอีกเลย
