# Vues'dal villages

กลุ่มหมู่บ้านเกษตรกรรมที่กระจายตัวอยู่รอบ **Vues'dal Waters** ทะเลสาบที่มีดินภูเขาไฟอุดมสมบูรณ์ เหมาะกับการเพาะปลูกและประมง อยู่ภายใต้การคุ้มครองของ Syngorn ผลผลิตขึ้นชื่ออย่างมะเขือเทศ เชอร์รี ฟักทอง ถั่ว และมันเทศ ถูกส่งออกไปทั่ว Tal'Dorei ผ่านทาง Syngorn

ประชากรเติบโตอย่างรวดเร็ว จากราวพันคนในปี 812 PD เป็นกว่า 2,400 คนในปี 836 PD โดยครึ่งหนึ่งเป็นเอลฟ์ อีกหนึ่งในสี่เป็นกอบลินคินที่หนีภัยจาก Iron Authority ทางใต้ ชาวบ้านต้องรวมตัวกันป้องกันตนเองจากพวกลิซาร์ดโฟล์กและโจรมนุษย์ในพื้นที่ ซึ่งในเหตุการณ์หนึ่งกลุ่มลิซาร์ดโฟล์กเหล่านี้ก่อความรุนแรงมากขึ้นภายใต้การนำของนาคาผู้เฝ้าวิญญาณ Maledicta Hexos
